# Tushare 季报分析

## 目标

1. **做什么**：基于 Tushare 数据，为 A 股季报披露（预告/快报/正式财报）提供业绩分类、归因分析与趋势归纳的结构化报告。
2. **不做什么**：不覆盖港股、美股、加密货币；不提供买卖建议或目标价；不做财务建模、DCF 估值或盈利预测。
3. **给谁用**：具备金融常识的主动投资者或研究员，用于季报季的快速跟踪、初筛与信息整合。

## 适用场景与边界

| 适用 | 不适用 |
|------|--------|
| 季报季每日收盘后跟踪新披露公司 | 非季报季的常规行情查询 |
| 业绩大幅增加/不及预期的批量排查 | 单个公司的深度基本面研究（需实地调研） |
| 基于公告文本的行业趋势初步归纳 | 跨市场（港股/美股）财报分析 |
| 基准版全量数据与每日增量数据的维护 | 短线交易信号或技术面分析 |
| 财报数据的结构化筛选与对比 | 替代卖方研究员的正式研报 |

**边界说明**：本 skill 产出的是"信息整理 + 初步归因"，不是"研究结论"。涉及具体投资建议时，必须附加免责声明。

## 领域方法论

分析遵循三层逻辑，每层必须自洽——趋势结论必须能从多家公司的共性原因中归纳，原因必须能从公告原文中找到来源。

**详细分析框架见 `references/FRAME.md`，以下为核心纲要：**

### 1. 业绩分类标准

| 类别 | 判定规则 |
|------|----------|
| **大幅增加** | 净利润同比增速 ≥ 50%；或扭亏为盈；或大市值公司归母净利润绝对增量显著 |
| **不及预期** | 低于一致预期 ≥ 10%；或公司此前业绩指引下调；或净利润同比下滑 > 20%；或增速明显低于行业均值 |
| **平稳** | 增速在 -20% ~ 50% 之间 |
| **不确定** | 数据不足，无法判断 |

**优先级**：同一公司若同时满足"大幅增加"和"不及预期"（如同比+60%但低于市场预期+90%），归入**不及预期**组，在原因分析中注明绝对增速。

### 2. 原因分析框架

对每家公司的业绩变动，从四个维度拆解：

- **收入端**：量（出货量/订单量/用户规模）、价（ASP/产品结构）、新（新产品/新客户/新市场）
- **利润端**：毛利率变化（原材料/产品结构/价格策略）、费用变化（研发/销售/管理）、非经常性损益（补贴/资产处置/汇兑）
- **外部环境**：宏观需求、政策因素、竞争格局、季节性
- **公司个体**：管理层战略、大客户集中度、产能爬坡/项目周期

### 3. 行业趋势归纳

| 级别 | 标准 |
|------|------|
| 强趋势 | 同一行业 ≥3 家公司公告中有明确相同表述 |
| 中趋势 | 2 家头部公司（市值/营收前三）+ 数据印证 |
| 弱趋势/待验证 | 单家公司 + 逻辑推导，需后续跟踪 |

**禁忌**：不以个股原因代替行业趋势；不以管理层乐观表述替代数据验证；趋势结论必须注明支撑公司名称。

### 4. 公告可信度分级

| 标记 | 含义 |
|------|------|
| ✅ | 正式预告公告，数字区间明确 |
| 〇 | 业绩快报，待年报/季报验证 |
| △ | 投资者关系口径，非正式披露 |
| ✗ | 已修正/与后续数据矛盾 |

### 5. 分析优先级

资源有限时按以下顺序取舍：
1. 沪深300成分股 · 权重靠前
2. 行业龙头（各行业市值/营收前三）
3. 业绩变动幅度最极端的（涨幅/跌幅榜前10）
4. 公告中原因描述最具体、信息量最大的

原因描述模糊（仅写"受市场需求影响"）的公司，降低分析优先级，归入附录简表。

## 工作流程

### Step 1: 获取原始数据
**做什么**：调用脚本获取指定日期/范围内的业绩预告、快报、正式财报、公司基础信息、市值数据。
**用什么**：`scripts/fetch_forecast_express.py` 或 `scripts/fetch_quarterly.py` 或 `scripts/q1_analysis.py` 或 `scripts/week_filter.py`
**产出什么**：结构化原始数据表（CSV/JSON），含公司信息、财务指标、公告原文/摘要。脚本不输出任何分类结论或分析报告。

### Step 2: 业绩分类与归因分析
**做什么**：读取 Step 1 的 CSV，按 FRAME.md 标准逐家公司分类；从公告文本中提取业绩变动原因，按收入端/利润端/外部环境/公司个体四维度拆解。
**用什么**：CSV 数据 + `references/FRAME.md`
**产出什么**：带分类标签（大幅增加/不及预期/平稳/不确定）和归因要点的分析表。

### Step 3: 行业趋势归纳
**做什么**：按行业分组，寻找共性原因；按强/中/弱分级；评估持续性。
**用什么**：Step 2 的归因分析表
**产出什么**：行业趋势列表（含方向、强度、支撑公司、核心逻辑、数据佐证、持续性判断）。

### Step 4: 撰写结构化报告
**做什么**：按 TEMPLATE.md 模板组织内容，生成 Markdown 报告。
**用什么**：Step 2 的分类结果 + Step 3 的趋势归纳 + `references/TEMPLATE.md`
**产出什么**：完整的 Markdown 分析报告。

## 数据获取（脚本抓手）

### 脚本清单

| 脚本 | 职责 | 典型调用 |
|------|------|----------|
| `scripts/fetch_forecast_express.py` | 获取指定日期的业绩预告、快报、公司基础信息、市值数据，合并为结构化 CSV。支持合并到 `baseline.json`。仅做数据聚合与单位转换，不分类、不写报告。 | `python scripts/fetch_forecast_express.py --date 20260421 --merge-to-baseline` |
| `scripts/fetch_quarterly.py` | 获取指定披露日期的正式财报数据（收入、利润、毛利率、ROE），支持多维度数值筛选 | `python scripts/fetch_quarterly.py --date 20260421 --min-revenue 1` |
| `scripts/q1_analysis.py` | 获取指定日期范围内正式财报的同比/环比数据，输出 CSV。仅做数据获取与计算，不做分类或报告。 | `python scripts/q1_analysis.py --start-date 20260401 --end-date 20260421` |
| `scripts/week_filter.py` | 按指定日期范围获取披露公司列表，计算同比并按增速阈值筛选，输出 CSV。仅做数值筛选，不做分类归因。 | `python scripts/week_filter.py --start-date 20260420 --end-date 20260426` |
| `scripts/show_result.py` | 将 CSV 转换为 Markdown 表格。仅做格式转换，不添加标题、摘要或分析结论。 | `python scripts/show_result.py week_20260420_20260426_filtered.csv -o table.md` |

### 调用契约

**`fetch_forecast_express.py`**
- 必需参数：`--date`（披露日期，YYYYMMDD）
- 可选参数：`--period`（报告期，默认 20260331）、`--output`（输出 CSV 路径）、`--merge-to-baseline`（合并到 baseline.json）、`--baseline-only`（仅合并，不输出 CSV）
- 返回：CSV 文件（含股票代码、公告日期、预告类型、净利润增速区间、公告摘要/原因、数据来源标记、市值、营收、净利润）
- 环境变量：`TUSHARE_TOKEN`

**`fetch_quarterly.py`**
- 必需参数：`--date`（披露日期，YYYYMMDD）
- 可选参数：`--period`（报告期，默认 20260331）、`--min-revenue`、`--max-revenue`、`--min-net-profit`、`--min-gross-margin`、`--min-net-margin`、`--min-roe`
- 返回：CSV 文件，含股票代码、公告日期、报告期、营业收入(亿元)、净利润(亿元)、毛利率(%)、净利率(%)、ROE(%)
- 环境变量：`TUSHARE_TOKEN`

**`q1_analysis.py`**
- 必需参数：`--start-date`、`--end-date`
- 可选参数：`--period`（默认 20260331）、`--max-workers`（默认 3）
- 返回：CSV 原始数据（含同比/环比增速、营收、净利润、公司名称、行业）

**`week_filter.py`**
- 必需参数：`--start-date`、`--end-date`
- 可选参数：`--period`（默认 20260331）、`--period-last`（默认 20250331）、`--min-revenue-yoy`（默认 20）、`--min-profit-yoy`（默认 20）、`--output`
- 返回：CSV 文件（含公司名称、代码、行业、收入/利润同比增速、营收、净利润、公告日期）

**`show_result.py`**
- 必需参数：`csv`（输入 CSV 文件路径）
- 可选参数：`-o`（输出 Markdown 文件路径）
- 返回：纯 Markdown 表格（无标题、无摘要、无分析）

### 环境要求

- Python 3.7+
- 依赖：`pip install tushare pandas`
- 环境变量：`export TUSHARE_TOKEN=your_token`

### 常见错误与降级

| 现象 | 处理 |
|------|------|
| 当日无数据返回 | 可能为非交易日或无公司披露，跳过即可 |
| 缺少 TUSHARE_TOKEN | 提示用户设置环境变量后重试 |
| baseline.json 损坏 | 删除后重新运行 `--merge-to-baseline` 重建 |
| 数据缺失（某家公司无同比/环比） | 在分析中标注"数据不足"，不强行推算 |

## 输出规范

**报告结构**（按 `references/TEMPLATE.md`）：
1. **当日概览** — 大幅增加/不及预期/平稳 的数量统计
2. **行业趋势归纳** — 🔴 大增方向 / 🟢 不及预期方向的趋势总结（含强度、支撑公司、持续性判断）
3. **业绩大增个股** — 按增速排序，每家公司包含：业绩数据、可信度标记、核心表述（摘录原文）、要点拆解
4. **不及预期个股** — 同上结构
5. **附录：其他披露公司简表** — 原因描述模糊的公司归入简表

**长度控制**：
- 单家公司分析不超过 200 字（核心数据 + 1-2 句原因提炼）
- 行业趋势每条不超过 100 字
- 日报总长度控制在 2000 字以内，基准版全量报告控制在 5000 字以内

**风格**：中立报告性，避免口语化与情绪词汇。用"同比增长""环比改善"等标准财务用语。

**数据呈现**：
- 净利润、营收统一为亿元，保留 2 位小数
- 增速统一为百分比，保留 1 位小数
- 可信度标记统一使用 ✅ / 〇 / △ / ✗

**附加要求**：
- 每份报告末尾附加数据时间戳与免责声明："本报告基于公开披露信息整理，不构成投资建议。"
- 引用公告原文时需注明来源（业绩预告/快报/正式财报）

## 示例

### Input
> "分析一下 2026年4月21日新披露的季报，看看哪些公司业绩大增、哪些不及预期。"

### 执行步骤

1. **获取数据**
   ```bash
   python scripts/fetch_forecast_express.py --date 20260421 --merge-to-baseline
   ```
   读取生成的 `data/raw/forecast_express_20260421.csv`，或从 `data/raw/baseline.json` 中筛选 ann_date=20260421 的记录。

2. **数据示例（片段）**

   | 公司 | 代码 | 行业 | 净利润同比 | 类型 | 数据来源 | 公告摘要 |
   |------|------|------|-----------|------|----------|----------|
   | 创维数字 | 000810.SZ | 家用电器 | 1455.8% | 预增 | 预报 | 智能终端业务增长，海外订单增加 |
   | 高德红外 | 002414.SZ | 电器仪表 | 338.0% | 预增 | 预报 | 红外热成像产品需求旺盛 |

3. **模型分析与分类**
   - 创维数字：净利润同比 +1455.8%，"预增"类型，符合"大幅增加"标准。原因拆解：收入端"智能终端业务增长" + "海外订单增加"（量+新），未见利润端异常费用提示。
   - 高德红外：同比 +338.0%，"预增"类型，大幅增加。原因："红外热成像产品需求旺盛"（宏观需求/行业景气）。

4. **行业趋势归纳**
   - 家用电器/电子：暂无 ≥3 家共性原因，不构成强趋势。
   - 电器仪表：仅高德红外 1 家，弱趋势/待验证。

5. **输出报告（片段）**

   ```markdown
   # 2026年Q1季报分析 · 20260421 日更新

   > 更新内容：2026年4月21日当日新披露的公司
   > 样本数量：12 家公司

   ## 一、当日概览
   - **大幅增加**：2 家
   - **不及预期**：0 家
   - **平稳/其他**：10 家

   ## 二、行业趋势归纳
   ### 🔴 大幅增加方向
   暂无明确趋势信号。

   ### 🟢 不及预期方向
   暂无明确趋势信号。

   ## 三、业绩大增个股

   ##### 【创维数字】000810.SZ · 家用电器
   **业绩数据**
   - 归母净利润：0.83 亿元（同比 +1455.8%）
   - 预告区间：— 至 — 亿元
   - 数据可信度：△ (forecast)

   **核心表述**
   > 智能终端业务增长，海外订单增加。

   **要点拆解**：净利率约 3.3%。增速极高但绝对利润额偏低，需关注收入增长的持续性及海外订单占比。

   ---

   ##### 【高德红外】002414.SZ · 电器仪表
   **业绩数据**
   - 归母净利润：3.66 亿元（同比 +338.0%）
   - 数据可信度：△ (forecast)

   **核心表述**
   > 红外热成像产品需求旺盛。

   **要点拆解**：净利率约 29.4%。高增速由行业景气驱动，需跟踪下游军工/安防需求持续性。

   ---

   ## 附录：其他披露公司简表
   （10 家平稳/数据不足公司，略）
   ```

> **注**：本示例基于真实数据片段，实际分析时应逐家核对公告原文，确保归因有据。
