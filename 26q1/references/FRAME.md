
## 一、核心分析逻辑

预告分析回答三个问题：
1. **超预期/不及预期的公司有哪些？**（事实层）
2. **为什么？**（原因层——从公告文本中找依据）
3. **这些原因是个股问题还是行业共性？**（趋势层）

三层必须逻辑自洽——行业趋势结论必须能从多家公司的
共性原因中归纳，原因必须能从公告原文中找到来源。

---

## 二、业绩分类标准

### 2.1 大幅增加定义
- 净利润同比增速 ≥ 50%，或
- 扭亏为盈，或
- 归母净利润绝对值增量显著（大市值公司参考）

### 2.2 不及预期定义
- 低于Wind/Bloomberg一致预期 ≥ 10%，或
- 公司此前业绩指引下调，或
- 净利润同比下滑 > 20%，或
- 增速明显低于行业均值

### 2.3 分类优先级
同一公司可能同时满足"大幅增加"和"不及预期"
（如：同比+60%但低于市场预期+90%），
此类归入**不及预期**组，在原因分析中注明绝对增速。

---

## 三、原因分析框架

### 3.1 收入端拆解
- **量**：出货量/订单量/用户规模变化
- **价**：产品均价/ASP变化（提价/降价/产品结构升级）
- **新**：新产品/新客户/新市场贡献

### 3.2 利润端拆解
- **毛利率变化**：原材料成本、产品结构、价格策略
- **费用变化**：研发/销售/管理费用是否异常
- **非经常性损益**：政府补贴、资产处置、汇兑损益

### 3.3 外部环境因素
- 宏观需求：下游行业景气度
- 政策因素：补贴、关税、行业政策
- 竞争格局：行业供需变化、竞争对手动态
- 季节性因素：Q1是否为淡旺季交替期

### 3.4 公司个体因素
- 管理层战略调整
- 大客户集中度风险
- 产能爬坡/项目周期

## 四、行业趋势归纳规则

**归纳为行业趋势的条件：**
同一行业内 ≥ 3家公司出现相同原因描述，
或头部公司（市值/营收前三）出现，视为趋势信号。

**趋势强弱分级：**

| 级别 | 标准 |
|------|------|
| 强趋势 | ≥3家公司公告中有明确相同表述 |
| 中趋势 | 2家头部公司 + 数据印证 |
| 弱趋势/待验证 | 单家公司 + 逻辑推导，需后续跟踪 |

**避免的错误：**
- 不以个股原因代替行业趋势
- 不以管理层乐观表述替代数据验证
- 趋势结论必须注明支撑公司名称

## 五、公告可信度分级

| 标记 | 含义 |
|------|------|
| ✅ | 正式预告公告，数字区间明确 |
| 〇 | 业绩快报，待年报/季报验证 |
| △ | 投资者关系口径，非正式披露 |
| ✗ | 已修正/与后续数据矛盾 |

---

## 六、分析优先级排序

每期分析资源有限，按以下顺序取舍：

1. 沪深300成分股 · 权重靠前
2. 行业龙头（各行业市值/营收前三）
3. 业绩变动幅度最极端的（涨幅/跌幅榜前10）
4. 公告中原因描述最具体、信息量最大的

原因描述模糊（仅写"受市场需求影响"）的公司，
降低分析优先级，归入附录简表。
