# 报告模板与 verdict 契约

报告写到 `reports/dc-<report_date>.md`。`report_date` 是开始生成报告时的本地执行日期，
不从观测日期或锚定日期推导。**frontmatter 的 `verdict` 块是仪表盘唯一认的判断契约**，
必须填；正文写仪表盘表达不了的推理，不要重抄梯级表——那是仪表盘的活。

不传 `--input` 也能出图，判断区会显示「报告未提供整体判断」、面板说明整行不出现——
**脚本不会替模型编结论。**

## frontmatter

```yaml
---
date: 2026-08-30              # 报告生成的执行日；决定文件名、页面标题与报告标题
data_asof: 2026-08-27         # evidence.asof；只表示本报告读取的数据截止日
verdict:
  # 体系状态机的档。没到能定档的条件就写「未定档」并说明缺什么。
  regime_state: "R0 正常（暂定）"
  badge: "R0 正常"
  badge_tone: watch          # widening | watch | tightening | unknown
  headline: "梯级七档齐整，标尺本身没动；能定的只有横截面，动词一个都不能写"
  summary: >
    一句到三句，说清今天框架有没有移动、哪个判据触发、以及最关键的那个限制。
  # 各档状态。键是档号，只填你要点名的那几档，不必写全。
  rungs:
    4:
      status: "长端已单独定价"
      tone: watch
      note: "20Y+ 181bp 对 GOOGL 109bp，差 72bp，是 5–10Y 那 26bp 的近三倍"
    6:
      status: "全曲线最贵的 IG"
      tone: widening
      note: "2–5Y 153bp 比任何其他超大厂的 20Y+ 都宽"
    7:
      status: "高溢价但未定价迫近违约"
      tone: watch
      note: "曲线向上倾斜未倒挂；5.10→5.89 有负斜率段但只有 4 个点"
  # 面板异动说明：说今天什么在动、值得看哪里。判断不是取数，所以由模型写，
  # 脚本只搬运 + 查字数（≤100 字，超了会点名但不截断）。
  # 精简页（默认）只用 ladder 那一条，挂在核心刻度表下面；
  # 其余三条只在 --full 的完整版里出现。
  panels:
    ladder: "……"        # 精简页与完整版都用
    curves: "……"        # 仅 --full
    gaps: "……"          # 仅 --full
    structure: "……"     # 仅 --full
---
```

`date` 与 `data_asof` 是两套日期，不能混用。即使 ETF 持仓、国债曲线或其它证据只更新到
T-1，也不能因此把报告日期退回 T-1。各数据源的真实锚定日继续以 evidence 的 `anchors`
为准，并在正文说明相对报告日的滞后。

`badge_tone` / `tone` 的取值语义：`widening` 走宽（红）、`tightening` 收窄（绿）、
`watch` 观察（琥珀）、`unknown` 数据不足（灰）。**颜色只是辅助，文字始终在场。**

## 正文七节，顺序不变

1. **今天框架移动了什么** —— 第一句必须是框架移动（哪个判据触发、档位有没有变），
   不是数字罗列。没有移动就明说「没有移动」，并说清这是因为没变化还是因为没数据。
2. **梯级读数** —— 各档位置与相对锚点的漂移；离散度是扩张、压缩还是整体平移。
   **漂移要报两个口径**：G-spread 口径（`drift_vs_anchor_bp`）与剔市场口径
   （`drift_vs_anchor_excess_bp`），并明说两者的差就是同期指数 OAS 自己的移动。
   写「档 X 走宽 Y bp」而不交代口径不合格。
3. **曲线形状** —— 谁倒挂了、谁分桶不单调、谁的斜率在收窄。CRWV 单独一段。
4. **归因** —— alpha 分解的结果。序列不够就写「不出数」并说明还差多少天。
5. **结构层** —— 转债位置、GPU 抵押品规模、SPV 租户锚。
6. **三层裁决** —— 市场 / 一级 / 基本面互相矛盾时按 `credit_framework.md` §五 裁决，
   把裁决过程写出来。
7. **证伪条件** —— 每条判断跟一个「什么情况下我这个说法是错的」。

正文 900–1600 字，表格不计入。

## 文风

像跟懂行的人当面把事讲清楚——句子通顺、有逻辑衔接，给判断时把话说透。
不要模板腔，不要成段堆套话。同一维度的多个条目用 bullet，一条一项，
每条用完整通顺的话写完，**不要退化成「主体 − 利差 − 变动」式的横杠拼接**；
结构化对照（发行人 × 期限 × 利差）才用表格。

## 数据呈现

- 利差一律 bp，整数；收益率两位小数带 `%`；金额 `$X,XXXmn`。
- 变化量带正负号。
- **每个数字都要能在证据包里找到出处。**
- 缺失就写「暂无数据 / 该体制不适用」，不用前值冒充最新值。
- 说「可能是 X」时讲清凭什么，以及什么证据会推翻它。

## 每次都必须出现的口径句

以下口径句用于报告正文与 `--full` 完整版；默认精简 HTML 不重复渲染底部口径块。

- G-spread 不是 OAS；含权券已剔除。
- 引用档位漂移时点明是 G-spread 口径还是剔市场口径；G-spread 只剥了利率 beta，
  信用市场 beta 仍在里面。
- ETF 持仓价是基金管理人的估值不是成交价。
- 这是该发行人在指数样本中的子集，不是全部存量债。
- 引用 SPV 组合级数字时必须带「它含 N 项投资，不是本 SPV 单体」。
- CDS 与逐笔 TRACE 无免费源，本监控不覆盖。
