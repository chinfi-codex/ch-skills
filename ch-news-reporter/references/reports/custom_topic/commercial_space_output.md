# 商业航天主题的输出规范(汇报简报)

`commercial_space` 的成品是给 CEO 与董事长看的**汇报简报**,只放主体信息。其余关注
事项照走 `template.md` 的通用骨架。这份规范管写法、结构与取舍;证据分层、传闻降级、
无增量不硬凑这些底线仍按 `methodology.md`,不因为读者换了人就放松。

## 两位读者决定颗粒度,不决定结构

简报**不按人分栏,不设"给 CEO""给董事长"这类小标题**。一条信息只写一次,把它的
工程含义和资本含义在同一段里说完整,两位读者各取所需。

两人的背景只用来定"每条要写到什么程度":

- CEO 是院所总体设计那条线出身,决定了**事实的颗粒度**——型号、批次、地点、日期、
  状态词必须给准,不能停在"某型火箭完成一次试验"。技术细节不用解释,写浅了是浪费他时间。
- 董事长是投融资背景,决定了**每条必须落到哪里**——估值(带口径)、轮次、金额、IPO 节点、
  订单规模。一条工程事实如果推不出任何资本含义,它就不值得单独占一段。

跨界的词各解释一次:技术词第一次出现给一句不超过 15 字的白话注解(如"星间激光 =
卫星之间不落地直接传数据");资本运作的词(老股转让、Pre-IPO、特别表决权、对赌、
募投项目、递表)第一次出现同样用一句话点破。后面再出现不重复解释。

## 简报纪律:不留歧义

这是这份规范的核心。简报是拿去做决定的,任何一处含糊都会让读者停下来猜。

- **判断要给死,不骑墙。** "可能""或将""有望""预计""据悉""相关方面""一定程度上"
  这类词一律不用。有判断就写判断,没把握就写清楚没把握到什么程度。
- **不确定要写成可核验的事实,而不是模糊措辞。** 写"仅界面新闻一家报道,公司未确认",
  不要写"据悉"。写"金额未披露",不要写"金额较大"。
- **时间写绝对日期**,不写"近日""日前""近期"。原文只说"近期"时,照实写"原文称近期,
  未给具体日期"。
- **数字带口径和单位**,不写"大额融资""估值大幅提升"。
- **主体写全称到不会认错的程度**,不写"某公司""相关企业";代词不跨段指代。
- **原文含糊的地方要标出来,不要替它补全,也不要跟着含糊。** 金十电报常写"某试验场"
  "某任务",转述时保留原话并标"原文未披露地点",既不自己编一个地点,也不把这条模糊掉。
- **状态词用准的那一个。** 已受理 / 已问询 / 辅导备案 / 已递表 / 静力试验 / 出厂评审 /
  首飞 / 复用回收各是各的意思,不能混用,也不能笼统写成"IPO 有进展""试验成功"。

## 结构:只有三块

### 1. 结论

3-5 条,每条一句话,一条一件事。写判断,不写摘要——"谁的什么变了,把谁的位置推到了哪儿",
而不是"某公司发布了某消息"。当天没有够格的增量就直接写"今日无实质增量",然后结束,
不要拿旧闻换个说法重发。

### 2. 五条主线正文

按 focus 的五条主线依次组织,顺序固定,不要调换:发射与运力 / 卫星与载荷 /
地外探索与空间站 / **订单披露** / **产业融资**。订单排在融资前面——订单是已经发生的
需求,融资是对未来需求的下注,先看谁真的拿到了钱,再看谁在筹钱。

订单与融资这两节各自的写法:

- **订单披露**这一节写清楚四件事:中标方是谁、合同金额多少(含税口径要标)、交付周期
  到什么时候、这笔订单在对方手里是新增还是替换。上市公司公告口径的合同额与实际确认
  收入常常差很远,两个数都拿得到时并列写出来,只拿到一个数时说明是哪一个。
- **产业融资**这一节按"轮次 → 金额 → 投后估值(标口径) → 领投方 → 资金用途"把一轮
  说完整,拿不到的字段明写未披露。IPO 节点单独说清楚走到哪一步(辅导备案/受理/问询/
  递表/注册/发行),不要笼统写成"IPO 有进展"。
每条事件按"事实 → 工程含义 → 资本含义"想清楚,**写成连贯的话**,不要贴
"事实:""含义:"这种标签,更不要写成"公司 - 轮次 - 金额"的横杠拼接。

中美两条产业线分开写,不用一边的节奏推断另一边。

前瞻节点(下次发射窗口、问询回复期限、募资交割时点)如果对判断实质重要,就写进对应
主线的正文里,当事实的一部分——比如"遥十七拟于 8 月下旬在广东海域首发"——**不要**
另立"观察点"小节。

### 3. 融资与 IPO 进度变化表

只在当天有轮次、估值、受理/问询/递表状态变化时才出,列:公司 / 板块 / 状态 /
本轮变化 / 估值口径。没有变化就整块省掉,不要每天重贴一张静态表。

这张表和「产业融资」正文分工不同,不要把同样的话说两遍:正文讲清一轮融资的来龙去脉
和它意味着什么,表只做多家横向对照。当天只有一两家有变化时,直接并进正文、不出表。

## 不进简报的东西

下面这些是运营侧的记录,**一律不出现在简报里**,只留在证据记录与 watchboard:

- 顶部的数据源说明、检索口径说明、纪律与免责说明
- 底部的覆盖说明、通道状态、web 检索预算用量、数据缺口清单
- 跟踪项(#T-xxx)的开项与结算
- 单独成节的 24-72h 观察点

**但它们照常产出,只是不给这两位看**:`save_report_state.py --profile custom_commercial_space`
仍按原样回写 watchboard(regime / tracking_items / next_nodes / falsifiers),跨天状态不受影响;
合并日报 `custom_daily_<date>.md` 作为运营侧产物,也照旧保留它的全局覆盖说明。

一个例外情况:**数据缺口如果让某条判断站不住,不要靠底部的覆盖说明去交代**,直接在那条
判断旁边写明依据不足到什么程度。比如"国内这条线今天只有金十一条转述,拿不到公司确认"。

## 估值口径纪律

给董事长看的部分最容易在这里翻车,单独立一条:**报估值必须同时报口径**。

- 一级市场增资估值与 IPO 发行隐含估值不可直接比较。参照口径:蓝箭航天一级约 207 亿元、
  IPO 隐含约 750 亿元;中科宇航一级 149.8 亿元、IPO 隐含约 420 亿元——两者差 3-5 倍,
  混着说就是错的。
- IPO 隐含估值按"拟募资额 ÷ 发行比例"倒算,通常显著高于最近一轮一级估值,引用时标明。
- 国内一级市场消息多为转述,金额与估值要写明信息来源和是否经公司确认;"未披露"不等于
  "没有",不要把拒绝披露写成没有融资。
- 行业总量的各家统计口径差异很大(同一个 2026H1:澎湃 89 起 / 151.3 亿、投中网 79 笔 /
  127.9 亿、未来天玑 102 起 / 177.1 亿),引用时说明用的是哪一家。

## 一个写对了的例子

> 中科宇航把力箭一号遥十七送去海上发射,这是它第一次做海射。**8 月 13 日**该箭在
> 中科宇航产业化基地通过出厂评审,拟在广东附近海域执行任务,金十电报未披露具体发射日期。
> 海射绕开了内陆发射工位的排期,谁先跑通,谁在明年的批量发射合同里就多一张牌。中科宇航
> 目前处于科创板已问询阶段,这次海射给它补了一个可讲的运力故事;但它的估值是
> **一级 149.8 亿元、IPO 隐含约 420 亿元**两个口径并存,问询期间的讨论只能用一级那个数。

这段之所以合格:日期是绝对的,状态词("出厂评审""已问询")是准的,原文没给的东西
(发射日期)明说没给,判断("多一张牌")直接下了,估值两个口径都标了。

不合格的两种写法:

- **"中科宇航 - 力箭一号遥十七 - 海上发射 - 8月13日 - 通过出厂评审"** —— 字段拼接,
  没有判断,读者不知道该拿它干什么。
- **"近日中科宇航在海射方面取得重要进展,有望进一步提升其商业价值,估值可能受益"**
  —— "近日""重要进展""有望""可能"全是含糊词,四句话没有一个可核验的事实。
