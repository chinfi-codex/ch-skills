# 地缘日报方法论（方法论常量）

> 本文件只保留跨框架不变的方法论常量。当前 regime 的分型、frame schema、watchlist 和输出板块见同目录 `framework.md`；活动状态机制见 `../watchboard.md`；跨资产传导见 `cross_asset_impact_framework.md`。

## 目标

把金十与地缘 RSS 中的军事、外交、制裁、能源、航运和大国博弈信息合并为可核查的事件脉络，输出一份面向市场研究的中文地缘日报。脚本只负责取数、筛选、排序和状态校验；判断哪个事件重要、风险如何传导、下一步盯什么，必须由 Agent 基于证据完成。

本日报不提供交易建议，不把单源快讯当结论，不用“全球风险很高/很低”这种空泛话替代证据链。

## 必读 references

1. `framework.md`：当前地缘风险分型、区域主线、frame schema、watchlist、冷启动种子。
2. `../watchboard.md`：活动状态机制，尤其是上一期 open 项必须逐条结算。
3. `cross_asset_impact_framework.md`：能源、航运、制裁、避险资产和通胀传导。
4. `template.md` 或 `template_brief.md`：输出骨架。

## 边际变化判定

每日只把真正改变判断的事项写进“今日边际变化”。满足任一即可：

1. **事实新增**：出现此前未确认的军事行动、停火文本、制裁措施、军援、航运中断、能源设施扰动或官方政策转向。
2. **能力/动机/约束变化**：行为体获得或失去行动能力，国内政治压力改变，盟友约束变强或变弱。
3. **传导路径变化**：事件开始影响能源、航运、制裁、供应链、通胀或风险资产定价。
4. **下一节点变化**：关键会议、期限、选举、审判、军演、协议窗口的预期或日期改变。

不计入边际变化：重复表态、标题党转述、无新事实的分析文章、单方未经证实说法、与上一期 watchboard 无关的零散噪音。

## 证据处理流程

1. **聚类**：先按区域和传导渠道聚类，不按新闻来源堆列表。
2. **可信度分层**：官方/国际组织/多源确认优先；匿名来源、社媒、单方声明降级。
3. **去重**：同一事件只保留最早时间、最新进展、来源差异和影响方向。
4. **事实与推演分离**：事实写“发生了什么”，推演写“它可能改变哪条路径”，不要混成一句。
5. **市场校验**：价格没有反应不等于事件无效，但必须解释为何价格暂未验证。

## 可信度标记

- `高`：官方确认、多源独立确认、国际组织或交易数据可核查。
- `中`：可信媒体单源、政策文件间接印证、价格或航运数据有部分验证。
- `低`：单方声明、匿名消息、社媒流传、尚未被价格或官方口径确认。
- `否`：已被否认、明显误读或与后续事实冲突。

## 降级策略

当地缘证据不足时：

- 明确写“今日证据不足以支持 path / 概率调整”。
- 沿用上一期 watchboard 的 path 与 probabilities，除非 framework 定义的边际变化出现。
- 上一期所有 open 项仍必须结算或顺延，不许因为新闻少就漏掉。
- 若 RSS 或金十缺数，在报告覆盖说明中标注“今日该源无数据/未覆盖”，相关判断降级。

## 文风

文风讲人话，减少机械和僵硬。区域主线、观察项、新闻证据优先用 list，但每条要写成完整句子，解释它为什么重要，不要退化成“国家 - 动作 - 影响”的字段拼接。
