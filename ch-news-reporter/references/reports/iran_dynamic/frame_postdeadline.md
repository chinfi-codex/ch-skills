## 一、阶段定位

- **2026 年 4 月 21 日两周停火窗口已过期。** 局势已实际落入下列三条路径之一：
  - **路径 A：续期 / 谈判推进** —— 出现新协议、谈判会议恢复、制裁部分暂缓
  - **路径 B：崩溃 / 恢复交战** —— 一方或多方在窗口期后新增确认军事行动并触发报复链
  - **路径 C：僵尸化延续** —— 协议形式空转，无重大新交火，亦无谈判突破，问题悬置
- **本框架是阶段感知的元框架**。每日报告第一步：用近 7-14 天证据做路径判定，再按当前路径加载对应子框架（第六章）。
- **不写死当前路径**。模型必须用证据现场判定，避免锚定上一份日报的路径假设。出现"路径切换信号"（第八章）时必须重新评估。

## 二、路径判定逻辑

每日报告首步，用过去 7-14 天事实总和做判定（不是单日证据）：

| 路径 | 判定主标志（任一） | 反向 / 排除证据 |
|---|---|---|
| **A 续期/谈判** | 新协议文本 / 谈判会议恢复 / 任一方公开撤回最后通牒 / 制裁某项暂缓 | 任一方公开退出，或核心条款被官方拒绝 |
| **B 崩溃/交战** | 任一主要方（美/以/伊）在窗口期后确认的新增军事行动 + 已形成报复链 | 双方在 48h 内达成新静默 |
| **C 僵尸化** | 无新协议 + 无重大军事交火（≥ 7-14 天） + 各方均不愿承担破裂责任 | 任一方采取明确升级或谈判动作 |

**判定纪律：**
- 单日只看是否出现"路径切换信号"，不重新整体判定。
- 默认延续上一日报告的路径判定，除非出现下列任一切换信号（第八章详述）。
- 若证据不足以判定，明确写"路径暂不明朗，倾向于 [X]，但需 [Y] 验证"。

## 四、行为体压力变量（权重已重校）

**当前权重排序：** 以色列 > 伊朗内部 > 美国
（基于：停火空转已延续超一月，以色列防空补给和军事预置时间窗口足够；伊朗经济与内部压力累积；美国主导权下降）

### 🇮🇱 以色列（最高优先级监测）
- **监测重点：** 防空 / 弹药补给完成度；内塔尼亚胡联合政府稳定性；右翼联盟伙伴施压强度；美以协调度
- **关键信号：** 任何未经美方背书的对伊行动准备；防空补给宣布完成；联合政府关键投票
- **结构性判断：** 同时具备动机、能力、约束最弱的行为体

### 🇮🇷 伊朗（内部压力监测）
- **监测重点：** 哈梅内伊与政府公开口径分歧；IAEA 关于核活动的最新通报；制裁缓解或加码；代理人（胡塞 / PMF）自主性变化
- **关键信号：** 最高领袖与外长 / 总统口径不一致；浓缩铀活动公开化；代理人在无指令下行动；伊朗主动寻求续谈以换取制裁松动

### 🇺🇸 美国（外部约束监测）
- **监测重点：** 扫雷行动是否得出结论；特朗普叙事是否从"胜利"转向"重新交涉"或"最终通牒"；对以约束意愿
- **关键信号：** 特朗普公开背书或施压以色列；扫雷遭对抗后美军回应方式；新增 / 撤销的最后通牒

## 六、A/B/C 路径子分支

判定为某路径后，加载对应子分支跟踪：

### 路径 A：续期 / 谈判推进
- **A-1 实质性推进** —— 谈判会议恢复 + 出现可验证让步 → 烈度 2-3 级，市场含义：Brent 较空转期回落 $5-10
- **A-2 形式续期、内核空转** —— 协议文本延续但无实质让步 → 烈度 3-4 级，Brent 维持空转区间溢价
- **早期信号：** 第三方（卡塔尔/巴基斯坦/阿曼）提出框架；任一方核心条款松动

### 路径 B：崩溃 / 恢复交战
- **B-1 局部交火** —— 以色列单独行动 + 伊朗有限报复 → 烈度 5-6，Brent 反弹至战时峰值，保险费率 1.0-1.5%
- **B-2 核设施级目标** —— 以军或美军打击伊朗核相关目标 → 烈度 7+，Brent 冲极端高点，霍尔木兹局部封锁
- **B-3 第三方 / 代理人卷入** —— 真主党 / 胡塞 / PMF 系统性介入 → 烈度 6+，LNG 现货溢价扩大，区域航运全面绕航
- **早期信号：** 以色列防空补给完成宣告；伊朗对扫雷的实际对抗动作；代理人自主行动密度上升

### 路径 C：僵尸化延续
- **C-1 持续低烈度蠕变** —— 各方均不愿担破裂责任，蠕变升级缓慢 → 烈度 4-5，Brent 高位震荡，溢价 $6-10
- **C-2 向 B 滑移** —— 以色列约束进一步松动 / 哈梅内伊与政府分歧公开化 → 烈度 5 上探 6，需重新评估路径
- **C-3 被外部冲击推回 A** —— IAEA 报告 / G7 调解 / 关键经济冲击迫使各方回到谈判桌 → 烈度回落 3-4
- **早期信号：** 蠕变升级单方累计；以色列 / 哈梅内伊单方面强硬表态密度变化

## 八、边际变化判定标准（核心）

每日报告必须区分"真正边际变化"和"噪音"。判定三条线（满足任一即计入）：

1. **新事实/数据**：引入此前未确认的事实、数据、或官方表态（不计入：重复表态、媒体二次报道）
2. **能力/动机/约束变动**：改变某一行为体的能力（防空补给）、动机（国内政治压力）或约束（盟友态度）
3. **下一节点预期变化**：影响第五章中下一关键节点的预期或日期

**路径切换信号（必触发重新判定）：**
- 出现新协议或谈判会议确认 → 评估是否切到 A
- 任一主要方在窗口期外的确认军事行动 + 报复链 → 评估是否切到 B
- 已判定为 A 或 B 但出现持续 7+ 天的"无新动作" → 评估是否切到 C

**不记录为边际变化：** 例行强硬表态、重复性媒体报道、未经证实的匿名情报、与前日无实质差异的外交辞令。

## 九、核心信号清单（无论路径每日扫描）

无论当前判定为哪条路径，下列信号每日扫描一次：

1. **以色列防空 / 补给状态** — 任何"补给完成"信号 = 立即标注
2. **IAEA 关于伊朗核活动的任一更新** — 直接影响 A 和 B
3. **扫雷行动进展 / 伊朗反应** — 持续摩擦点
4. **真主党 / 胡塞 / PMF 行动密度** — 代理人是路径切换的早期指示
5. **特朗普 / 内塔尼亚胡 / 哈梅内伊任一公开表态的口径变化** — 高权重信号
6. **Brent / LNG / 保险费率** — 市场是否按当前路径定价
7. **第三方调解信号**（卡塔尔 / 巴基斯坦 / 阿曼 / 中国）— 路径 A 触发器
