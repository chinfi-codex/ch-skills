# iran_dynamic 分析框架 · v1 停火僵局

> 本文件是 iran_dynamic **分析框架的唯一可信源（single source of truth）**。框架契约——path 定义、frame 维度、watchlist、输出板块、regime 失效触发器——全部收敛在这里。
> 跨框架不变的方法论常量（证据处理、可信度分级、降级策略、边际判定通用部分）见同目录 `methodology.md`；活动状态机制（读→结算→回写、台账生命周期）见 `../watchboard.md`。
> **变更框架只改这一个文件。** 当 regime 发生质变（如停火破裂转入持续战争），由慢思考层（`../framework_governance.md`）生成新版本框架（如 `iran-v2-wartime`）整体替换本文件，经人确认后切换并迁移状态。

## 机器区 — 脚本只解析下面这一个 yaml 块

```yaml
# frame schema：save_report_state.py 用它校验每日 watchboard 的 frame 字段。
# 严格等同迁移前 report_profiles.yaml 的 state_schema，不改变任何校验行为。
frame:
  path:             {required: true, enum: [A, B, C]}   # A 续期 / B 交战 / C 僵尸化
  sub_branch:       {}                                  # A-1/A-2 · B-1/B-2/B-3 · C-1/C-2/C-3
  intensity:        {}                                  # 3 / 4 / 5 / 6 / 7+
  actor_weights:    {required: true, type: list}        # 行为体权重排序
  signal_watchlist: {type: list}                        # 当日核心信号清单（可增删）
  probabilities:    {type: map, sum: 100}               # {A, B, C}，和=100

# regime 失效触发器：慢思考层检测这些条件命中即评估"框架换代"，
# 区别于框架内的 path 切换（见模型区"path 判定逻辑"末尾的两级触发说明）。
invalidation_triggers:
  - 任一主要方(美/以/伊)在停火窗口期外、确认的、成规模军事行动且报复链持续 ≥3 天 → 停火 regime 失效，启动战时框架换代评估
  - 正式停火/和平协议签署并落地 → 进入"后战时/重建"regime
  - 政权层级更迭（如哈梅内伊继任引发对外路线质变）→ regime 重定义

# 输出板块骨架：template 渲染顺序（各板块写作要点见模型区）
output_sections: [速览, 核心行动, 能源与市场反应, 推演与观察, 本期变更]
```

## 模型区 — 本框架的领域判定逻辑与写作要点

### path 判定逻辑（A / B / C）

每日报告首步，用过去 7-14 天事实总和做判定（不是单日证据）：

| 路径 | 判定主标志（任一） | 反向 / 排除证据 |
|---|---|---|
| **A 续期/谈判** | 新协议文本 / 谈判会议恢复 / 任一方公开撤回最后通牒 / 制裁某项暂缓 | 任一方公开退出，或核心条款被官方拒绝 |
| **B 崩溃/交战** | 任一主要方（美/以/伊）在窗口期后确认的新增军事行动 + 已形成报复链 | 双方在 48h 内达成新静默 |
| **C 僵尸化** | 无新协议 + 无重大军事交火（≥ 7-14 天）+ 各方均不愿承担破裂责任 | 任一方采取明确升级或谈判动作 |

**判定纪律：**
- 单日只看是否出现"路径切换信号"（见 `methodology.md` 边际变化判定），不重新整体判定。
- 默认延续上一期 watchboard 的 `path`，除非出现切换信号。
- 不写死路径，也不锚定昨天：出现切换信号时必须重新评估。
- 证据不足以判定时，明确写"路径暂不明朗，倾向于 [X]，但需 [Y] 验证"。

> **两级触发要分清**：上面的"路径切换信号"是**框架内**的 A↔B↔C 移动，由快思考（每日 watchboard）处理；而机器区的 `invalidation_triggers` 是**框架级**的 regime 失效（例如交战从"停火被短暂打破"变成持续战争常态，整套停火框架失效），由慢思考处理框架换代。前者改 path 值，后者换整个框架。

### A / B / C 路径子分支

判定为某路径后，在 watchboard 的 `sub_branch` 记录，并按子分支跟踪：

- **路径 A 续期/谈判**：A-1 实质性推进（谈判恢复 + 可验证让步，烈度 2-3，Brent 较空转期回落 \$5-10）；A-2 形式续期、内核空转（协议延续但无实质让步，烈度 3-4）。早期信号：第三方（卡塔尔/巴基斯坦/阿曼）提框架、任一方核心条款松动。
- **路径 B 崩溃/交战**：B-1 局部交火（以色列单独行动 + 伊朗有限报复，烈度 5-6，保险费率 1.0-1.5%）；B-2 核设施级目标（以/美打击核相关目标，烈度 7+，霍尔木兹局部封锁）；B-3 第三方/代理人卷入（真主党/胡塞/PMF 系统介入，烈度 6+，LNG 现货溢价扩大）。早期信号：以色列防空补给完成宣告、伊朗对扫雷的实际对抗、代理人自主行动密度上升。
- **路径 C 僵尸化**：C-1 持续低烈度蠕变（烈度 4-5，Brent 高位震荡，溢价 \$6-10）；C-2 向 B 滑移（约束进一步松动 / 哈梅内伊与政府分歧公开化，烈度 5 上探 6，需重评路径）；C-3 被外部冲击推回 A（IAEA 报告 / G7 调解 / 经济冲击，烈度回落 3-4）。早期信号：蠕变升级单方累计、以色列 / 哈梅内伊强硬表态密度变化。

### 烈度评级（不预设当前级别，每日由 agent 现评）

| 级别 | 特征 |
|---|---|
| 3 | 路径 A 实质推进，蠕变信号轻微 |
| 4 | 路径 C 稳态，多点蠕变，无新交火 |
| 5 | 路径 C 上探边界，约束松动，单方有限违约 |
| 6 | 路径 B 启动，单次重大违约，报复性行动 |
| 7+ | 路径 B 扩散，恢复持续交战，回归战时框架 |

### 行为体权重与盯点（默认排序：以色列 > 伊朗内部 > 美国）

当前权重排序的默认值写在 watchboard 的 `actor_weights`，随证据调整。默认排序依据：停火空转已延续超一月，以色列防空补给和军事预置时间窗口足够；伊朗经济与内部压力累积；美国主导权下降。以色列独立行动监测优先级最高。

- **🇮🇱 以色列（最高优先级）**：盯防空 / 弹药补给完成度、内塔尼亚胡联合政府稳定性、右翼联盟施压强度、美以协调度。关键信号：任何未经美方背书的对伊行动准备、防空补给宣布完成、联合政府关键投票。结构性判断：同时具备动机、能力、约束最弱。
- **🇮🇷 伊朗（内部压力）**：盯哈梅内伊与政府公开口径分歧、IAEA 核活动通报、制裁缓解或加码、代理人（胡塞 / PMF）自主性变化。关键信号：最高领袖与外长/总统口径不一致、浓缩铀活动公开化、代理人无指令行动、伊朗主动寻求续谈换制裁松动。
- **🇺🇸 美国（外部约束）**：盯扫雷行动是否得出结论、特朗普叙事是否从"胜利"转向"重新交涉"或"最终通牒"、对以约束意愿。关键信号：特朗普公开背书或施压以色列、扫雷遭对抗后美军回应方式、新增/撤销的最后通牒。

**共用合规层（不论路径每日核查）：**

| 变量 | 监测指标 | 违约信号 |
|---|---|---|
| 美国对伊直接军事行动 | 伊朗境内新增美军主动打击 | 任一确认事件 |
| 以色列对伊直接军事行动 | 伊朗境内以军行动 | 任一以军认领事件 |
| 美军霍尔木兹穿行 / 扫雷行动 | 伊朗是否采取对抗措施 | 拦截 / 新布雷 / 主动接触 |
| 伊朗主动攻击 | 以色列 / 海湾国家境内袭击 | 伊朗或代理人发动攻击 |
| 以色列-真主党战线 | 黎巴嫩境内打击烈度 | 超出"防御性"范畴的主动进攻 |
| 伊朗核活动 | 铀浓缩活动是否扩大 / 重启 | IAEA 报告或卫星图像变化 |

**蠕变升级判定：** 同一行为体连续两日同类违约 = 蠕变升级，须在边际变化标注。

### watchlist 起点（核心信号清单）

无论当前判定为哪条路径，下列信号每日扫描一次。它们是 watchboard `signal_watchlist` 的默认起点，应随局势增删——这正是"关注点动态迁移"的落点：

1. 以色列防空 / 补给状态 —— 任何"补给完成"信号立即标注。
2. IAEA 关于伊朗核活动的任一更新 —— 直接影响 A 和 B。
3. 扫雷行动进展 / 伊朗反应 —— 持续摩擦点。
4. 真主党 / 胡塞 / PMF 行动密度 —— 代理人是路径切换的早期指示。
5. 特朗普 / 内塔尼亚胡 / 哈梅内伊任一公开表态的口径变化 —— 高权重信号。
6. Brent / LNG / 保险费率 —— 市场是否按当前路径定价。
7. 第三方调解信号（卡塔尔 / 巴基斯坦 / 阿曼 / 中国）—— 路径 A 触发器。

### 滚动关键节点候选库

每日报告由 agent 填入当下"下一 1-2 个关键节点"到 watchboard 的 `next_nodes`。候选节点库（按预期影响排序）：

- IAEA 季度理事会 / 通报 —— 直接驱动 B 风险，可能为 A 提供谈判触发。
- G7 / G20 / 联合国安理会关键会议 —— 第三方调解窗口，对 A 有正向作用。
- 以色列联合政府关键投票 / 内塔尼亚胡审判节点 —— 内部政治压力释放，可能触发 B。
- OPEC+ 会议 / 重大产油国政策变动 —— 路径定价器，影响 Brent 而非路径本身。
- 美国重要选举 / 国会涉伊立法节点 —— 对 A 和 B 都有影响，重点看特朗普表态变化。
- 重要军演 / 周年纪念 / 宗教节日 —— 可能成为预置 B 的窗口或情绪节点。

### 风险资产传导与"能源与市场反应"写作要点

- **路径定价器**：Brent、LNG 现货/期货价差、波斯湾航运保险费率、Murban-Brent 价差。
- **避险定价器**：黄金、瑞郎、美债收益率（注意通胀 vs 避险的方向分歧）。
- **市场判定纪律**（方法论常量，详见 `methodology.md`）：价格定价与判定路径不一致时，先检查市场是否提前定价某种路径切换，再修正自己的判定。
- 行情可通过 `scripts/macro_monitor.py market` 取数；不给交易建议。
- 板块字段：能源节点状态（霍尔木兹通航量 vs 战前 135 / 卡尔格岛 / 扫雷进展，仅记今日新增或变化）；价格变动（Brent / LNG·天然气 / 黄金 / USD-CNH·美债 10Y·BTC / 航运保险费率）；传导评估（市场正按哪条路径定价、是否与本日判定一致、不一致是提前定价还是错配）。

### 各输出板块写作要点

- **速览**：regime（取 watchboard.regime）/ 路径 + 第 N 天（自 2026-04-07 起算）/ 当前子分支 / 烈度 X 级（➡️持平 🔺上升 🔻下降）/ 一句话判断（区分事实与推演）。其后"今日边际变化"必填，无变化明确写"今日无显著边际变化"，按 `methodology.md` 边际变化判定三条线筛 1-3 条。
- **核心行动**：按 🇺🇸 美国 / 🇮🇱 以色列 / 🇮🇷 伊朗 / 代理人与第三方 分组；每条事件后标 🔴升级 / 🟢缓和 / ⚪持平；同类事件合并写解读，个例只列事实。各国"重点监测"项见上文"行为体权重与盯点"。代理人段无新信号则整段省略。
- **推演与观察**：三项必须与本期 watchboard 一致——概率 = `frame.probabilities`、下一关键节点 = `next_nodes`、24-72h 观察清单 = 本期 open 跟踪项按优先级投影。概率仅在出现边际变化时调整并标 ±X%；观察清单 3-5 条按 🔴/🟡 优先级。
- **本期变更（框架 × 跟踪合并）**：渲染约定为所有 `state_enabled` profile 通用，见 `../watchboard.md`。
