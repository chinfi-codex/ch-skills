# 伊朗动态报告方法论

## 目标

把金十、财联社、RSS 等来源中的伊朗/中东局势快讯合并为可核查的事件脉络，输出带可信度分级、停火压力变量、航运能源传导和情景推演的中文动态播报。

本 profile 继承 `iran-war-tracker` 的分析框架，但在 `ch-news-reporter` 内遵守统一三段式流程：采集层写入 SQLite，profile 层生成 evidence packet，Agent 负责理解、判断和写作。

## 必读 references

按任务需要渐进加载：

1. `template.md`：伊朗动态播报输出结构（精简版，强调边际变化）。
2. **`frame_postdeadline.md`：当前默认加载的分析框架**。停火窗口（4/21）到期后阶段，包含路径判定逻辑、A/B/C 路径子分支、合规层、行为体压力变量、滚动关键节点倒计时、边际变化判定标准、核心信号清单。
3. `frame_ceasefire.md`：**仅作历史档案**。停火期（停火生效 → 4/21 到期）的分析框架。不再作为默认加载，仅在回顾或对照停火期分析方法时参考。
4. `economic_impact_framework.md`：霍尔木兹、油气、航运、通胀和宏观传导框架。

## 阶段感知加载规则

- **默认阶段：到期后阶段**。每日报告默认加载 `frame_postdeadline.md`，按其第二章路径判定逻辑确认当前处于 A / B / C 哪条路径，再加载该路径的子分支跟踪框架（第六章）。
- **不要写死当前路径**。模型必须根据近 7-14 天事实总和现场判定，避免锚定上一份日报的路径假设。
- **若局势出现根本性切换**（如正式签署新长期协议、或全面恢复战时框架），评估是否需要新建对应阶段的 `frame_*.md` 而非套用现有框架。新建后将本文件加载顺序改为新框架。

## 宏观行情取数

风险资产宏观行情(Brent / 黄金 / 天然气 / USD-CNH / 美债 / BTC / 纳指期货)不再由本 skill 脚本采集,改由 `chstock-macro-monitor` skill 提供。流程中需要时切到该 skill 目录运行：

```bash
python scripts/macro_monitor.py market
```

获得的 JSON 与 evidence packet 合并作为风险资产证据。金十 MCP 优先(`JIN10_AUTH_TOKEN`),失败回退 AlphaVantage / Stooq。

## 行动基准哲学

- 分析框架是行动基准。先判断当前阶段，再解释证据，不要从立场或标题出发。
- 保持冷静、客观，不预设任何一方必然升级或让步。
- 把局势视为多变量叠加后的概率分支：识别核心变量、权重变化和触发条件，再叠加高可信证据。
- 每个推演必须能回到当日 evidence packet 中的事实、市场价格或官方表态。

## 证据处理流程

1. **事件聚类**：军事行动、外交/调解、核活动、霍尔木兹/航运、能源设施、代理人网络、市场价格、制裁与政策。
2. **可信度分层**：官方/国家级媒体/多源确认优先；单方声明、社媒传言、匿名消息必须降级。
3. **时效筛选**：默认关注过去 18 小时；日报开头标明更新时间和证据窗口。
4. **相似快讯合并**：同一事件只写一条脉络，保留最早时间、最新进展、来源数量和关键差异。
5. **事实与判断分离**：事实、市场定价、推演分别表述。

## 分析要求

- 不能只总结事件。每个关键模块都需要"证据 + 解读"。
- 必须分开分析石油和天然气，不能合并成笼统的"能源"段落。
- 不能把局势简化成"霍尔木兹是否开放"；还要看出口节点、运输交付、保险、炼化错配和政策路径。
- **行为体压力监测以 `frame_postdeadline.md` 第四章权重为准**：以色列 > 伊朗内部 > 美国。以色列独立行动监测优先级最高。
- **必须显式给出"今日边际变化"**：用 `frame_postdeadline.md` 第八章三条判定线识别"真正变化 vs 噪音"，不要把例行表态当作信号。
- 对油价、黄金、美元、美债、BTC 等风险资产只写传导路径、观察点和可能压力，不给交易建议。

## 可信度标记

- `✅`：多方独立确认或官方确认。
- `〇`：单一可信来源。
- `△`：单方声明或未经证实。
- `✗`：已被否认或明显存疑。

## 降级策略

如果当天 evidence packet 中伊朗相关信息不足：

- 明确写"今日证据不足以支持烈度或路径判定调整"。
- 仍可输出观察清单和"下一关键节点"，但不要强行给出高置信推演。
- **沿用上一日的路径判定**（A/B/C），除非出现 `frame_postdeadline.md` 第八章定义的"路径切换信号"。
