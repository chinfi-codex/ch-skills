# 伊朗动态报告方法论

## 目标

把金十、财联社、RSS 等来源中的伊朗/中东局势快讯合并为可核查的事件脉络,输出带可信度分级、行为体压力变量、航运能源传导和情景推演的中文动态播报。

本 profile 在 `ch-news-reporter` 内遵守统一三段式流程:采集层写入数据库,profile 层生成 evidence packet,Agent 负责理解、判断和写作。**当前阶段 / 路径 / 权重 / 信号清单不再写死在静态 frame 文件里,而是由每日滚动的 watchboard 承载**(见下一节)。

## 本 profile 的活动状态(watchboard)

通用机制读 `references/reports/watchboard.md`,这里只说本 profile 的特化部分。

`frame` 字段(声明见 `config/report_profiles.yaml` 的 `state_schema`):

- `path`:`A 续期` / `B 交战` / `C 僵尸化`,每日用近 7-14 天证据现判。
- `sub_branch`:A-1/A-2、B-1/B-2/B-3、C-1/C-2/C-3。
- `intensity`:烈度级别(见"烈度评级")。
- `actor_weights`:行为体权重排序,默认 `[以色列, 伊朗内部, 美国]`,随证据调整。
- `signal_watchlist`:当日核心信号清单,从下面"核心信号清单"起步,逐日增删。
- `probabilities`:`{A, B, C}` 概率,和=100,只在出现边际变化时调整。

每天先读 packet 里的 `Prior Watchboard`,逐条结算上一期 open 跟踪项,写完报告再用 `save_report_state.py` 回写。**首次没有上一期时**,按文末"冷启动种子"构造第一份 watchboard,但 `path` / `probabilities` 必须用今天证据现判,种子里的旧值只当结构脚手架。

## 必读 references(渐进加载)

1. `references/reports/watchboard.md`:活动状态机制(读→结算→回写、台账生命周期、脚本用法)。
2. `template.md`:伊朗动态播报输出结构。
3. `economic_impact_framework.md`:霍尔木兹、油气、航运、通胀和宏观传导框架。

## 行动基准哲学

- 分析框架是行动基准。先判断当前路径,再解释证据,不要从立场或标题出发。
- 保持冷静、客观,不预设任何一方必然升级或让步。
- 把局势视为多变量叠加后的概率分支:识别核心变量、权重变化和触发条件,再叠加高可信证据。
- 每个推演必须能回到当日 evidence packet 中的事实、市场价格或官方表态。

## 路径判定逻辑(A / B / C)

每日报告首步,用过去 7-14 天事实总和做判定(不是单日证据):

| 路径 | 判定主标志(任一) | 反向 / 排除证据 |
|---|---|---|
| **A 续期/谈判** | 新协议文本 / 谈判会议恢复 / 任一方公开撤回最后通牒 / 制裁某项暂缓 | 任一方公开退出,或核心条款被官方拒绝 |
| **B 崩溃/交战** | 任一主要方(美/以/伊)在窗口期后确认的新增军事行动 + 已形成报复链 | 双方在 48h 内达成新静默 |
| **C 僵尸化** | 无新协议 + 无重大军事交火(≥ 7-14 天) + 各方均不愿承担破裂责任 | 任一方采取明确升级或谈判动作 |

**判定纪律:**

- 单日只看是否出现"路径切换信号"(见"边际变化判定"),不重新整体判定。
- 默认延续上一期 watchboard 的 `path`,除非出现切换信号。
- 不写死路径,也不锚定昨天:出现切换信号时必须重新评估。
- 证据不足以判定时,明确写"路径暂不明朗,倾向于 [X],但需 [Y] 验证"。

## 共用合规层(不论路径每日核查)

| 变量 | 监测指标 | 违约信号 |
|---|---|---|
| 美国对伊直接军事行动 | 伊朗境内新增美军主动打击 | 任一确认事件 |
| 以色列对伊直接军事行动 | 伊朗境内以军行动 | 任一以军认领事件 |
| 美军霍尔木兹穿行 / 扫雷行动 | 伊朗是否采取对抗措施 | 拦截 / 新布雷 / 主动接触 |
| 伊朗主动攻击 | 以色列 / 海湾国家境内袭击 | 伊朗或代理人发动攻击 |
| 以色列-真主党战线 | 黎巴嫩境内打击烈度 | 超出"防御性"范畴的主动进攻 |
| 伊朗核活动 | 铀浓缩活动是否扩大 / 重启 | IAEA 报告或卫星图像变化 |

**蠕变升级判定:** 同一行为体连续两日同类违约 = 蠕变升级,须在边际变化标注。

## 行为体压力变量(权重默认:以色列 > 伊朗内部 > 美国)

当前权重排序的默认值写在 watchboard 的 `actor_weights`,随证据调整。默认排序的依据:停火空转已延续超一月,以色列防空补给和军事预置时间窗口足够;伊朗经济与内部压力累积;美国主导权下降。以色列独立行动监测优先级最高。

- **🇮🇱 以色列(最高优先级)**:盯防空 / 弹药补给完成度、内塔尼亚胡联合政府稳定性、右翼联盟施压强度、美以协调度。关键信号:任何未经美方背书的对伊行动准备、防空补给宣布完成、联合政府关键投票。结构性判断:同时具备动机、能力、约束最弱。
- **🇮🇷 伊朗(内部压力)**:盯哈梅内伊与政府公开口径分歧、IAEA 核活动通报、制裁缓解或加码、代理人(胡塞 / PMF)自主性变化。关键信号:最高领袖与外长/总统口径不一致、浓缩铀活动公开化、代理人无指令行动、伊朗主动寻求续谈换制裁松动。
- **🇺🇸 美国(外部约束)**:盯扫雷行动是否得出结论、特朗普叙事是否从"胜利"转向"重新交涉"或"最终通牒"、对以约束意愿。关键信号:特朗普公开背书或施压以色列、扫雷遭对抗后美军回应方式、新增/撤销的最后通牒。

## 滚动关键节点

每日报告由 agent 填入当下"下一 1-2 个关键节点"到 watchboard 的 `next_nodes`。候选节点库(按预期影响排序):

- IAEA 季度理事会 / 通报 —— 直接驱动 B 风险,可能为 A 提供谈判触发。
- G7 / G20 / 联合国安理会关键会议 —— 第三方调解窗口,对 A 有正向作用。
- 以色列联合政府关键投票 / 内塔尼亚胡审判节点 —— 内部政治压力释放,可能触发 B。
- OPEC+ 会议 / 重大产油国政策变动 —— 路径定价器,影响 Brent 而非路径本身。
- 美国重要选举 / 国会涉伊立法节点 —— 对 A 和 B 都有影响,重点看特朗普表态变化。
- 重要军演 / 周年纪念 / 宗教节日 —— 可能成为预置 B 的窗口或情绪节点。

## A / B / C 路径子分支

判定为某路径后,在 watchboard 的 `sub_branch` 记录,并按子分支跟踪:

- **路径 A 续期/谈判**:A-1 实质性推进(谈判恢复 + 可验证让步,烈度 2-3,Brent 较空转期回落 \$5-10);A-2 形式续期、内核空转(协议延续但无实质让步,烈度 3-4)。早期信号:第三方(卡塔尔/巴基斯坦/阿曼)提框架、任一方核心条款松动。
- **路径 B 崩溃/交战**:B-1 局部交火(以色列单独行动 + 伊朗有限报复,烈度 5-6,保险费率 1.0-1.5%);B-2 核设施级目标(以/美打击核相关目标,烈度 7+,霍尔木兹局部封锁);B-3 第三方/代理人卷入(真主党/胡塞/PMF 系统介入,烈度 6+,LNG 现货溢价扩大)。早期信号:以色列防空补给完成宣告、伊朗对扫雷的实际对抗、代理人自主行动密度上升。
- **路径 C 僵尸化**:C-1 持续低烈度蠕变(烈度 4-5,Brent 高位震荡,溢价 \$6-10);C-2 向 B 滑移(约束进一步松动 / 哈梅内伊与政府分歧公开化,烈度 5 上探 6,需重评路径);C-3 被外部冲击推回 A(IAEA 报告 / G7 调解 / 经济冲击,烈度回落 3-4)。早期信号:蠕变升级单方累计、以色列 / 哈梅内伊强硬表态密度变化。

## 烈度评级(不预设当前级别,每日由 agent 现评)

| 级别 | 特征 |
|---|---|
| 3 | 路径 A 实质推进,蠕变信号轻微 |
| 4 | 路径 C 稳态,多点蠕变,无新交火 |
| 5 | 路径 C 上探边界,约束松动,单方有限违约 |
| 6 | 路径 B 启动,单次重大违约,报复性行动 |
| 7+ | 路径 B 扩散,恢复持续交战,回归战时框架 |

## 边际变化判定(核心)

每日报告必须区分"真正边际变化"和"噪音"。判定三条线(满足任一即计入):

1. **新事实/数据**:引入此前未确认的事实、数据或官方表态(不计:重复表态、媒体二次报道)。
2. **能力/动机/约束变动**:改变某行为体的能力(防空补给)、动机(国内政治压力)或约束(盟友态度)。
3. **下一节点预期变化**:影响 `next_nodes` 中关键节点的预期或日期。

**路径切换信号(必触发重新判定):**

- 出现新协议或谈判会议确认 → 评估是否切 A。
- 任一主要方在窗口期外的确认军事行动 + 报复链 → 评估是否切 B。
- 已判 A 或 B 但出现持续 7+ 天"无新动作" → 评估是否切 C。

**不记录为边际变化:** 例行强硬表态、重复性媒体报道、未经证实的匿名情报、与前日无实质差异的外交辞令。

## 核心信号清单(每日扫描;构成 signal_watchlist 起点)

无论当前判定为哪条路径,下列信号每日扫描一次。它们是 watchboard `signal_watchlist` 的默认起点,你应随局势增删——这正是"关注点动态迁移"的落点:

1. 以色列防空 / 补给状态 —— 任何"补给完成"信号立即标注。
2. IAEA 关于伊朗核活动的任一更新 —— 直接影响 A 和 B。
3. 扫雷行动进展 / 伊朗反应 —— 持续摩擦点。
4. 真主党 / 胡塞 / PMF 行动密度 —— 代理人是路径切换的早期指示。
5. 特朗普 / 内塔尼亚胡 / 哈梅内伊任一公开表态的口径变化 —— 高权重信号。
6. Brent / LNG / 保险费率 —— 市场是否按当前路径定价。
7. 第三方调解信号(卡塔尔 / 巴基斯坦 / 阿曼 / 中国)—— 路径 A 触发器。

## 风险资产传导(锚点,详见 economic_impact_framework.md)

- **路径定价器**:Brent、LNG 现货/期货价差、波斯湾航运保险费率、Murban-Brent 价差。
- **避险定价器**:黄金、瑞郎、美债收益率(注意通胀 vs 避险的方向分歧)。
- **市场判定纪律**:当价格定价与判定路径不一致时,先检查市场是否提前定价某种路径切换,再修正自己的判定。
- 风险资产宏观行情(Brent / 黄金 / 天然气 / USD-CNH / 美债 / BTC / 纳指期货)可通过 `scripts/macro_monitor.py market` 取数,与 evidence packet 合并作为证据;不给交易建议。

## 证据处理流程

1. **事件聚类**:军事行动、外交/调解、核活动、霍尔木兹/航运、能源设施、代理人网络、市场价格、制裁与政策。
2. **可信度分层**:官方/国家级媒体/多源确认优先;单方声明、社媒传言、匿名消息必须降级。
3. **时效筛选**:默认关注过去 18 小时;日报开头标明更新时间和证据窗口。
4. **相似快讯合并**:同一事件只写一条脉络,保留最早时间、最新进展、来源数量和关键差异。
5. **事实与判断分离**:合规层事实、市场定价、推演分别表述。

## 可信度标记

- `✅`:多方独立确认或官方确认。
- `〇`:单一可信来源。
- `△`:单方声明或未经证实。
- `✗`:已被否认或明显存疑。

特别约定:扫雷行动以 CENTCOM 官方公告为准;伊朗对扫雷的反应,伊朗单方声明默认 △;以色列对伊军事行动表态须区分以官方政府发言和"知情来源"两档。

## 降级策略(当日伊朗证据不足时)

- 明确写"今日证据不足以支持烈度或路径判定调整"。
- 仍可输出观察清单和下一节点,但不强行给高置信推演。
- **沿用上一期 watchboard 的 `path` 与 `probabilities`**,除非出现上面定义的"路径切换信号"。
- 上一期所有 open 跟踪项仍要逐条处理(至少标注"今日无新进展,顺延"),不许漏。
