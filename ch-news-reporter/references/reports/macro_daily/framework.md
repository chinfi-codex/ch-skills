# macro_daily 分析框架 · v1 流动性锚

> 本文件是 macro_daily **分析框架的唯一可信源**。框架契约——frame 维度、regime 失效触发器、输出板块、流动性观测维度与位置分档——都收敛在这里。
> 跨框架不变的方法论常量（结论约束、月度数据规则、不给交易指令等研究语言）见同目录 `methodology.md`；状态机制见 `../watchboard.md`。
> **变更框架只改这一个文件。** 当 regime 质变（如盈利而非流动性成为权益日频主驱动、或进入系统性去杠杆危机模式）时，由慢思考层生成新版本框架整体替换，经人确认后切换。

## 机器区 — 脚本只解析下面这一个 yaml 块

```yaml
# frame schema：严格等同迁移前 report_profiles.yaml 的 state_schema。
frame:
  swing_factor:         {required: true}                                   # 当下流动性主驱动维度
  liquidity_bias:       {enum: [收紧, 边际收紧, 中性, 边际宽松, 宽松]}      # 上次给出的流动性边际方向
  position_regime:      {type: map}                                        # {纳指: 高/中/低, 上证: 高/中/低}
  imminent_data_events: {type: list}                                       # 临近的 CPI/PPI/社融/PMI/非农/FOMC 带日期

# regime 失效触发器：慢思考层检测命中即评估"框架换代"
invalidation_triggers:
  - 盈利（而非估值/流动性）成为权益日频主驱动（盈利衰退或盈利爆发主导定价）→ "流动性锚"范式失效，换代
  - 流动性传导失灵（信用冻结 / 政策工具失效 / 利率与权益脱钩）→ 框架重定义
  - 市场进入非流动性驱动的系统性去杠杆危机模式 → 换代评估

output_sections: [一句话结论, 流动性总图, 市场相对位置, 今日3个关键边际信号, 流动性传导推断, 宏观新闻与数据事件, 中国政策与流动性, 美国政策与流动性, 反向场景与风险, 后续观察, 本期变更]
```

## 模型区 — 本框架的领域判定逻辑与写作要点

### 范式与第一性原理

把当日宏观数据、政策表态与市场价格转化为对**权益估值的流动性影响判断**：

```
流动性条件 → 折现率 / 风险溢价 → 权益估值锚 → 市场相对位置 → 边际方向信号
```

日频下盈利变化不大，**估值是最该跟踪的变量**，而估值核心驱动是流动性（折现率/长端利率、风险溢价/资金风险偏好、货币条件/资金可得性）。因此每天先答"流动性边际方向"，再答"市场已经定价了多少"，最后答"两者之间还有多少空间"。脚本只取数与算确定性指标（52 周高低、距高比例、YTD、20 日均线）；松紧、定价是否充分、位置高低、边际是否构成新信号由 Agent 判断。

### frame 字段填写约定

- **`swing_factor`**：当下流动性主驱动维度（利率 / 汇率 / 政策预期 / 风险偏好），今天最值得盯的那一维。
- **`liquidity_bias`**：流动性边际方向（收紧 / 边际收紧 / 中性 / 边际宽松 / 宽松）。
- **`position_regime`**：`{纳指: 高/中/低, 上证: 高/中/低}`，市场位置档位。
- **`imminent_data_events`**：临近的 CPI/PPI/社融/PMI/非农/FOMC 带日期事件，作为跟踪项进台账。

### 流动性观测三维度

1. **美元体系**（决定纳指/美股/黄金/BTC/新兴市场）：折现率端 US10Y/US5Y（当日 ≥ 5bp 即重要）；政策预期端（联储表态、利率期货隐含路径、"年内剩余降息次数"边际）；美元端 DXY（上行=全球美元紧=非美承压）；数量端（BTFP/TGA/ON RRP/缩表）；风险偏好端（VIX/高收益债利差/BTC/黄金）。
2. **人民币体系**（决定上证/港股/A 股）：政策端（MLF/逆回购、降准降息预期、PSL）；价格端（USDCNH 反向反映外部美元压力、DR007/SHIBOR）；数量端（社融、M2 同比、专项债节奏）；政策表态（财政部/人行/政治局/国常会措辞）。
3. **跨市场风险偏好**（信号验证）：DXY↑+美债↑→新兴流动性紧→上证/港股承压；DXY↓+美债↓→全球宽→纳指+新兴成长共振；VIX 跳升+黄金强→避险驱动；商品上行要分清供给冲击 vs 需求复苏 vs 通胀避险。

### 市场相对位置（估值锚）

每日固定对照两个核心估值锚（取数后必须为每个核心指数打位置标签）：

| 标的 | 取数 | 关键指标 |
|---|---|---|
| 纳斯达克综合（^IXIC） | Yahoo | 收盘、距 52 周高 %、YTD、20 日均线 |
| 上证指数（000001.SS） | Yahoo | 同上 |
| 纳指期货（NQ） | Stooq | 隔夜变动（反映亚洲时段美股预期） |
| VIX（^VIX） | Yahoo | 当前值、与 20 日均值偏离 |

**位置分档**：高位（距 52 周高 < 5%）→ 边际利空放大、利多钝化；中位（5–15%）→ 完全跟随流动性边际；低位（> 15%）→ 边际利好弹性大、利空被吸收。**位置 × 边际信号的矩阵是日报最关键的结论生产线。**

### 边际变化识别（每日必跑排查表）

按序逐条排查；**没有边际变化的指标不要凑数填进结论**：① 政策预期边际（联储/央行鸽鹰转向、利率期货路径变化）；② 利率边际（US10Y/US5Y ≥ 5bp、曲线斜率、中美利差）；③ 汇率边际（DXY、USDCNH ≥ 0.3%）；④ 风险偏好边际（VIX ≥ 10%、BTC ±3%、黄金 ±1%）；⑤ 大宗边际（Brent ±2%、天然气 ±3%、库存 surprise）；⑥ 数据 surprise（实际 vs 预期偏离）。

### 信号分析三步法

每个重要信号都走一遍：① **属性归类**（哪个流动性维度、偏紧偏松）；② **市场定价校验**（资产价格是否已反映、是否互相一致）；③ **位置约束**（当前高/中/低位下被放大还是吸收、是否触发反转风险）。

### 各输出板块写作要点

- **一句话结论**：2-3 句覆盖流动性边际方向+主驱动维度、市场相对位置、流动性×位置对权益估值的影响方向。
- **流动性总图**：维度×指标×数值×边际×信号方向表，无变化行折叠为"无明显变化"。
- **市场相对位置**：估值锚表 + 位置×流动性一句话评估（放大/吸收/反向修正及理由）。
- **今日 3 个关键边际信号**：按重要性排序，每条必须三步法。
- **流动性传导推断 / 中国·美国政策与流动性**：分体系写折现率/汇率/风险偏好的传导；月度数据规则见 `methodology.md`，无更新明确写"无新增月度数据事件"。
- **反向场景与风险**：流动性与位置矛盾时的反向风险点、哪些后续证据会推翻今日判断。
- **后续观察**：即本期 watchboard 投影（`imminent_data_events` 的 open 项 + 关键价格位）。
- **本期变更**：渲染约定见 `../watchboard.md`。

### 冷启动

首次无上一期时，按当日流动性三维度直接构造第一份 watchboard（`swing_factor` / `liquidity_bias` / `position_regime` 用今天证据现判，`imminent_data_events` 填临近带日期事件）。
