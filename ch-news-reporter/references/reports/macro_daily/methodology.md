# 每日宏观日报方法论

## 目标

把当日宏观数据、政策表态与市场价格转化为对**权益估值的流动性影响判断**。范式：

```
流动性条件 → 折现率 / 风险溢价 → 权益估值锚 → 市场相对位置 → 边际方向信号
```

脚本只负责取数与计算确定性指标（52 周高低、距高比例、YTD、20 日均线）；判断流动性松紧、定价是否充分、当前位置高低、边际是否构成新信号——必须由 Agent 完成。

## 第一性原理：为什么以流动性为锚

权益市值 = 盈利 × 估值。日报频率下盈利变化不大，**估值是日报里最该跟踪的变量**，而估值的核心驱动是流动性：

- 折现率（长端利率）→ 直接决定远期现金流现值
- 风险溢价（资金风险偏好）→ 决定愿意付的估值倍数
- 货币条件（资金可得性）→ 决定能买进多少风险资产

因此：**每天先回答"流动性边际方向"，再回答"市场已经定价了多少"，最后回答"两者之间还有多少空间"**。

## 流动性观测三维度

### 1. 美元体系流动性（决定纳指 / 美股 / 黄金 / BTC / 新兴市场）

- **折现率端**：US10Y（长端折现率）、US5Y（中期）；当日变动 ≥ 5bp 即重要信号
- **政策预期端**：美联储官员表态、利率期货隐含路径（电报）；2024-2026 关键观察"年内剩余降息次数"的边际变化
- **美元端**：DXY 美元指数。DXY 上行 = 全球美元紧 = 非美资产承压，新兴市场尤甚
- **数量端**：BTFP、TGA 余额、ON RRP 变化、缩表节奏（金十/RSS 电报关注）
- **风险偏好端**：VIX（隐含波动率）、高收益债利差、BTC、黄金

### 2. 人民币体系流动性（决定上证 / 港股 / A 股权益）

- **政策端**：央行 MLF / 逆回购操作、降准降息预期、PSL；电报关注"逆回购净投放/净回笼"
- **价格端**：USDCNH（汇率，反向反映外部美元压力）；DR007、SHIBOR 短端利率
- **数量端**：社融、M2 同比（月度数据事件触发）；地方专项债发行节奏
- **政策表态**：财政部、人行、政治局、国常会等关键会议措辞变化

### 3. 跨市场风险偏好（信号验证）

- DXY ↑ + 美债 ↑ → 新兴市场流动性紧 → 上证 / 港股估值承压
- DXY ↓ + 美债 ↓ → 全球流动性宽 → 纳指 + 新兴成长股共振
- VIX 跳升 + 黄金强 → 避险驱动；BTC 弱 + 黄金强 → 风险资产整体退潮
- 商品上行原因要分清：供给冲击（地缘、库存）vs 需求复苏 vs 通胀避险

## 市场相对位置（估值锚定）

判断"流动性松紧的影响"必须与**市场已经定价了什么**对照。每日固定关注两个核心估值锚：

| 标的 | 取数 | 关键指标 | 解读 |
|---|---|---|---|
| 纳斯达克综合（^IXIC） | Yahoo | 收盘、距 52 周高 %、YTD、20 日均线 | 高估值科技定价基准 |
| 上证指数（000001.SS） | Yahoo | 同上 | A 股整体估值锚 |
| 纳指期货（NQ） | Stooq | 隔夜变动 | 反映亚洲时段美股预期 |
| VIX（^VIX） | Yahoo | 当前值、与 20 日均值偏离 | 流动性恐慌代理 |

### 位置分档（必须为每个核心指数打标签）

- **高位（距 52 周高 < 5%）**：市场已定价乐观流动性 → 边际利空放大、边际利多钝化
- **中位（距 52 周高 5–15%）**：方向待定 → 完全跟随流动性边际
- **低位（距 52 周高 > 15%）**：估值缓冲厚 → 边际利好弹性大、边际利空被吸收

位置 × 边际信号的矩阵是日报最关键的结论生产线。

## 边际变化识别（每日必跑的排查表）

按以下顺序逐条排查；**没有边际变化的指标不要凑数填进结论**。

1. **政策预期边际**：联储/央行官员表态明显鸽鹰转向、利率期货隐含路径变化
2. **利率边际**：US10Y / US5Y 当日 ≥ 5bp 变动、收益率曲线斜率变化、中美利差变化
3. **汇率边际**：DXY、USDCNH 当日 ≥ 0.3% 变动
4. **风险偏好边际**：VIX 跳升 ≥ 10%、BTC ± 3%、黄金 ± 1%
5. **大宗边际**：Brent ± 2%、天然气 ± 3%、库存数据 surprise
6. **数据 surprise**：实际值 vs 预期值偏离明显（电报通常会标）

## 信号分析三步法

每个被识别为重要的信号都要走一遍：

1. **属性归类**：流动性维度是哪个（利率/汇率/数量/偏好/政策预期）？方向偏紧 or 偏松？
2. **市场定价校验**：今天的资产价格（纳指/上证/美债/汇率/黄金）是否已经反映？反应是否互相一致？
3. **位置约束**：当前市场位置（高/中/低）下，这个信号会被放大还是吸收？是否触发反转风险？

## 月度数据规则（保留）

CPI、PPI、社融、PMI 只在 evidence packet 的 `macro_data_events` 当天触发时才使用 `conditional_data_fetches.china_monthly` 中的 Tushare 细项；没有事件时明确写"无新增月度数据事件"，不复述旧月度结论。

美国 CPI/PPI/PCE/非农/PMI/零售销售等首发优先引用金十电报里的实际值、预期值、前值，不补造官方明细。

## 结论约束

- 单日价格只是定价信号，不等同趋势确认；明确区分"信号"与"趋势"。
- 流动性判断必须落到**对权益的具体影响方向**（折现率上升压估值 / 美元紧压新兴 / 风险偏好回升支撑成长股 / 政策宽松对冲外部紧）。
- 流动性信号与市场位置矛盾时必须提示反向风险（如：流动性收紧 + 市场位于高位 = 估值压缩风险放大；流动性宽松 + 市场位于低位 = 反弹弹性高）。
- 多源单条快讯属中可信证据，关键结论说明是否还待官方原文或后续数据验证。
- 不给交易指令，使用"利率压力上升 / 缓和"、"流动性边际收紧 / 宽松"、"权益估值承压 / 受支撑"、"高位放大利空 / 低位吸收利空"等研究语言。
