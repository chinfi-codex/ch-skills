# 每日宏观日报方法论（方法论常量）

> 本文件只保留**跨框架不变的方法论常量**。当前 regime 的**分析框架**（流动性观测三维度、市场相对位置与位置分档、边际变化排查表、信号三步法、frame schema、输出板块）已收敛到同目录 `framework.md`（唯一可信源）；活动状态机制见 `../watchboard.md`。**每日报告先读 `framework.md`。**

## 目标

把当日宏观数据、政策表态与市场价格转化为对**权益估值的流动性影响判断**。脚本只负责取数与计算确定性指标（52 周高低、距高比例、YTD、20 日均线）；判断流动性松紧、定价是否充分、当前位置高低、边际是否构成新信号——必须由 Agent 完成。范式（流动性→折现率/风险溢价→估值锚→位置→边际方向）与流动性观测维度见 `framework.md`。

## 月度数据规则

CPI、PPI、社融、PMI 只在 evidence packet 的 `macro_data_events` 当天触发时才使用 `conditional_data_fetches.china_monthly` 中的 Tushare 细项；没有事件时明确写"无新增月度数据事件"，不复述旧月度结论。

美国 CPI/PPI/PCE/非农/PMI/零售销售等首发优先引用金十电报里的实际值、预期值、前值，不补造官方明细。

## 结论约束

- 单日价格只是定价信号，不等同趋势确认；明确区分"信号"与"趋势"。
- 流动性判断必须落到**对权益的具体影响方向**（折现率上升压估值 / 美元紧压新兴 / 风险偏好回升支撑成长股 / 政策宽松对冲外部紧）。
- 流动性信号与市场位置矛盾时必须提示反向风险（如：流动性收紧 + 市场位于高位 = 估值压缩风险放大；流动性宽松 + 市场位于低位 = 反弹弹性高）。
- 多源单条快讯属中可信证据，关键结论说明是否还待官方原文或后续数据验证。
- 不给交易指令，使用"利率压力上升/缓和""流动性边际收紧/宽松""权益估值承压/受支撑""高位放大利空/低位吸收利空"等研究语言。
