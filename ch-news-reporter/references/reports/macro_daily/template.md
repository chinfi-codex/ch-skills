## 一句话结论

2-3 句话，必须覆盖三个要素：
1. 今日**流动性边际方向**（明显收紧 / 边际收紧 / 中性 / 边际宽松 / 明显宽松），并指出最主要的驱动维度（利率 / 汇率 / 政策预期 / 风险偏好）。
2. **市场相对位置**对照（纳指与上证分别处于 52 周高低位的什么档位）。
3. 流动性 × 位置组合对**权益估值**的潜在影响方向（压估值 / 支撑估值 / 维持区间 / 高位放大风险 / 低位提供弹性）。

## 🔄 本期变更（框架 × 跟踪合并）

> 放报告末尾：先写完事实与推演，最后回填本期 watchboard 的变更。对照 `Prior Watchboard`，无上一期写"冷启动，本期建立初始 watchboard"。本段是 watchboard 结构化字段的渲染——框架移动取自 `frame_change`，跟踪项动作取自各项 `update`（顺延）/ `resolution`（结算）；**先填字段、再照着渲染本段，别两头写出不一致**。

把本期相对上一期的变化**合并成一段**，框架与跟踪混编、按重要性排序，逐条 bullet：

- **框架**（动了才写，未动写"主线 / 偏向 / 档位沿用，N 项顺延"）：`swing_factor` 主线维度是否切换、`liquidity_bias` 沿用/调整（带价格证据）、`position_regime` 纳指/上证档位变化、`imminent_data_events` 到期结算/新临近补入——每条紧跟"为什么"（← `frame_change`）。
- **跟踪项结算**（上一期每个 open 项必须出现，不许遗漏）：`#T-xxx → ✅兑现 / ❌证伪 / ⏸️顺延 / ⌛过期`：实际值 vs 预期，验证还是推翻昨天的判断（← `update` / `resolution`）。
- **新开**：`#T-xxx [新临近数据事件 / 摆动项] —— 因为 [事件临近 / 出现某证据]`。
