# 简版 · 每日宏观日报模板（正文 ≤600 字）

> **何时用**：用户要“简版 / 精简 / 速览 / 短版 / 600 字以内”的宏观日报。完整骨架见同目录 `template.md`。
> **字数纪律**：正文控制在 600 字以内（标题行、更新时间行、免责声明不计）。砍掉流动性总图大表、市场位置表、信号三步法逐段、传导分三体系铺开——全部压成要点。
> **不破的底线**（见 `methodology.md`）：一句话结论三要素必给（流动性边际方向 + 主驱动维度；纳指 / 上证位置档位；流动性 × 位置对权益估值的影响方向）；信号 vs 趋势要分；流动性方向与市场位置矛盾时提示反向风险；月度数据无更新明确写“无新增月度数据事件”，不复述旧结论；不给交易指令，用研究语言。
> **watchboard 照常**：仍读 `Prior Watchboard`、在内部逐条结算 open 项、第 6 步用 `save_report_state.py` 回写今天的 watchboard；正文一句话带过。
> **文件名**：`reports/macro_daily_<date>_brief.md`。

# 每日宏观速报 | YYYY-MM-DD

**一句话结论**（2-3 句，必含三要素）：① 今日流动性边际方向（明显收紧 / 边际收紧 / 中性 / 边际宽松 / 明显宽松）+ 主驱动维度（利率 / 汇率 / 政策预期 / 风险偏好）；② 纳指、上证各处 52 周高低的什么档位；③ 流动性 × 位置对权益估值的影响方向（压估值 / 支撑估值 / 维持区间 / 高位放大风险 / 低位提供弹性）。

**月度数据**：[CPI / PPI / 社融 / PMI 有更新则列实际值 / 前值；无则写“无新增月度数据事件”]
