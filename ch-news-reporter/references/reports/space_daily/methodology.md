# 商业航天日报方法论（方法论常量）

> 本文件只保留**跨框架不变的方法论常量**。具体分析框架（四条主线、国内/海外分工、frame schema、输出板块）收敛在同目录 `framework.md`（唯一可信源）；活动状态机制见 `../watchboard.md`；检索关键词与噪音排除词见 `config/report_profiles.yaml` 的 `space_daily`。**每日报告先读 `framework.md`。**

## 目标

跟踪全球商业航天产业的**实际进度**，不写发射流水账。每条事件都要接回四条主线之一（发射与运力 / 卫星与载荷 / 订单披露 / 产业融资），并说清它改变了谁的相对位置。

这份报告的成品形态是**汇报简报**：只放主体信息，读者是 CEO 与董事长背景的人。给前者看工程事实的准度，给后者看资本含义的落点——一条信息只写一次，把两层含义在同一段里说完整。

## 数据信息分层

每条证据进报告前先归层，写法不同：

- **确认事实**：官方口径或多源一致、时间可追溯。可以写进结论。
- **信号**：可观察的变化——试车、转运、中标公告、融资轮次、产能节点。单源也可登记，但必须标可信度，措辞留余地。
- **推断**：基于证据链的判断。必须写明不确定性和可能反例，不许伪装成事实。

传闻、匿名源、社媒截图、二手转述一律降级：只能作线索登记，不作结论依据，并在文中显式标注"未经证实"。国内一级市场消息多为转述，金额与估值要写明信息来源和是否经公司确认——**"未披露"不等于"没有"**，不要把拒绝披露写成没有融资。

## 信源特性与权重

证据包按信源组织，两个源的性质差别极大，读的时候要分开看：

- **rss（10 个 `category: space` 源）**：海外线主干，覆盖发射、卫星、政策。SpaceNews / Payload 偏产业与资本，NASASpaceflight / Spaceflight Now 偏工程细节，SpacePolicyOnline 偏政策与频轨。英文源报道国内公司时只用英文名（NASASpaceflight 单日 LandSpace 能命中十几次），中文关键词命中不到，所以海外源的国内线索要靠英文公司名与型号名认人。
- **jin10（金十电报，按 `item_keywords` 过滤）**：国内线几乎唯一的实时来源——民营火箭的试车、转运、出厂评审、会议出席，官方 RSS 一个都没有，全靠金十转述。代价是它常写"某试验场""某任务"，地点与主体含糊，转述时保留原话并标"原文未披露"，**不要替它补全**。

**Space.com 与 NASA Breaking News 要当低信噪比源看**。这两个是面向大众读者的科普站，产业稿件和消费内容混在同一条 feed 里。2026-09-01 实测：当天 12 条航天条目中，游戏评测、天文每日一图、读者竞猜、业余天文摄影占了近一半。脚本已用 `item_exclude_keywords` 挡掉其中确定无价值的部分（APOD / Puzzler / sci-fi / 占星 / 流星雨等），但挡不干净——下面这几类要靠你读的时候自己剔除：

- 业余天文摄影与观测攻略（"How I captured…""What's next for…"这类读者向长文）。
- 纯科普与天体物理发现，除非它牵出一条产业动作（新望远镜立项带出的载荷订单才算）。
- 政府载人航天任务的花絮性报道（太空行走直播、乘组返回欢迎仪式等）——除非涉及商业载人或商业货运合同，否则不进商业航天日报。

SpaceNews / Payload / Spaceflight Now / NASASpaceflight / SpacePolicyOnline 这五个是产业源，噪音率低，命中即可信；来自它们之外的条目，进正文前先问一句"这条跟商业航天产业链有没有关系"。

两个源的覆盖是互补关系，不是冗余：**海外缺了只剩国内自说自话，国内缺了就退回外文转述**。某源缺数时，就地写在被影响的那条判断旁边，说明缺的是哪一侧、判断因此降到什么强度，不要用另一侧的内容量掩盖。

## 输出判断边界

- 可以说"谁先跑通谁就多一张牌""这笔订单把交付节奏推到了明年"，不直接说"必然拿到后续批次""估值必然上修"。
- 涉及上市公司或资产价格时，只写影响路径与观察点，**不给买卖建议、目标价与仓位**。
- **估值必须同时报口径**：一级市场增资估值与 IPO 发行隐含估值不可直接比较（同一家公司两个口径差 3-5 倍是常态），混着说就是错的。IPO 隐含估值按"拟募资额 ÷ 发行比例"倒算，引用时标明。
- 行业总量的各家统计口径差异很大（同一个 2026H1：澎湃 89 起 / 151.3 亿，投中网 79 笔 / 127.9 亿，未来天玑 102 起 / 177.1 亿），引用时说明用的是哪一家。
- 中美两条产业线分开记，不要用一边的节奏去推断另一边。
- 当天没有够格的增量就直接写"今日无实质增量"然后结束，不要拿旧闻换个说法重发。

## 简报纪律：不留歧义

这是这份报告最硬的一条。简报是拿去做决定的，任何一处含糊都会让读者停下来猜。

- **判断要给死，不骑墙。** "可能""或将""有望""预计""据悉""相关方面""一定程度上"这类词一律不用。有判断就写判断，没把握就写清楚没把握到什么程度。
- **不确定要写成可核验的事实，而不是模糊措辞。** 写"仅界面新闻一家报道，公司未确认"，不要写"据悉"。写"金额未披露"，不要写"金额较大"。
- **时间写绝对日期**，不写"近日""日前""近期"。原文只说"近期"时，照实写"原文称近期，未给具体日期"。
- **数字带口径和单位**，不写"大额融资""估值大幅提升"。
- **主体写全称到不会认错的程度**，不写"某公司""相关企业"；代词不跨段指代。
- **状态词用准的那一个。** 已受理 / 已问询 / 辅导备案 / 已递表 / 静力试验 / 出厂评审 / 首飞 / 复用回收各是各的意思，不能混用，也不能笼统写成"IPO 有进展""试验成功"。

## 文风常量（讲人话）

与项目级 `report-tone` 一致：像跟懂行的同行当面把一件事讲清楚，句子通顺、有因果、把话说透。

- **每条按"事实 → 工程含义 → 资本含义"想清楚，再写成连贯的话**，不要贴"事实:""含义:"这种标签。
- **同维度多条目一律 list**：一条一项，每条写完整通顺的话，别退化成"公司 - 轮次 - 金额"的横杠拼接。
- **结构化对照才用表格**：只有「融资与 IPO 进度变化表」这类多家横向对照才上表格；叙述性判断用 list。
- **跨界词各解释一次**：技术词第一次出现给一句不超过 15 字的白话注解（如"星间激光 = 卫星之间不落地直接传数据"）；资本运作的词（老股转让、Pre-IPO、特别表决权、对赌、募投项目、递表）同样一句话点破。后面再出现不重复。

## 反例（常见错误，看到要改）

- 罗列今天的发射记录当流水账——不接回四条主线、不说清改变了谁的位置的，不写。
- 把 SpaceX 的 AI 侧新闻（Grok、AI 编程、持仓披露）写进航天日报——合并后同名新闻极多，只有涉及发射、星链、星舰、订单、产能的才算本主题增量。
- 把地外探索与空间站（探月、火星、载人登月、ISS、天宫）单独成节——只有它直接改变某家公司的发射订单、运力占用或产能时，才作为发射与运力那条主线的证据带一句。
- 低空经济、eVTOL、民航客机、纯天文科普写进来——除非与航天主体直接相关（可重复使用飞行器、空天飞机、卫星应用落地场景）。
- 用"某公司""近期""重要进展""有望提升商业价值"这类含糊词糊弄——四句话没有一个可核验的事实。
- 一条工程事实推不出任何资本含义，却单独占一段。
- 另立「24-72h 观察点」小节——前瞻节点如果对判断实质重要，就当事实的一部分写进对应主线的正文。
- 每天重贴一张静态的融资进度表——只在当天有轮次、估值、受理/问询/递表状态变化时才出。
- 表格和正文说同样的话——正文讲清来龙去脉和它意味着什么，表只做多家横向对照；当天只有一两家有变化时直接并进正文、不出表。
