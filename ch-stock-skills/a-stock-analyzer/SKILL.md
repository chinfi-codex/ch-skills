# A股基本面投研分析助手

把这个技能当作股票基本面投研方法论使用。不要依赖脚本生成报告、提示词、投资结论、组合分析或推荐。脚本只能取数；你作为智能体负责解释数据、判断重点，并直接写出最终内容。

---

## 一、总原则

- 所有内容逻辑都放在本 `SKILL.md` 中：分析路径、判断标准、报告结构、措辞边界。
- 只使用 `scripts/data_fetcher.py` 获取单一数据集，或解析股票名称/代码。
- 脚本输出只是证据，结论必须由你基于证据推理得出。
- **A股估值的核心哲学**：A股是高度叙事驱动的市场。一只股票是否处于当前市场主线内，会显著影响其估值定价方式。这一判断是定量分析中无法回避的关键变量，详见第 5.5 节。估值之前必须先对公司分型（成长股/成熟龙头/红利价值），不同类型适用不同估值模式，详见第 5.1 节。

### 2.1 数据维度说明

| 维度 | dataset | 用途 |
|---|---|---|
| 股票识别 | `search` | 名称/代码解析，确认 `ts_code`、地区、行业、市场、上市日期和板块 |
| 公司画像 | `company` | 公司简介、行业、注册地、主营概况 |
| 财务指标 | `financial` | ROE、毛利率、净利率、成长、偿债、周转等财务指标 |
| 三大报表 | `income`、`balance`、`cashflow` | 利润表、资产负债表、现金流量表，用于增长质量、利润质量和财务健康验证 |
| 行情估值 | `daily`、`daily-basic` | 日线、换手率、PE/PB/PS、股息率、市值、股本结构 |
| 历史估值分位 | `valuation-band` | 从多年 `daily_basic` 确定性计算 PE/PB/PS/股息率的近 1/3/5 年区间与当前分位（PE band）。Tushare 无现成分位接口，由脚本计算 |
| 主营结构 | `main-business-product`、`main-business-region` | 产品和地区收入/利润结构，判断业务驱动和集中风险 |
| 股东治理 | `top10-holders`、`managers`、`rewards` | 十大股东、董监高、管理层薪酬和持股 |
| 筹码变化 | `holder-number`、`holder-trade` | 股东户数、重要股东增减持 |
| 交易与供给压力 | `share-float`、`block-trade` | 限售股解禁、大宗交易 |
| 年报季报 | `report-list`、`report-raw`、`report-text` | 巨潮定期报告列表、PDF 下载、PDF 文本抽取 |
| 个股公告 | `announcements`、`announcement-raw`、`announcement-text` | 仅按个股查询巨潮公告，按标题规则标记问询回复、监管函、回购、减持、股权激励、定增、重大合作、业绩快报等 |
| 机构调研 | `institutional-research` | Tushare `stk_surv`，用于观察调研频率、参与机构、接待方式和调研内容关键词 |
| 上下文包 | `pack` | 单股完整 evidence、轻量 `analysis_context` 和模块级 JSON，供 subagent 或低上下文顺序分析 |

### 2.2 公告查询边界

- `announcements` 只支持按个股查询。不要用本 skill 做全市场公告扫描。
- 标题规则只负责定位事件类型，不负责判断影响大小。
- `tabtype=fulltext` 用于公告全文列表；`tabtype=relation` 仅作为互动易/调研相关列表的辅助入口。
- PDF 原文读取使用本 skill 内置下载与 `PyPDF2` 文本抽取，不跨 skill 引用。

### 2.3 把研报渲染成 HTML（可选）

写完 Markdown 研报后，可用 `render_report_html.py` 渲染成自包含的单页 HTML（Claude UI 风格），并自动从 evidence 里嵌入两类图表：**PE/PB/PS 估值带时间序列**（`valuation-band` 的 `series` + 历史分位带，横轴日期、纵轴估值倍数，叠加 P25–P75 带与当前分位）、营收/归母净利/同比增速/盈利能力**财务趋势**（`income`+`financial`）。

```bash
python scripts/render_report_html.py -i reports/report_600519.md --evidence reports/evidence_600519.json
# 不传 --evidence 时，会自动找同目录的 evidence_<代码>.json；找不到则只渲染正文、不嵌图表
```

**内容与输出格式解耦（重要）**：HTML 渲染器对正文是"只读装饰"——它不改写任何文字，只把 Markdown 转成 HTML，并在客户端用 JS 注入图表与 hero 卡片。因此写研报时**不需要为 HTML 迁就措辞或结构**：

- 图表锚点是"尽力而为"。找不到对应小标题（如「估值快照与历史分位」「成长性与财务质量诊断」「核心判断」）时，对应图表**静默跳过**，不报错。
- evidence 缺某个数据集时，对应图表自动不画，正文照常输出。
- 文本保全校验默认**只告警不中断**（`--no-validate` 完全跳过，`--strict` 才在不一致时报错），正文内容怎么改都不会导致 HTML 生成失败。
- 沿用模板（第八节）里的小标题命名能让图表落到最合适的位置；即使大改结构，最坏情况也只是少几张图，正文与样式不受影响。

## 三、工作流程

### 收集证据

- 只获取完成任务所需的最小数据集。
- 财务趋势优先取最近 6-8 个报告期，覆盖至少 2 个完整财年。
- 如果任务是完整单股研究，优先运行 `pack`，再按模块级 JSON 分析，避免一次加载完整 evidence。
- 主线归属判断需要联网检索近期市场动态，不要依赖训练记忆。
- 数据缺失时要明确说明缺口，并降低结论置信度，不要补造数据。

### 原文升级规则

默认先看公告/报告元数据。只有出现以下情况，才升级读取 PDF 原文：

- 用户明确要求“看原文”“读公告”“解释公告”“公告具体说了什么”。
- 标题命中监管函、问询回复、重大合作/投资、股权激励、定增、员工持股、回购、增持、减持、业绩快报。
- 财务指标出现异常，需要查定期报告里的管理层解释、会计政策、业务拆分、风险提示。
- 仅凭标题无法判断事件性质，例如“签署协议”需要确认金额、约束力、履约条件和收入确认节奏。

需要原文时：

1. 先用 `announcements` 或 `report-list` 定位候选。
2. 按标题相关性、披露时间、是否全文公告选择 1-3 篇。
3. 用 `announcement-text` 或 `report-text` 读取 PDF 文本。
4. 输出时明确区分“原文事实”和“模型推断”，不得只凭标题判断影响。

### Subagent 编排与上下文管理

使用 `pack` 后，主 agent 得到三类产物：

- 完整 `evidence`：归档证据，不直接整体塞进模型上下文。
- 轻量 `analysis_context`：单会话分析时优先加载。
- `module_contexts/`：供 subagent 分模块撰写。

**分发前先定初步分型**：主 agent 在拆分 subagent 之前，先用增速、股息率、行业地位、主线做一次初步分型（4.1），并把"该公司初步判定为 X 型"写进每个 subagent 的指令——这样模块 1（定性侧重）和模块 2（估值模式）才能在同一透镜下展开，而不是各自默认成长股口径。

有 subagent 编排能力时，每个 subagent 只读取自己的模块 JSON 和本 `SKILL.md` 对应方法论：

| 模块 | JSON | 任务 |
|---|---|---|
| 1 | `module1_growth_financial.json` | 成长性、财务质量、业务结构 |
| 2 | `module2_valuation_market.json` | 估值快照、隐含预期、市场定价 |
| 3 | `module3_governance.json` | 股东结构、管理层、筹码、解禁、大宗交易 |
| 4 | `module4_announcements.json` | 公告事件筛查、原文升级候选、定期报告候选 |
| 5 | `module5_research_mainline.json` | 机构调研、主线连接线索、市场关注度 |

没有 subagent 能力时，按同样模块顺序逐段加载模块 JSON。聚合阶段只读取模块结论、`analysis_context`、必要的公告/报告原文摘录。

### 分析与判断

先按 4.1 做初步分型，再按下文第四节（定性框架，重心随类型调整）和第五节（定量框架，估值模式随类型选择）的方法论展开分析。

### 写作输出

- 先给核心结论和置信度。
- 用取到的数据作为证据，给出具体数字和报告期。
- 显式说明关键假设（包括主线归属假设）。
- 避免单边结论，写出最强反方观点。
- 结尾写清风险和非投资建议声明。

## 四、定性分析框架：成长性判断与核心亮点

定性分析的核心任务是回答两个问题：**这家公司在成长吗？为什么值得关注？**

### 4.1 先做初步分型（定性与定量的共同透镜）

进入五维度诊断之前，先用增速、股息率、行业地位、主线归属做一次**初步分型**（成长股 / 成熟龙头 / 红利价值；三型的完整定义与对应估值模式见 5.1）。分型不是定量章节专属——它同时决定**本节定性分析的重心**：对不同类型，五维度里哪些是 first-class、哪些近乎无关，差异很大。分型是基于初步证据的**可推翻假设**，可在分析过程中回头修正（尤其类型切换期：成长股增速降档转成熟、成熟龙头被新主线重新点燃）。

| 类型 | 定性分析重心（本节哪些维度优先 + 额外要看什么） | 对应估值模式 |
|------|--------------------------------|------------|
| **成长股** | 重心在**维度一（收入增速质量：量 vs 价、公司 alpha vs 行业 beta）**与**维度四（业务结构与壁垒：远期空间 TAM、第二曲线、渗透率提升）**。额外看：赛道天花板、产品管线/产能投放节奏、主线持续性。**判断逻辑：增速能否兑现 > 当期利润高低**；自由现金流为负在重投入期可容忍。 | 5.3 隐含预期 + 5.4 三情景；PE band 仅作下行参考 |
| **成熟龙头** | 重心在**维度二（利润含金量与利润率稳定性）**、**维度五（ROE 可持续性与杜邦结构）**、**维度三（现金流）**。额外看：增速降档后是否仍有定价权与份额、护城河是否在维持、分红 + 回购等股东回报力度。**判断逻辑：看"稳"不看"快"**，增速从高速回落到中速本身不是利空，盈利能力松动才是。 | 5.2 PE/PB 历史分位带为核心 |
| **红利价值** | 重心在**维度三（现金流：自由现金流能否覆盖股息）**、**维度四（业务稳定性与永续经营属性）**、资产负债安全。维度一增速基本不作主线（低速可接受），维度五 ROE 看稳定性而非高低。额外看：派息率与连续派息历史、资本开支是否轻、行业是否夕阳。**判断逻辑：稳定与永续 > 成长**。 | 5.2 股息率分位 + 股息率/利差、DDM |

下面的五维度模型是**通用清单**，但要按上表的重心**分配权重**，不要对三类公司机械地等权打分。

### 4.2 成长性诊断：五维度模型

按照以下五个维度逐一评估，每个维度给出"强/中/弱/恶化"判断（权重按 4.1 分型调整）：

**维度一：收入增长的质量**
- 观察指标：近 4-8 个报告期的营业收入同比增速序列。
- 判断标准：
  - **强**：连续 3 期以上正增长且增速稳定或加速。
  - **中**：正增长但增速波动较大，或刚从负增长恢复。
  - **弱**：增速持续下滑或在低个位数徘徊。
  - **恶化**：出现负增长，尤其是连续 2 期以上。
- 深层追问：增长是来自量（市占率扩张、新客户）还是价（提价能力）？是行业 beta 还是公司 alpha？用 `main-business-product` 判断哪些产品线在驱动增长。

**维度二：利润增长的含金量**
- 观察指标：归母净利润增速、扣非净利润增速、毛利率和净利率的趋势。
- 判断标准：
  - 利润增速 ≥ 收入增速 → 经营杠杆释放或效率改善，含金量高。
  - 利润增速 < 收入增速 → 增收不增利，需追查成本端原因。
  - 扣非利润与归母利润严重背离 → 利润质量存疑，关注非经常性损益占比。
- 关键信号：毛利率连续 2 期以上下滑是成长性减弱的早期预警。

**维度三：现金流验证**
- 观察指标：经营活动现金流净额 vs 净利润；自由现金流（经营现金流 - 资本支出）。
- 判断标准：
  - 经营现金流/净利润 > 0.8（长期均值） → 利润可回收，成长有实质支撑。
  - 经营现金流/净利润持续 < 0.5 → 利润可能被应收/存货吞噬，成长虚实存疑。
  - 自由现金流持续为负但收入高增 → 可能处于重投入扩张期，需判断资本开支回报周期。
- 注意：对于重资产行业（基建、制造）和高速扩张期企业，短期自由现金流为负不一定是负面信号，需要结合 ROIC 和资本开支去向判断。

**维度四：业务结构与竞争壁垒**
- 数据来源：`company`（行业、简介）、`main-business-product`（产品结构）、联网检索（行业格局）。
- 判断要素：
  - **收入集中度**：单一产品/客户占比 > 50% 是集中风险，但也可能是细分领域龙头的表现。
  - **业务多元性**：多产品线且新产品贡献上升 → 第二增长曲线正在形成。
  - **竞争壁垒类型**：规模效应、品牌溢价、技术专利、客户切换成本、网络效应、牌照/准入。
  - **行业位置**：在行业中处于领导者/挑战者/跟随者的哪个位置？
- 注意：竞争壁垒和行业地位等外部判断，如果无法仅从财务数据得出，必须联网检索并引用来源。不要编造。

**维度五：再投资能力与ROE分解**
- 观察指标：ROE 序列、杜邦三因子拆解（净利率 × 总资产周转率 × 权益乘数）。
- 判断标准：
  - ROE > 15% 且稳定 → 优质企业特征。
  - ROE 上升由净利率驱动 → 最健康的路径。
  - ROE 上升由杠杆驱动（权益乘数上升） → 需关注债务风险。
  - ROE 下行但收入仍增 → 可能因大额资本开支稀释，需判断是否为合理扩张。
- 与成长的关系：可持续增长率 ≈ ROE × 留存收益比率。ROE 高且稳定的公司，内生成长能力更强。

### 4.3 成长阶段定位

综合五个维度的证据，将公司归入以下成长阶段之一。**成长阶段与 4.1 分型应当自洽**：高速/稳健成长期通常对应成长股，成熟稳定期对应成熟龙头或红利价值，下行/困境期则要重新审视分型是否成立。两者若矛盾（如判成长股却落在成熟稳定期），说明分型需要修正。

| 阶段 | 特征 | 典型财务画像 |
|------|------|------------|
| **高速成长期** | 收入增速 > 20%，利润增速更快，市场份额快速扩张 | 高收入增速、毛利率稳定或上升、自由现金流可能为负（重投入） |
| **稳健成长期** | 收入增速 10-20%，盈利能力稳定提升，竞争格局趋于稳定 | 收入利润同步增长、ROE 稳中有升、现金流改善 |
| **成熟稳定期** | 收入增速 < 10%，利润率稳定，强现金流生成能力 | 增速放缓但利润率高、自由现金流充沛、高分红/回购 |
| **增速放缓/拐点待察期** | 增速连续下台阶，盈利能力出现压力但尚未恶化 | 收入增速下滑、毛利率松动、ROE 下行但仍在合理区间 |
| **下行/困境期** | 收入负增长，利润大幅下滑或亏损，资产负债表承压 | 负增长、利润率大幅萎缩、现金流恶化、杠杆上升 |

### 4.4 核心亮点提炼："为什么要关注这只股票"

在成长诊断和阶段定位后，提炼 2-4 条核心亮点。**亮点要落在该类型的核心矛盾上**：成长股的亮点是成长动力与远期空间，成熟龙头的亮点是盈利稳定性与股东回报，红利价值的亮点是高且可持续的现金分红与永续属性。每条亮点必须有数据支撑：

- **亮点的来源**：成长动力（新产品/新市场/产能释放）、效率提升（利润率改善/费用率下降）、壁垒强化（市占率提升/客户黏性增加）、资本配置优化（资本开支收缩后现金流释放）、行业景气上行。
- **亮点的检验**：每条亮点都要问"反方怎么看？"如果反方观点同样有合理依据，将其写在亮点后面作为对冲。
- **措辞边界**：亮点是"值得关注的理由"，不是"买入推荐"。

## 五、定量分析框架：估值阶段与隐含预期

定量分析的核心任务是回答：**当前价格隐含了什么样的未来预期？这个预期合理吗？**

**但在回答之前，必须先做一步前置判断：这家公司属于哪种类型？** A 股最常见的估值错误不是算错数，而是**用错估值模式**——拿 PE band 去框一只逻辑还没兑现的成长股，或拿远期空间去给一只永续红利股讲故事。先分型，再选模式（5.1），然后才进入隐含预期（5.3）和阶段定位（5.6）。

### 5.1 公司分型与估值模式选择（估值的前置判断）

先把公司归入以下三型之一（可以是「主导型 + 次要属性」，但必须有一个主导判断）。分型依据来自第四节的成长诊断、`daily-basic` 的股息率与增速、以及 5.5 节的主线归属。**分型在 4.1 已先行做出，并决定了第四节定性分析的重心**；本节是同一分型在定量侧的延续——下表给出每型对应的估值模式。

| 类型 | 识别特征 | 看重什么 | 主估值模式 | PE/PB band 的作用 |
|------|---------|---------|-----------|------------------|
| **成长股** | 处在当前主线/风口（5.5 强连接），收入高增、有未被证实的远期预期，估值随叙事大幅跳变 | 未来增速 + 远期期权（行业空间 TAM × 渗透率 × 公司市占）+ 主线持续性 | 反向 DCF / 空间法（远期市值 = 远期净利 × 远期合理 PE） / PEG / 远期 PE | **弱**：历史样本短且估值随预期跳变，分位带只作「逻辑被证伪时会跌到哪」的下行参考，不作贵贱锚 |
| **成熟龙头** | 行业龙头但增速已降档、盈利可预测、竞争格局稳定（典型如宁德时代） | 盈利稳定性 + 增速台阶（从高增到中速）+ 股东回报（分红 + 回购占净利润比例） | **PE/PB 历史分位带（核心）** + 降档后的 PEG + 股东回报率 | **核心工具**：判断当前估值处于公司自身历史的便宜/中枢/贵区间 |
| **红利价值** | 业务稳定、现金流强、永续经营属性强、高派息、低增速 | 股息率水平 + 派息可持续性（派息率、自由现金流覆盖）+ 永续属性 + 资产负债安全 | **股息率 band / 股息率 vs 无风险利率利差 / DDM**；FCF yield 辅助 | 看 **`dv_ttm`（股息率）分位** 为主，PE/PB band 为辅——红利股贵贱由股息率而非 PE 决定 |

**分型与模式选择规则：**

- **成长股**：核心问题是「市场隐含的远期预期 vs 公司能兑现的空间」，走 5.3 隐含预期 + 5.4 三情景。PE band 在此**不能用来说"便宜"**——主线退潮时历史中枢会整体下移。band 的唯一价值是估计下行空间。
- **成熟龙头**：核心问题是「相对自身历史，现在贵还是便宜」。**这是 PE/PB 历史分位带最适用的类型**：当前 `pe_ttm`/`pb` 处于近 3-5 年的低分位（如 < 30%）且基本面未恶化，是估值修复线索；高分位（如 > 70%）需增速能支撑。同时核对股东回报（分红率、回购）是否构成估值底。
- **红利价值**：核心问题是「股息率是否够厚、能否永续」。主看 `dv_ttm` 的历史分位（高分位 = 相对自身便宜）和股息率与 10 年国债利率的利差。**警惕"高股息陷阱"**：股息率高若因股价下跌或一次性高分红，且派息率 > 100% 或自由现金流无法覆盖，则不可持续。

**分型本身的边界：**

- 分型是**可被推翻的假设**，要标注置信度。处于类型切换期的公司（成长股增速降档转成熟、成熟龙头被新主线重新点燃）最难判断，必须说明。
- 类型决定「历史中枢是否仍然有效」：增速降档的公司，过去高增长期的 PE 中枢已失效，band 要相应缩短窗口或明确弃用。

### 5.3 逆向推算隐含预期

通过当前市值逆向推算市场隐含的增长预期，再与公司实际能力对比：

**步骤 A：锚定当前盈利基线**
- 取最近 4 个季度的归母净利润（TTM）作为基线盈利。
- 如果最新一期利润有明显的非经常性因素，同时参考扣非净利润。

**步骤 B：从市值推算隐含增速**
- 当前 PE(TTM) 反映的是市场对未来盈利增长的定价。
- 下面的 PE→增速档位**只是粗略启发式**，必须用以下两点校准，不能机械套用：
  - **行业与利率环境**：利率下行、行业景气上行期，同样增速可接受更高 PE；反之收缩。
  - **ROE 锚定**：高 ROE（如 > 20%）公司天然支撑更高 PE/PB，低 ROE 公司同样 PE 隐含的预期更激进。同样 PE 30，ROE 25% 与 ROE 8% 的公司隐含预期天差地别。
  - PE < 15：市场隐含低增长或零增长预期（或低估）。
  - PE 15-25：市场隐含中等增长预期（约 10-20% 年化增速）。
  - PE 25-40：市场隐含高增长预期（约 20-35% 年化增速）。
  - PE > 40：市场隐含极高增长预期或处于特殊估值逻辑（赛道/主题/亏损转盈利）。
- 更精细的方法：用 PEG 思维，PE / 未来 2 年预期净利增速。PEG < 1 暗示增速未被充分定价；PEG > 2 暗示估值对增长过度乐观。**注意：本 skill 没有一致预期数据，"未来 2 年增速"是你基于历史趋势和业绩预告的假设，必须显式标注为假设而非市场共识。**

**步骤 C：与实际成长能力对比**
- 将步骤 B 推算的隐含增速，与第四节定性判断的实际成长能力对照：
  - **隐含预期 < 实际能力** → 市场可能低估了成长空间，或存在尚未被市场认知的利好。
  - **隐含预期 ≈ 实际能力** → 定价合理，上行空间取决于超预期。
  - **隐含预期 > 实际能力** → 市场可能过于乐观，或依赖尚未兑现的叙事（需要催化剂验证）。

**重要**：5.3 节得出的隐含预期判断必须用 5.5 节的主线归属做最终修正，否则容易系统性误判 A 股估值。

### 5.4 三情景估值框架

在隐含预期分析的基础上，构建三种情景：

**基准情景（Consensus）**
- 假设：当前盈利能力延续，收入按近 2 年平均增速增长，利润率维持稳定。
- 推算方式：基线盈利 × (1 + 平均增速)^2 = 两年后预期盈利 → 给予历史中位 PE → 得到情景市值。
- 与当前市值比较得出隐含回报。

**乐观情景（Bull）**
- 假设：增长加速（新产品放量/行业景气上行/市占率提升）、利润率改善。
- 说明什么条件触发这个情景，以及需要什么证据来验证。

**压力情景（Bear）**
- 假设：增长放缓或负增长（需求萎缩/竞争加剧/政策冲击）、利润率压缩、估值回落。
- 说明什么事件会导致这个情景。

每个情景输出格式：
```
情景名称 | 核心假设 | 预期盈利变化 | 合理PE区间 | 隐含市值 | 与当前偏离
```

### 5.5 主线归属判断（A股估值的关键调节变量）

**核心哲学：A股是高度叙事驱动的市场。一只股票如果处于当前市场主线内，估值往往会被资金提前给出——市场会把未来 1-3 年甚至更远的预期提前打入当前价格。如果脱离主线，估值就必须靠业绩实打实兑现才能扩张。这个判断不是锦上添花，而是定量分析中无法回避的关键修正项。**

忽略主线归属做估值判断，是 A 股研究最常见的系统性错误：要么把主线内合理的高估值误判为泡沫，要么对主线外的低估值机械地认为是机会。

#### 5.5.1 判断公司是否处于市场主线内

**第一步：识别当前市场主线是什么**

- 主线是阶段性的，必须结合**当前时点**判断。不同阶段主线不同——可能是 AI/算力，可能是高股息红利，可能是新能源/出海/创新药/国产替代/军工/低空经济等等。
- 主线的可观察特征：
  - 成交活跃度集中在该方向相关板块。
  - 机构调研频率上升、卖方研报密集出现。
  - 政策和产业催化频繁出现。
  - 媒体和投资者讨论高度集中。
- **绝对不要凭训练时的记忆判断当前主线**——主线随时间快速变化，必须通过近期市场观察和联网检索得出。如果检索不到清晰证据，明确说明"主线判断置信度低"。

**第二步：评估公司与主线的连接强度**

| 连接强度 | 特征 | 估值表现 |
|---------|------|---------|
| **强连接（核心标的）** | 主营业务直接受益于主线，是市场公认的代表性公司 | 估值显著膨胀，PE 50+、PEG 2+ 都可能被市场接受 |
| **弱连接（边缘受益）** | 业务有部分关联但非主导，配套或间接受益 | 阶段性溢价，主线降温即回落 |
| **无连接（脱离主线）** | 业务与当前主线无关，或在已经退潮的旧主线中 | 估值锚回到基本面本身，甚至可能因被资金抛弃而折价 |

**第三步：用资金和数据验证连接强度**

- 公募基金/北向资金持仓近期是否上升 → 主流资金是否在认可。**数据边界**：交易所自 2024 年起取消了个股层面北向持股的高频披露，只剩季度数据；公募持仓也仅季度披露。不要假装能拿到实时北向数据，更不要编造——拿不到时改用季度持仓 + 联网检索卖方观点。
- 卖方研报频率近期是否明显上升 → 市场共识是否在形成（需联网检索，本 skill 无研报数据）。
- 个股近期涨跌幅是否显著跑赢/跑输行业 → 资金偏好的差异（用 `daily` 自算个股区间涨跌，行业对比需联网或同业取数）。
- `institutional-research` 中调研频率、参与机构类型、问题关键词是否集中在当前主线 → 市场关注度和产业问题焦点。
- `announcements` 中是否有主线相关订单、合作、扩产、定增、股权激励等公司级催化 → 主线连接是否有公司披露支撑。
- 上述信号有助于校验你对主线归属的判断，避免凭主观印象误判。

#### 5.5.2 主线归属对估值判断的修正规则

把 5.3 节的隐含预期结论用以下规则修正：

| 主线归属 | 估值容忍度 | 对 5.3 节结论的修正方向 |
|---------|-----------|----------------------|
| **强连接（核心标的）** | 估值可适度膨胀。市场愿意提前定价 1-3 年甚至更长的预期。 | 5.3 判定"隐含预期 > 实际能力"时，**调降一档警示**——市场认可的高估值不必然是泡沫，是叙事溢价的体现。但要明确这个溢价的可持续性依赖主线本身。 |
| **弱连接（边缘受益）** | 估值可阶段性扩张但缺乏持续性。 | 估值溢价视为"可消失的奖励"，不应作为核心买入理由。如果 5.3 已显示估值偏高，警示级别保持。 |
| **无连接（脱离主线）** | 估值必须由业绩和现金流支撑。市场不给预期溢价，反而可能折价。 | 5.3 判定"隐含预期 < 实际能力"（看似低估）时，**追问是否长期就该如此**——脱离主线的公司，估值修复可能要等到业绩超预期或主线轮动到自己。**估值要谨慎，不要把脱离主线的低估当作机会**。 |

#### 5.5.3 主线判断本身的风险

- **主线轮换风险**：A股主线切换迅速。原核心标的会被快速杀估值，回归基本面定价。投资强连接标的实际是在押注主线的持续性。
- **伪主线风险**：短期热点不等于真主线。判断时要看持续度（一般至少持续数月、有产业/政策基本面支撑）和资金共识度，而非单日热度或自媒体噪音。
- **主线判断的主观性**：主线判断带有主观性。在结论中必须明确说明判断依据，并把"主线归属"作为一个**可被推翻的假设**而非事实陈述。
- **置信度标注**：每次主线归属判断都要标注置信度（高/中/低），并说明依据。

#### 5.5.4 写作要求

完整基本面研报中，主线归属判断必须作为估值章节的关键变量明确写出，不能跳过。措辞示例：

- "本股票当前与 [X 主线]（[简要说明为何是当前主线]）形成**强连接**，市场对其给予较高估值容忍度。当前 PE 看似偏高，但在主线内属于可接受的预期溢价。主线判断置信度：[高/中/低]，依据：[资金/研报/政策/产业事实]。"
- "本股票当前**不在市场主线内**，估值定价以现实业绩为锚。即使 PE 看似不高，也需要警惕长期'估值修复缺乏催化'的可能性。"
- "本股票与 [X 主线] 形成**弱连接**，主线热度上升时可能享受阶段性溢价，但不构成核心持有理由。"

### 5.6 估值阶段定位（结合主线归属修正后）

综合 5.3、5.4、5.5 的分析，将当前估值状态归入以下阶段之一。**注意：主线归属是这个表的关键修饰语**——同样的 PE 水平在主线内和主线外含义完全不同。

| 估值阶段 | 特征 | 投资者关注点 |
|---------|------|------------|
| **深度低估** | PE/PB 远低于历史均值和同业，市场隐含负增长，但基本面未实质恶化。**主线外此判断更可靠**（因为没有主线踩踏导致的虚假低估）。 | 关注预期差修复的催化剂；主线外标的需要更长的兑现周期 |
| **合理偏低** | 估值略低于中枢，隐含预期保守，成长性尚可。 | 适合关注超预期的可能性；如果主线轮动至此，可能形成戴维斯双击 |
| **合理定价** | 估值接近历史中枢，隐含预期与实际能力匹配。 | 上行靠业绩超预期或主线加持，下行靠估值回落或主线退潮 |
| **偏高/透支** | 估值高于历史中枢，隐含高增长预期。**主线内此判断要打折**（高估值是叙事溢价，不必然是泡沫）；**主线外此判断要加重**（缺乏催化的高估更危险）。 | 需要持续高增长兑现，否则有回调风险 |
| **极度乐观** | PE 极高或无法用盈利合理解释，依赖叙事和远期展望。 | 高波动、高风险，需要主线持续 + 强催化剂双重支撑 |

### 5.7 财务健康度交叉验证

财务健康度有两个用途：一是作为**定性的质量底座**（输出写进报告第一部分「成长性与财务质量诊断」），二是作为**估值的置信度调节**（异常项在「估值结论」里下调置信度，无论主线归属如何）。以下指标出现异常时需警惕：

**偿债安全**
- 资产负债率：> 70%（非金融行业）需警惕。
- 流动比率 < 1 且速动比率 < 0.5 → 短期偿债压力。
- 有息负债率持续上升 → 财务杠杆风险积累。

**利润质量验证**
- 经营现金流/净利润长期 < 0.7 → 利润回收能力弱。
- 应收账款增速 > 收入增速 → 可能存在激进确认收入。
- 存货增速 > 收入增速 → 可能面临去库存压力。
- 商誉/净资产 > 30% → 减值风险。

**资本效率**
- ROIC（如可得） vs WACC：ROIC > WACC 说明资本配置创造价值。
- 总资产周转率趋势：下降可能暗示资产利用效率降低或过度投资。

## 六、股东与治理分析

输出落位：报告第三部分「背景与风险」，作为背景与风险信号（管理层激励、大股东增减持对成长股/红利股判断有信息量的，可在定性里点一句）。

使用 `top10-holders`、`managers`、`rewards`、`holder-number`、`holder-trade`、`share-float`、`block-trade`。

### 6.1 判断要素

- **股权集中度**：第一大股东持股 > 40% 且与第二大股东差距大 → 控制力强但需关注一言堂风险。机构/社保/QFII 占比上升 → 通常为正面信号。
- **管理层激励**：有期权/限制性股票激励的管理团队与股东利益更绑定；对比管理层薪酬与公司利润规模。
- **股东户数变化**：连续下降 → 筹码集中，通常与价格上行共振；连续上升 → 筹码分散。
- **重要股东增减持**：`holder-trade` 大额减持需关注原因；增持通常是信心信号（但也可能是护盘）。
- **限售股解禁**：`share-float` 近期有大额解禁 → 供给压力。
- **大宗交易**：`block-trade` 频繁出现且折价明显，需结合股东变动和公告判断是否存在减持压力。

### 6.2 注意事项

- 不要基于单个报告期过度推断治理质量。
- 股东户数变化是辅助信号而非决策依据。

## 七、公告事件与机构调研分析

输出落位：报告第一部分「近期动态：公告事件与机构调研」，作为对公司现状的补充；其中与主线相关的佐证在定量「主线归属修正」处被引用。

### 7.1 公告事件验证

使用 `announcements` 先定位事件，再决定是否读取 `announcement-text`。

- **监管/问询**：监管函、关注函、问询回复通常需要读原文，确认问题指向、公司解释和整改承诺。
- **资本运作**：定增、股权激励、员工持股要确认发行对象、价格、解锁条件、业绩考核和摊薄影响。
- **回购/增减持**：确认规模、价格区间、资金来源、执行进度和主体身份，不要只凭“回购/增持”定性利好。
- **重大合作/项目**：必须读原文确认协议约束力、金额、履约期限、收入确认条件、对手方和风险条款。
- **业绩快报/预告**：重点比较收入、利润、扣非利润和现金流线索，必要时再读定期报告解释。

公告标题只是索引。对公司基本面、估值或风险有影响的结论，必须来自公告原文、定期报告正文或其他可验证来源。

### 7.2 机构调研使用方法

使用 `institutional-research` 观察市场关注度和产业问题焦点。

- **调研频率**：短期明显升温说明关注度上升，但不等同于基本面改善。
- **机构类型**：公募、券商、险资、QFII、私募等参与结构可以辅助判断关注质量。
- **调研方式**：现场、电话、线上会议等只说明沟通形式，不直接说明信息增量。
- **调研内容关键词**：提取 AI/算力/出海/订单/价格/产能/客户/毛利率等关键词，验证公司是否被市场放入当前主线。
- **风险边界**：机构调研记录是公开披露信息，不能当作业绩承诺或内幕信息。

## 九、质量要求

- 能给具体数字时优先给数字，数据有日期时写明报告期。
- 不要堆原始表格，用关键数字支撑论点。
- 不要编造竞争对手、客户、政策、产业事实或市场主线；这类当前外部事实需要联网检索并引用来源。
- 主线归属判断必须基于近期可验证的市场观察，不要凭训练记忆判断当前主线。
- 避免单边结论，每个判断都要写出最强反方观点。
- 区分"我从数据中看到了什么"和"我推断了什么"——前者是事实陈述，后者需标注为推断。
- 公告标题只能用于定位事件；涉及重大影响时必须读取公告或报告原文。
- 机构调研只能用于关注度和问题焦点验证，不得写成业绩改善证据。
- 主线归属作为可被推翻的假设而非事实，必须标注置信度。
- 最终回答要适合投资者阅读：简洁、有证据、清楚表达不确定性。
