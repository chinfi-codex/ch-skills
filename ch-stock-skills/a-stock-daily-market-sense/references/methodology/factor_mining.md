# 特征分组 · 量化回溯相对收益因子挖掘

这是一条**按需触发的研究流程**，跟每日盘后日报是两条线——你想挖某个特征分组时才跑，不进日报。
目标：你提一个特征分组，skill 在分组之上做额外因子挖掘，最终给出**分组中的叠加条件最优解**。

脑/手边界照旧：脚本 `scripts/factor_backtest.py` 只铺确定性证据（命中、6 格前向收益、因子分层、
单/配对候选叠加条件 + 护栏标记），**不挑"最优解"、不下结论**；读证据、选叠加条件、写归因与
caveat 是模型的活。

## 一、整条流程（两处人工，其余自动）

1. **你提分组**（人工）：已有内置分组（如 `discount_relaunch` 折扣启动）一句话点名；或全新分组用
   大白话描述硬条件。
2. **模型译成规则**（自动，新分组给你确认）：把自然语言翻成 filter spec（见 §五）。
3. **脚本回放 + 回测 + 铺网格**（自动）：历史回放命中 → 6 格前向相对收益 → 单/配对叠加网格 + 护栏 →
   写 `reports/factor_mining_<group>_<asof>.json`。
4. **模型选最优叠加解**（自动）：读 JSON，按 §四 rubric 选定叠加条件，写报告。
5. **你决定要不要用**（人工）：当研究参考，或手动把叠加条件提级成分组生产阈值——脚本不替你改生产。

## 二、回测口径（脚本固定）

- **信号日 T**：个股命中分组那天。
- **进场**：T+1 开盘 / T+1 尾盘（收盘）两种；**持有**：到 T+3 / T+5 / T+10 收盘 → 共 **6 格**。
- **价格**：后复权（adj_factor），中性化除权除息。
- **相对收益 = 个股收益 − 匹配基准同窗口收益**。基准按**板块优先、主板内再按市值档**分配：

  | 个股归属 | 匹配基准 | 代码 |
  |---|---|---|
  | 科创板 | 科创50 | `000688.SH` |
  | 创业板 | 创业板指 | `399006.SZ` |
  | 主板 · 大盘（≥300亿） | 沪深300 | `sh.000300` |
  | 主板 · 中盘（80–300亿） | 中证500 | `sh.000905` |
  | 主板 · 小盘（<80亿） | 中证1000 / 国证2000 | `sh.000852` / `sz.399303` |

  沪深300 另作"宽基对照"列（`relo_k_w` / `relc_k_w`），方便和旧的宽基口径对得上。

- 每格输出 N、均值、**中位数**（识别右偏）、胜率、相对均值与相对胜率。

## 三、因子挖掘（叠加条件搜索）

- **候选因子**取自 `add_numeric_features` + `daily_basic` 派生：换手率、量比、总市值、当日涨幅、
  T+1 高开（`t1_gap`）、前高折扣、120 日位置、5 日前收益、放量倍数等（见脚本 `FACTOR_BINS`）。
- **不做连续阈值网格扫描**，只在经济上有意义的少量切点（分档边界）上切，压住多重检验。
- **单因子**：每个因子按切点生成 `>=` / `<` 两类候选，算 G∧c 表现。
- **配对（深度≤2）**：取每个因子最优的单条件，跨不同因子两两组合——专门捕捉"单看都一般、合起来强"的组合。
- 不再加深到三因子：样本小，三层组合几乎必然过拟合。

## 四、护栏与"最优解"怎么选（模型的核心判断）

**脚本的护栏**（`passes_guardrails` 为真才算过闸）：

- 保留样本 ≥ `--min-n`；前后两个时间半区各 ≥ 8 且**均为正**；
- 确实超过基础组（`delta_vs_base` > 0）；
- **弱半区 / 强半区 ≥ 0.3**（`oos_balance`）——边际不能全堆在某一段行情，这是最容易识破"假因子"的一条。

**模型在过闸候选里选最优解时，按优先级权衡：**

1. **稳健 > 大 Δ**：`oos_balance` 高、前后半区都厚的，优先于 Δ 大但偏某一段的。一个 Δ+3 但
   `oos_balance` 0.31 的，往往不如 Δ+1.5 但 0.6 的可信。
2. **经济逻辑**：能讲通的因子（反转组要真实换手、不追高；强势组低换手、别接力）比纯统计巧合更可信。
   留意不同性质的组方向可能相反——折扣启动（反转）偏高换手，容量上涨（强势）偏低换手。
3. **同看中位数与胜率，不只看均值**：均值常被少数大赢家抬高；胜率 ≤50% 而均值为正多半是右偏，要点明。
4. **深度封顶 2**：单因子能解决就别叠两个；叠两个要确认 N 没塌、`oos_balance` 没垮。
5. **选目标格**：默认 T+1尾盘→T+5；但快动量组可选 T+3、底部反包组可选 T+10——6 格都在证据里，按组性质选并说明。

**最终输出**一句可落地的话，例如「折扣启动 ∧ 换手率≥10% → T+5 相对同类基准 +X%、胜率 Y%、N=Z、前后半区均正」，
并**老实写 caveat**：样本窗口、单一市场环境、均值右偏、T+10 样本更薄——这是证据扫描下的假设，不是已验证因子。

## 五、运行

```bash
# 内置折扣启动（多日序列组，复用生产函数，语义同线上）
python3 scripts/factor_backtest.py --group discount_relaunch [--min-n 15] [--entry close --horizon 5]

# 自定义分组（单日特征阈值组，用 spec）
python3 scripts/factor_backtest.py --group custom --spec my_group.json [--start YYYYMMDD --end YYYYMMDD]
```

custom 的 spec（单日特征阈值条件；含价量条件会自动用作廉价预筛压缩计算面）：

```json
{
  "name": "容量上涨",
  "warmup": 120,
  "conditions": [
    ["total_mv_100m_yuan", ">", 70],
    ["amount_100m", ">", 5],
    ["pct_chg", ">", 8]
  ],
  "exclude_st": true,
  "exclude_bj": true
}
```

条件列名可用：`total_mv_100m_yuan` / `amount_100m` / `pct_chg` / `turnover_rate` / `volume_ratio` /
`drawdown_120_high` / `close_position_120d` / `pre_ret_5d` / `amount_vs_prev5_ratio` / `ret_5d` / `ret_20d` 等
（`add_numeric_features` 与 daily_basic 派生列）。操作符：`> >= < <= ==`。
**折扣这类多日序列条件（前高折扣、缩量再放量、月线趋势）不能用 spec 表达，走内置分组。**

常用参数：`--min-n` 叠加条件最小保留样本（小样本时调低，如 15）；`--entry/--horizon` 选目标格；
`--skip-backfill` 仅用已缓存 daily_basic 日做快速冒烟；`--refresh-basic` 整窗重取 daily_basic 修脏缓存。

## 六、数据前置

`daily_basic`（换手/市值/量比）历史在 PG 里常常只缓存了零星几天。脚本默认会把**信号窗口**内缺失的
`daily_basic` 从 Tushare 回补入库（需要 `TUSHARE_TOKEN`）。所以首次跑某个分组、或跑较长窗口时会先回补，
之后命中缓存就快。后复权可用区间受 `stock_adj_factor` 起始约束；折扣启动还要完整 200 日历史，信号只
落在数据最近端，窗口与样本偏小——这正是护栏与诚实 caveat 是骨架的原因。

## 七、证据包 JSON 结构（模型读这个）

- `meta`：分组、asof、目标格、基准方案、护栏定义、数据覆盖、caveats、命中计数。
- `base_cells`：基础组 6 格（绝对 + 相对匹配基准的均值/中位/胜率）。
- `factor_layers`：各因子分层表 + 是否单调（单调因子最可信）。
- `overlay_singles` / `overlay_pairs`：候选叠加条件，每条带 `obj_mean` / `delta_vs_base` / `win` /
  `oos_first_mean` / `oos_second_mean` / `oos_balance` / `passes_guardrails`。
- `signals`：逐 (个股, 信号日) 明细（特征值 + 6 格收益），供个股归因与交叉核对。

## 八、报告写法（模型产出 `reports/factor_mining_<group>_<asof>.md`）

按文风默认（讲人话、同项用 list）：

1. **回测设置**：分组定义、窗口、样本量、基准方案、诚实 caveat（开门见山讲清这是单一环境的证据扫描）。
2. **基础组怎么样**：6 格里挑目标格说边际厚薄，点出均值 vs 中位的右偏。
3. **因子网格**：哪些单调因子有效、方向与经济解释；高 Δ 但不稳的要点名"偏某段行情"。
4. **叠加条件最优解**：给一句可落地的叠加条件 + 它的目标格表现 + 为什么是它（稳健/逻辑），并列出次选与不取的理由。
5. **个股例子**：从 `signals` 里举 2–3 只印证。
6. 不出买卖建议、不出仓位/止损/目标价。
