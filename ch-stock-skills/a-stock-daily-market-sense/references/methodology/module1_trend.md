# 模块 1：盘面趋势

使用 `module1_market_trend.json`。

只分析：

- `trend_state_card`（趋势轴状态卡，机器生成）
- 上证指数
- 创业板指数
- 科创50
- Baostock 风格代理指数
- `market.trend.sentiment`
- `market.temperature`

不要加入创业板 PE、外围资产或新闻解释；融资类读数**只允许出现在 1.1 开头的趋势状态卡**（计数器口径，机器生成），不得进入正文叙事；市场风格只用 `market.trend.market_style` 里的 Baostock 指数证据，不临时引入别的风格口径。

分析框架：

1. 情绪趋势（1.1，趋势状态卡置于小节最前）：紧跟 1.1 标题先呈现趋势状态卡——读 `trend_state_card`，按模板原样列出趋势状态与深度（如"深度退潮（第 2 日）"、"退潮·修复中（第 1 日）"）、五计数器（破位 / 融资连负及累计 / 缩量 / 顶背离 N/10 / 反弹质检戳）、近 5 个交易日状态轨迹、解除进度。这些是确定性机判读数，**只能照抄、不得改写或凭盘面自行推翻**；`is_current=false` 时必须注明"数据截至 {data_through}（融资/收盘数据滞后）"。卡后接情绪指标表（量能温度、全市场换手率、情绪温度、广度温度；情绪历史不可用时只保留当日快照）。小节末尾是唯一判断段 `==趋势判断：...==`——用一两句话给出清晰、明确的趋势定性（方向与所处阶段：上行 / 高位分歧 / 退潮 / 恐慌极值等），判断词必须与状态档位一致，可挑 1-2 个当日情绪读数作证据说明状态的巩固或边际变化，但单日反弹不得推翻退潮档（升档须右侧确认）；只描述市场状态，**不写任何仓位、买卖或操作建议**。**不再单独写"情绪判断"段落**。`available=false` 时状态卡替换为一行"趋势轴不可用（原因），本节仅按当日盘面描述"，其余照常。
2. 指数趋势：用一张紧凑表对照上证、创业板、科创50的趋势阶段、量价质量、均线位置和相对强弱，再用一段话判断三者共振还是分化。
3. 市场风格：用 Baostock 代理指数判断容量抱团、微盘扩散、红利防守、成长修复、风格均衡或风格混乱；证据不足时不强行定性。
4. 盘面定性：明确写成指数、风格与情绪的共振、背离或分化。

写作要求：

- 状态卡的读数逐项来自 `trend_state_card`，格式按模板；1.1 末尾的 `==趋势判断==` 是模块 1 唯一允许下"方向性结论"的位置，必须明确（不写"或涨或跌"式两可话），且只做客观趋势定性，不含仓位与买卖字眼；不再单独写"情绪判断"段落。
- `==趋势判断==` 的判断词必须与状态机档位对应，映射固定如下，不得自创两可表述：
  - 进攻 → "上行（进攻）"
  - 标准 → "震荡平衡（标准）"
  - 谨慎 → "高位分歧 / 转弱预警（谨慎）"
  - 退潮 → "退潮"
  - 深度退潮 → "深度退潮"
  - 冰点 → "恐慌极值（冰点）"
- 退潮 / 深度退潮附带的 phase 相位（修复中 / 企稳 / 恶化中）是边际方向的确定性读数，照抄进状态卡（如"退潮·修复中（第 1 日）"），判断词可顺势写成"退潮，修复信号出现"或"深度退潮，仍在恶化"；相位不改动档位本身，升出退潮梯队仍须机器解除确认。
- 不要把单日涨跌写成趋势。
- 指数趋势必须合并在 `1.2 指数趋势`，不要拆成上证、创业板、科创50三个独立小节。表格承载核心数值，段落只解释最关键的共振或分化。
- 市场风格必须说明代理口径：Baostock 指数字典没有直接的微盘指数，国证2000只是小微盘代理。
- 市场风格只根据代表指数的相对收益、均线位置和成交额相对 20 日均量判断，不写成行业或题材归因。
- `指数趋势判断` 和 `市场风格判断` 两个总结段落必须用 `==...==` 包裹，和 `盘面定性` 一样渲染为高亮提示块。
- 指数上涨但缩量时，写“反弹质量待确认”。
- 成交额与全市场换手率同步抬升、上涨家数同步改善时，写“良性放量加速，风险中性偏高”。
- 全市场换手率上升但上涨/下跌家数转弱时，写“换手加速但承接分化，风险升温”。
- 指数强但广度/情绪弱时，写“指数掩盖分化”。
- 情绪先修复但指数未确认时，写“情绪先行修复但指数尚未确认”。
