# 模块 1：盘面趋势

使用 `module1_market_trend.json`。

只分析：

- `trend_state_card`（趋势轴状态卡，机器生成）
- `extreme_state`（极值状态卡，机器生成：底部出清分 0~6 / 顶部拥挤分 0~5）
- `forward_odds`（前瞻轴，机器生成：情绪脉冲 pulse + 同类日之后的条件分布）
- 上证指数
- 创业板指数
- 科创50
- Baostock 风格代理指数
- `market.trend.sentiment`
- `market.temperature`

不要加入创业板 PE、外围资产或新闻解释；融资类读数**只允许出现在 1.1 开头的趋势状态卡与极值轴**（机器口径，机器生成），不得进入正文叙事；市场风格只用 `market.trend.market_style` 里的 Baostock 指数证据，不临时引入别的风格口径。

分析框架：

1. 情绪趋势（1.1，趋势状态卡置于小节最前）：紧跟 1.1 标题先呈现趋势状态卡——读 `trend_state_card`，按模板原样列出趋势状态与深度（如"深度退潮（第 2 日）"、"退潮·修复中（第 1 日）"）、极值轴（读 `extreme_state` 的出清分与顶部拥挤分）、五计数器（破位 / 融资连负及累计 / 缩量 / 顶背离 N/10 / 反弹质检戳）、相位证据比分（`phase_score` 的修复 N 项 vs 恶化 N 项，逐项列出命中标签）、前瞻轴（读 `forward_odds` 的 pulse 门槛与条件分布）、近 5 个交易日状态轨迹、解除进度。这些是确定性机判读数，**只能照抄、不得改写或凭盘面自行推翻**；`is_current=false` 时必须注明"数据截至 {data_through}（融资/收盘数据滞后）"。卡后接情绪指标表（量能温度、全市场换手率、情绪温度、广度温度；情绪历史不可用时只保留当日快照）。小节末尾是唯一判断段 `==趋势判断：...==`——用一两句话给出清晰、明确的趋势定性（方向与所处阶段：上行 / 高位分歧 / 退潮 / 恐慌极值等），判断词必须与状态档位一致，可挑 1-2 个当日情绪读数作证据说明状态的巩固或边际变化，但单日反弹不得推翻退潮档（升档须右侧确认）；只描述市场状态，**不写任何仓位、买卖或操作建议**。**不再单独写"情绪判断"段落**。`available=false` 时状态卡替换为一行"趋势轴不可用（原因），本节仅按当日盘面描述"，其余照常。
   - 极值轴的读法、阈值与措辞纪律见 `references/methodology/extreme_state_framework.md`；前瞻轴见 `references/methodology/forward_odds.md`。
   - **前瞻轴只给条件分布，不给新的状态定性。** 三根轴各答一问：趋势轴答「所处阶段」、极值轴答「两端拐点到了没有」、前瞻轴答「历史上出现同类读数之后发生了什么」。引用前瞻读数必须带样本量与全样本基准对照。
   - **`forward_odds.pulse` 是四腿合取门槛，不是分数。** 只写「四腿全中」或「未全中（N/4）」加逐腿命中项，**不得据腿数定性**——实测腿数 0~3 档全部贴基准或跑输，只有四条全中那一档有效。
   - **只能引用 `gate_detail.publishable_horizons` 里列出的视窗**。这表示样本量、子样本方向与置换检验在同一个视窗内同时过门槛；引用样本量取对应 `horizons[].n`，不得拿总触发数代替。当前 +1 日在子样本里不稳，不得拿来说事。
   - **`publishable=false` 的信号只能作为背景读数**，不得进 `==趋势判断==`。顶部侧一律 `publishable=false`，只输出回撤风险分布，不得写成方向性结论。
   - **极值轴与趋势轴冲突时并列写，不许调和**：退潮档里出现出清极值是 A 股最常见的底部形态，照实写成"趋势仍在退潮（第 N 日），但出清分已到 4/6"，不得为了让两句话一致而改写任何一边。
   - **顶部分只写风险累积度**，不写方向性结论；≥3 分时要带出"顶是过程不是点"（实测触发后 20 日平均还有 +2.03% 上冲，60 日均值才转负）。
   - `extreme_state.percentile_source` 不是 `rolling_quantile` 时要注明阈值口径尚未攒满窗口。
2. 指数趋势（1.2）：用一张紧凑表对照上证、创业板、科创50的趋势阶段、量价质量、均线位置和相对强弱，再用一段话判断三者共振还是分化。
3. 市场风格（1.3）：用 Baostock 代理指数判断容量抱团、微盘扩散、红利防守、成长修复、风格均衡或风格混乱；证据不足时不强行定性。

写作要求：

- 状态卡的读数逐项来自 `trend_state_card` 与 `extreme_state`，格式按模板；1.1 末尾的 `==趋势判断==` 是模块 1 唯一允许下"方向性结论"的位置，必须明确（不写"或涨或跌"式两可话），且只做客观趋势定性，不含仓位与买卖字眼；不再单独写"情绪判断"段落。
- **融资读数是 T-1 口径，写的时候必须带数据日**。`market_history` 第 d 行的融资取自前一交易日，`counters.margin_data_date` 给出它实际描述的是哪一天。卡面写成"融资连负 2 日（累计 -319.4 亿，数据日 07-24）"，正文里也**不得把它说成"今日融资流出"**——今天的杠杆行为要等明天的卡才看得到。同理，相位里的"融资转正 / 融资大卖"腿自带数据日后缀，照抄即可。
- **`deep_escalation_deferred=true` 时必须把 `state_note` 原文列出来**。这表示条件组已经 3/3、但第三组恰是滞后的融资腿，而当日盘面出现广度反转，状态机按「降档同样不由不含当日信息的读数单独推动」把深度退潮升档推迟了一日。此时档位写"退潮"，不得自行改写成"深度退潮"，也不要把推迟说成"状态好转"——它只是等一天用能反映当日的融资数据再判。
- `==趋势判断==` 的判断词必须与状态机档位对应，映射固定如下，不得自创两可表述：
  - 进攻 → "上行（进攻）"
  - 标准 → "震荡平衡（标准）"
  - 谨慎 → "高位分歧 / 转弱预警（谨慎）"
  - 退潮 → "退潮"
  - 深度退潮 → "深度退潮"
  - 冰点 → "恐慌极值（冰点）"
- 极值轴的判断词同样固定，出现时**追加**在趋势判断之后，不替换趋势档位：
  - `washout.zone=true` → "已进入出清区"
  - `washout.extreme=true`（当日 ≥3 分）→ "出清极值"
  - `top.risk=true`（≥2 分）→ "顶部风险累积"
  - `top.high_risk=true`（≥3 分）→ "顶部高危"
- 前瞻轴的判断词只有一个，且**只在 `pulse.gate=true` 且该信号 `publishable=true` 时**追加：
  - → "情绪脉冲触发"，后面必须紧跟一句带该视窗有效样本量与基准的条件分布（例："历史上 13 次已完成 +3 日观察的同类日中，84.6% 收涨、均值 +3.40%，全样本基准 52.5% / +0.06%"）。
  - 不得写成"大概率会涨""反弹在即"这类去掉了样本与基准的断言，更不得出现仓位、买卖、目标价。
- **退潮梯队是风险状态描述，不等于看空。** 5 年回放里冰点日之后 20 个交易日平均上涨 8.92%、81.8% 的时候在涨，深度退潮 +1.54%，都高于全样本的 +0.44%。写趋势判断时不得暗示应当离场或减仓，也不得把"退潮"直接翻译成"看空"。
- 退潮 / 深度退潮附带的 phase 相位（修复中 / 企稳 / 恶化中）是边际方向的确定性读数，照抄进状态卡（如"退潮·修复中（第 1 日）"）。相位由 5v5 镜像证据定档——广度、20 日线缺口、量能、跌停四对取自当日，融资一对滞后一日——任一侧 ≥2 项且严格多于对方才定向，否则企稳。判断词顺势写成"退潮，修复信号出现"这类表述时，**必须先看轨迹再决定用词**：相位是今天才转向的写"转入修复 / 转入恶化"，连续同相位才写"仍在恶化 / 修复延续"，别把第 1 日的转向说成"仍在"。相位不改动档位本身，升出退潮梯队仍须机器解除确认。
- 不要把单日涨跌写成趋势。
- 指数趋势必须合并在 `1.2 指数趋势`，不要拆成上证、创业板、科创50三个独立小节。表格承载核心数值，段落只解释最关键的共振或分化。
- 市场风格必须说明代理口径：Baostock 指数字典没有直接的微盘指数，国证2000只是小微盘代理。
- 市场风格只根据代表指数的相对收益、均线位置和成交额相对 20 日均量判断，不写成行业或题材归因。
- `趋势判断`、`指数趋势判断` 和 `市场风格判断` 三个总结段落必须用 `==...==` 包裹，渲染为高亮提示块。
- 指数上涨但缩量时，写“反弹质量待确认”。
- 成交额与全市场换手率同步抬升、上涨家数同步改善时，写“良性放量加速，风险中性偏高”。
- 全市场换手率上升但上涨/下跌家数转弱时，写“换手加速但承接分化，风险升温”。
- 指数强但广度/情绪弱时，写“指数掩盖分化”。
- 情绪先修复但指数未确认时，写“情绪先行修复但指数尚未确认”。
