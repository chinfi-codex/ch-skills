# 模块 1：盘面趋势

使用 `module1_market_trend.json`。

只分析：

- `market_state`（市场状态定位卡，机器生成：宽基位置 / 市场宽度 / 申万一级结构 / 融资余额趋势 / 流动性）
- `trend_state_card`（趋势轴状态卡，机器生成）
- 上证指数
- 创业板指数
- 科创50
- Baostock 风格代理指数
- `market.trend.sentiment`
- `market.temperature`

不要加入创业板 PE、外围资产或新闻解释（**唯一例外：1.5 东亚同步配对的韩指读数**，见下）；融资类读数**只允许出现在 1.1 市场状态定位卡与 1.2 开头的趋势状态卡**（机器口径，机器生成），不得进入正文叙事；市场风格只用 `market.trend.market_style` 里的 Baostock 指数证据，不临时引入别的风格口径。

分析框架：

1. 市场状态定位（1.1，状态卡置于小节最前）：读 `market_state`，先按 `references/template/section1.md` 的形状写状态卡四行——回撤分层（权重 / 成长小盘分档，档位取 `indexes[].tier`）、确认三要素的四条勾选项（勾选状态取 `confirmation.checks[].hit`，`✓ / ✗ / —` 是渲染锚点不能换写法）、边际变化、以及仅在 `stale_blocks` 非空时才出现的数据提示；卡后接状态表（六宽基 250 日高点回撤、宽度三指标、正 60 日收益行业数、融资余额趋势、流动性），末尾 `==市场状态定位==` 段按 `references/methodology/market_state_framework.md` 做回撤分层定性并判断调整是否接近尾声（≤150 字）。

   读数是确定性机判，只能照抄：阈值命中直接引 `confirmation`，不要自己重算；融资是 T-1 口径必须带 `margin_trend.trade_date` 数据日；确认三要素中「盈利上修」脚本不提供（`hit: null` + `source: external`），须由外部证据判断，缺外部证据时写明缺一条腿；行业分母写 `count_positive_60d_total` 的实际有效数而不是恒定 31；证据不足写「不足以判断」。**引任何读数前先看 `stale_blocks`**——申万行业走权限接口，掉权限后会静默吃旧缓存，超期读数必须在正文标出它自己的数据日。`available=false` 时整节替换为一行"市场状态定位不可用（原因）"，其余照常。
2. 情绪趋势（1.2，趋势状态卡置于小节最前）：紧跟 1.2 标题先呈现趋势状态卡——读 `trend_state_card`，按模板原样列出趋势状态与深度（如"深度退潮（第 2 日）"、"退潮·修复中（第 1 日）"）、五计数器（破位 / 融资连负及累计 / 缩量 / 顶背离 N/10 / 反弹质检戳）、相位证据比分（`phase_score` 的修复 N 项 vs 恶化 N 项，逐项列出命中标签）、近 5 个交易日状态轨迹、解除进度。这些是确定性机判读数，**只能照抄、不得改写或凭盘面自行推翻**；`is_current=false` 时必须注明"数据截至 {data_through}（融资/收盘数据滞后）"。卡后接情绪指标表（量能温度、全市场换手率、情绪温度、广度温度；情绪历史不可用时只保留当日快照）。小节末尾是唯一判断段 `==趋势判断：...==`——用一两句话给出清晰、明确的趋势定性（方向与所处阶段：上行 / 高位分歧 / 退潮 / 恐慌极值等），判断词必须与状态档位一致，可挑 1-2 个当日情绪读数作证据说明状态的巩固或边际变化，但单日反弹不得推翻退潮档（升档须右侧确认）；只描述市场状态，**不写任何仓位、买卖或操作建议**。**不再单独写"情绪判断"段落**。`available=false` 时状态卡替换为一行"趋势轴不可用（原因），本节仅按当日盘面描述"，其余照常。
3. 指数趋势：用一张紧凑表对照上证、创业板、科创50的趋势阶段、量价质量、均线位置和相对强弱，再用一段话判断三者共振还是分化。
4. 市场风格：用 Baostock 代理指数判断容量抱团、微盘扩散、红利防守、成长修复、风格均衡或风格混乱；证据不足时不强行定性。
5. 东亚同步配对（1.5）：把创业板指与**同日**韩指（KOSPI / KOSDAQ，首尔收盘 = 北京 14:30）涨跌幅配对，写差值与「同步（<2pct）/ 背离（≥2pct）」判定。依据是「东亚同步 · 美股滞后」时序模型：韩股与创业板同处一个交易时段、由同一批全球 AI / 半导体资金定价，日内基本同步；美股整个时段在东亚收盘之后，是下游滞后表达。背离时写疑似主导因素（A 股本土政策 / 流动性 / 资金结构，或韩国本土特异事件）。**今晚美股按模型是对今日东亚方向的滞后确认，只写预期方向，不得写成今日盘面的归因**。韩指无脚本数据源，须联网现查；查不到写「韩指配对不可用」并保留表行，**不得以隔夜美股顶替该位、不得跳过本小节**。本小节是模块 1 中唯一允许出现外围资产读数的位置，且只允许韩指一项。
6. 盘面定性（1.6）：明确写成指数、风格与情绪的共振、背离或分化。

写作要求：

- 状态卡的读数逐项来自 `trend_state_card`，格式按模板；1.2 末尾的 `==趋势判断==` 是模块 1 唯一允许下"方向性结论"的位置，必须明确（不写"或涨或跌"式两可话），且只做客观趋势定性，不含仓位与买卖字眼；不再单独写"情绪判断"段落。
- **融资读数是 T-1 口径，写的时候必须带数据日**。`market_history` 第 d 行的融资取自前一交易日，`counters.margin_data_date` 给出它实际描述的是哪一天。卡面写成"融资连负 2 日（累计 -319.4 亿，数据日 07-24）"，正文里也**不得把它说成"今日融资流出"**——今天的杠杆行为要等明天的卡才看得到。同理，相位里的"融资转正 / 融资大卖"腿自带数据日后缀，照抄即可。
- **`deep_escalation_deferred=true` 时必须把 `state_note` 原文列出来**。这表示条件组已经 3/3、但第三组恰是滞后的融资腿，而当日盘面出现广度反转，状态机按「降档同样不由不含当日信息的读数单独推动」把深度退潮升档推迟了一日。此时档位写"退潮"，不得自行改写成"深度退潮"，也不要把推迟说成"状态好转"——它只是等一天用能反映当日的融资数据再判。
- `==趋势判断==` 的判断词必须与状态机档位对应，映射固定如下，不得自创两可表述：
  - 进攻 → "上行（进攻）"
  - 标准 → "震荡平衡（标准）"
  - 谨慎 → "高位分歧 / 转弱预警（谨慎）"
  - 退潮 → "退潮"
  - 深度退潮 → "深度退潮"
  - 冰点 → "恐慌极值（冰点）"
- 退潮 / 深度退潮附带的 phase 相位（修复中 / 企稳 / 恶化中）是边际方向的确定性读数，照抄进状态卡（如"退潮·修复中（第 1 日）"）。相位由 5v5 镜像证据定档——广度、20 日线缺口、量能、跌停四对取自当日，融资一对滞后一日——任一侧 ≥2 项且严格多于对方才定向，否则企稳。判断词顺势写成"退潮，修复信号出现"这类表述时，**必须先看轨迹再决定用词**：相位是今天才转向的写"转入修复 / 转入恶化"，连续同相位才写"仍在恶化 / 修复延续"，别把第 1 日的转向说成"仍在"。相位不改动档位本身，升出退潮梯队仍须机器解除确认。
- 不要把单日涨跌写成趋势。
- 指数趋势必须合并在 `1.3 指数趋势`，不要拆成上证、创业板、科创50三个独立小节。表格承载核心数值，段落只解释最关键的共振或分化。
- 市场风格必须说明代理口径：Baostock 指数字典没有直接的微盘指数，国证2000只是小微盘代理。
- 市场风格只根据代表指数的相对收益、均线位置和成交额相对 20 日均量判断，不写成行业或题材归因。
- `指数趋势判断` 和 `市场风格判断` 两个总结段落必须用 `==...==` 包裹，和 `盘面定性` 一样渲染为高亮提示块。
- 指数上涨但缩量时，写“反弹质量待确认”。
- 成交额与全市场换手率同步抬升、上涨家数同步改善时，写“良性放量加速，风险中性偏高”。
- 全市场换手率上升但上涨/下跌家数转弱时，写“换手加速但承接分化，风险升温”。
- 指数强但广度/情绪弱时，写“指数掩盖分化”。
- 情绪先修复但指数未确认时，写“情绪先行修复但指数尚未确认”。
