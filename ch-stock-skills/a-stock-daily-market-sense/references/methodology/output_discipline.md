# 输出纪律

每个模块和最终聚合都要遵守本文件。

- 证据优先：所有强弱判断都要能回到候选数、成交额、成交额占比、放量倍数、涨跌幅、相对收益或回撤证据，但正文只挑最能解释状态的证据。
- 成交额优先：没有成交额支撑的价格波动只是弱证据；成交额集中、异常放量和持续换手权重更高。
- 不套现成行业标签：不要机械使用申万、同花顺、东方财富概念。主题只能从公司业务事实、产品环节、事件催化和同步量价行为中临时归纳。
- 不写投资建议：禁止写买入、卖出、加仓、止损、目标价或组合配置指令。
- 特征分组可以写“观察优先级”“持续性待验证”“交叉命中值得重点跟踪”等研究判断，但这些只表示证据强弱和跟踪优先级，不得延伸成具体交易指令。
- 不写空话：不要写“板块轮动明显”“资金关注度提升”“情绪较好”这类没有数字支撑的句子。
- 事实与判断分开：表格承载数据，段落解释数据意味着什么、哪些结论仍未确认。
- 每项数据有一个主要展示位置：宏观读数在 1.1、四卡在 1.2、量价与风格表在第 2 章、主线统计在第 3 章、个股在第 4/5 章。判断段只引用必要的关键证据，不把整行表格改写成一句话；跨章引用只解释新增含义。
- 摘要默认三句、约 150–250 字，分别说环境、主线和首要验证条件；不要把全篇数字挤进摘要。每个定性段通常 1–3 句，紧邻的数据叙事与高亮判断若在说同一件事，合并到高亮段。
- 集中度按 `turnover_concentration.md` 的“一条读数 + 一张轨迹图”呈现；常态不展开、同值分位不重复，回退与缺口照实披露。主线拥挤度列保留，不在后文重报全市场 CR。
- 主线表之后只解释最影响星级或持续性的证据，不逐行复述所有主题；无三星时直接省略催化节，不再重复“已锁星、不做搜索、整节省略”等执行日志。
- 第 4 章维度解读只补充并集表看不出的结构或分歧，不逐股重抄成交额、量比与信号。M3/M4 交叉结果完整说明一次，其他章节只有需要解释风险传导时简短引用。
- 纪律复核在内部完成，只披露影响结论的未决事项，不把落库、搜索、门禁日志写进研报。
- 瘦身先改 Markdown 草稿，再走门禁和 HTML 渲染；保留核心数据表、指数/个股 K 线、状态与集中度轨迹、风格曲线和主线生命周期图。不要靠隐藏或删除 HTML 正文制造精简版，也不删 evidence 字段。样本量、数据日期/滞后、缺失、口径冲突和降级原因不受长度目标限制。
- 人话先行：每个判断段第一句必须是自然语言结论，不以连续数字开头。例：“今天不是主线结束，而是强主线掩盖了弱广度。”
- 数字限流：同一自然段最多出现 3 个关键数字；超过部分放入表格，不在段落里复述。只约束散文判断段——状态卡、判据、口径声明这类模板强制块不受限，日期、时点、`5 日均` 这类窗口标签与指数名里的数字也不算读数。
- 少写审计句：减少“必须包含、暂不升级、需确认、候选数、占比、交叉结果”这类机械串联。保留边界判断，但要写成交易观察语言。
- 每节只回答一个问题：这节到底说明“进攻、分歧、退潮、修复、拥挤、扩散”中的哪一种状态。
- 高亮定性段落：每个一级大章节（1-4）里已有的总结/定性段落必须用 `==...==` 包裹，例如”趋势判断””指数趋势判断””市场风格判断””主线 vs 资金轮动结论””风险传导提示””特征分组一句话判断”。不要额外新增”本节总结”段落；高亮的是原本就承担总结作用的段落。
- 数据缺失或模块跳过时，要明确说明，并引用脚本给出的跳过原因。
- 2.2 三星门禁：最终聚合必须先检查 2.1 星级。只有至少一个 ★★★ 主线时才允许输出 `2.2 催化与细分线路推演`，且本节只能包含 ★★★ 主线；★ 与 ★★ 方向不得搜索、推演或进入本节。若 2.1 没有 ★★★，必须删除整个 2.2，包括标题与兜底句。
- 最终聚合要引用 `assembled_checks.json` 的 M3/M4 交叉检查；只有 M3 ★★★ 主线代表股也出现在爆量下跌池中，才升级为主线见顶预警。
