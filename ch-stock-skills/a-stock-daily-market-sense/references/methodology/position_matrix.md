# 仓位矩阵（position matrix）—— 环境与仓位总闸门的判定方法

本文件把"产业趋势波段"范式的仓位控制写成可复用的判定矩阵。它替代旧红线里"不写仓位"的一刀切：
**报告可以输出"研究仓位框架 / 仓位档位适配"，但仍禁止具体交易指令**——不点名个股买卖、不给止损价、不说"满仓/清仓"这类绝对指令，只输出环境与档位的适配关系。措辞边界见文末。

## 一句话定位

仓位控制不是预测，是**用环境状态给"该不该上仓位、上多少"一个纪律性的默认答案**。它回答的不是"买什么"，而是"现在的环境配得上多大的产业趋势敞口"。

## 三轴输入（全部为确定性读数，来自 evidence 与宏观记分卡）

| 轴 | 读数来源 | 对仓位的含义 |
|---|---|---|
| 指数趋势 | `trend_state_card.state` / `phase` | 趋势上行/修复 = 可以做；单边下跌/退潮 = 波段新仓受限 |
| 极值位置 | `extreme_state.washout` / `top` | 出清分高 = 分批布局窗；拥挤分高 = 只减不加、收紧信号阈值 |
| 宏观风险 | `macro_risk_scorecard.risk_level` / `score` | **只减不加**：宏观再好不是加仓理由，只是不减仓的理由；触发则降档 |

辅助输入（不改变档位，只作确认）：市场温度（up_ratio、成交额水位 vs 20 日均）、前瞻轴尾部风险（只读回撤分布，不读方向）、主线生命周期状态（`theme_lifecycle` 台账）、成交额集中度卡（`turnover_concentration`，`state=overheat` 时类比"主线高位分歧"提示收紧单线信号阈值；`passive` 时不做任何仓位侧引申，见 `turnover_concentration.md`）。

## 五档仓位档位（研究框架，非指令）

| 档位 | 适配环境（同时满足） | 研究仓位框架 |
|---|---|---|
| S 进攻档 | 趋势上行/修复 + 宏观风险低 + 存在 ★★★ 产业主线（低位启动/再聚焦态） | 产业趋势敞口可达个人上限 |
| A 标准档 | 趋势上行或修复 + 宏观风险低~中 + 有 ★★/★★★ 主线 | 正常敞口，聚焦产业主线 |
| B 中性档 | 趋势震荡 或 宏观风险中 或 主线高位分歧 | 持有为主，不加新仓 |
| C 防守档 | 趋势走弱/退潮 或 宏观风险高 或 指数跌破关键均线 | 压降敞口，只留核心观察仓 |
| D 冰点布局档 | 极值出清分高 + 前瞻轴尾部无恶化（无论趋势档位） | 分批布局窗，逆向小额试错 |

**档位裁决规则（确定性优先级，模型照此不即兴）：**

1. 宏观风险高 → 直接压到 C 或以下，其余轴再好也不升。
2. 趋势"退潮"且非修复中 → 上限 C。
3. 趋势"退潮 + 修复中"且极值出清有信号 → B，并标注"接近 D 布局窗"。
4. 趋势上行/修复 + 宏观低 + 有 ★★★ 主线低位/再聚焦 → S 或 A。
5. 多轴冲突时取**更保守**的一档，并在正文写明是哪根轴把它压下来的。

## 仓位控制的两条铁律

- **宏观只减不加。** 宏观信号满分不是进攻理由，只是"可以不防守"的理由；产业趋势的开仓理由永远来自产业本身（订单、排产、政策、技术拐点），宏观只能否决。
- **主线生命周期定单线敞口。** 持有某条产业趋势时，它的台账状态直接定这条线的相对权重：主线确认/再聚焦 = 满配候选；高位分歧 = 减半观察；退潮 = 退出该线敞口。这条不点名个股，只对"线"。

## 措辞边界（契约硬约束之外的本章纪律）

可以写：「当前环境适配 B 中性档」「宏观风险记分卡触发高等级，档位被压至 C」「该主线处于再聚焦态，单线敞口可按满配候选对待」。

不可以写：「买入/卖出/加仓/止损某只股票」「目标价」「满仓/清仓」「明天就降仓」这类具体交易指令或时点指令。研究仓位框架是**条件到档位的映射**，不是**下单指令**。

## 反例（禁区）

- 写「建议买入北方华创」——点名个股买卖，硬拦。
- 写「油价这么高应该清仓」——绝对指令 + 宏观加仓/减仓越界。
- 写「明天反弹概率大，可以上仓位」——前瞻轴只做尾部风险提示，不做方向依据，且变指令。
