# 市场风格因子判断手册（「市场风格」小节的主读数）

配套证据块：`module1_market_trend.json` 的 `market.trend.market_style.style_factors`（`scripts/style_factors.py` 生成）。计算与呈现口径移植自 skillhub `china-market-style-factors` v1.0.0，数据源换成 DMS 已有的 Tushare `index_daily`（PG 缓存）+ Baostock 整序列兜底。脚本只出确定性读数与规则标签；本手册是模型的判断框架。

## 判断目标

风格因子只回答两个问题：**市场现在偏大盘还是小盘、偏成长还是价值、行情有没有向更小的公司扩散、红利股价格是否领先；这些方向在 60/20/10 日三档上是延续还是在反转。** 它不回答所处阶段（趋势轴）、拐点（极值轴）、之后会怎样（前瞻轴），也不回答头部是否在吸筹（集中度卡）。

## 六个指标

| 键 | 名称 | 公式 | 正向含义 |
|---|---|---|---|
| `size` | 规模风格 | √(小盘成长 × 小盘价值) / √(大盘成长 × 大盘价值)，国证 399376/377 对 399372/373 | 小盘占优 |
| `growth` | 成长／价值 | [(大成/大价) × (中成/中价) × (小成/小价)]^(1/3)，国证 399372~377 | 成长占优 |
| `small_tail` | 小市值扩散 | 国证2000 / 国证1000 | 向更小市值扩散 |
| `dividend` | 红利偏好 | 中证红利价格 / 中证全指价格 | 红利价格领先 |
| `market_trend` | 市场趋势 | (全指收盘 / 过去 60 个收盘均值 − 1) × 100 | 高于 60 日均线 |
| `volatility` | 市场波动 | std(全指 20 日简单收益, ddof=1) × √252 × 100 | 波动较高 |

前四项的 `relative_Nd_pct` 是**比值涨跌**：100 × [exp(L_t − L_{t−N}) − 1]。分子 +10%、分母 +5%，相对变化是 4.76%，不是 5 个百分点——所以不要拿两个指数各自的涨跌幅相减去"复核"它。

## 读法

1. **60 日定中期方向，20 日与 10 日看延续还是反向修复。** `direction` 给出三档各自偏哪边，`label` 是原样可抄的一句（"60日：大盘；20日：大盘；10日：小盘"）。`rotation_code` 是机判的窗口关系：
   - `aligned`：10/20/60 日方向一致，写"方向一致、风格延续"；
   - `reversal_20v60`：20 日与 60 日方向相反，**这是唯一允许写"风格轮动 / 风格反转 / 风格切换"的情形**（契约硬拦）；
   - `shift_10v20`：10 日与 20 日相反，只能写"短期出现变化"，不得升格为轮动；
   - `mixed`：各窗口不完全一致，照实写。
2. **零附近信号很弱。** 相对变化绝对值在 1% 以内时写"偏向很弱"，不要把 0.3% 写成"小盘占优"。
3. **历史分位看位置，不看方向。** `percentile` 是 60 日相对变化在发布后历史里的分位（只比当日之前、至少 252 个样本），引用时写口径与样本数（"60 日信号位于发布后历史 13.1% 分位，样本 4003 日"）。分位高低只说明这次偏离在历史上算不算罕见，不是均值回归信号。`percentile=null` 时写"分位样本不足"。
4. **三年、一年与全历史只解释周期位置。** `views` 里的四窗口区间变化（风格比值在窗口首日重设为 100）说明这轮风格在更长周期里走到哪；长期累计水平不等于当前趋势。
5. **趋势与波动单独描述。** 趋势写"全指相对 60 日均线 −1.98%，趋势偏弱"；区间差值用"个百分点"。波动分位 ≥80 写"偏高"、≤20 写"偏低"——这只是描述规则。**波动上升本身不代表价格下跌。**

## 两条交叉核验（写结论前必须看）

- **规模稳健性**：`robustness_checks.size_csi1000_over_csi300` 给出中证1000/沪深300 的 20/60/120 日相对变化，以及和主规模指标的方向对照 `note`。方向冲突时照抄 `note`（"20日方向冲突，规模结论对指数构造敏感"），这一档的规模结论要降级为"存在分歧"。
- **全收益敏感性**：`sensitivity_total_return` 在六条国证全收益齐全时给出规模、成长价值的含分红口径；**DMS 扩展**另用 H00922/H00985 给红利偏好做含分红核验（原版做不到，`extension=true`）。`total_return_note` 原样引用；某组 `total_return_status` 不是 `complete` 时写明"含分红核验缺失"，不得声称方向一致。

## 措辞纪律

- 这是跨市场**指数风格代理**，不是逐股重建的纯 SMB/HML/UMD，没做行业与 Beta 中性化，四个因子互有相关（相关矩阵见 `factor_correlations`）。
- **相对领先不等于资金流入**，也不是经过回测的交易信号；不写"资金涌向小盘""该切成长了"。
- 价格指数不含分红：不能用红利价格曲线宣称红利投资总回报；除息季（6~8 月）红利偏好会被机械压低，看全收益核验再下结论。
- 成长按国证官方基本面风格分类，**不等于科技行业**；小市值扩散用国证2000，**不等于微盘股组合**。
- 风格判断不写仓位、买卖、目标价。

## 写法（报告里的固定形状）

产业趋势波段（dms/2.1）报告里，市场风格放在第 2 章「大盘温度与风格」的**章末**（legacy 报告仍是 1.3 市场风格节）。先放「风格因子」表，**首列表头必须就叫「风格因子」**（契约与 HTML 面板都按这个表头找锚点）：

```markdown
| 风格因子 | 10日 | 20日 | 60日 | 120日 | 60日历史分位 | 分窗口解读 |
|---|---:|---:|---:|---:|---:|---|
| 规模风格 | +0.48% | -1.34% | -8.04% | -1.44% | 13.1% | 60日：大盘；20日：大盘；10日：小盘 |
| 成长／价值 |  |  |  |  |  |  |
| 小市值扩散 |  |  |  |  |  |  |
| 红利偏好 |  |  |  |  |  |  |
```

表下用 list 各写一句（说人话，别拼字段）：市场环境（趋势 + 波动）、规模稳健性对照、含分红核验。最后是唯一的判断段 `==市场风格判断：...==`：先说偏大盘还是小盘、偏成长还是价值、有没有扩散、红利是否领先，再说这些方向是延续还是在变，最后点出交叉核验里需要保留的分歧。证据不足（`style_factors.available=false`）时整节只写"风格证据不足，不强行定性"并注明 `reason`。

表格数字只抄 `metrics` 里的读数（保留两位小数即可）；HTML 会在表后自动挂读数卡、窗口热力表、四窗口详情图与口径附录，Markdown 里不要重复画图说明。

## 与其他模块的关系

- **规模偏好矩阵（`size_preference.md`）**：矩阵用量能与趋势**推断**线内该偏大还是偏小，规模因子给的是市场**实际**在偏哪边。两者冲突（例如缩量但大盘持续跑赢）时并列写、不调和，在第 4 章维度 C 注明"规则倾向与实际风格背离"。
- **成交额集中度卡（`turnover_concentration.md`）**：集中度的 `rotation`/`overheat` 是成交额侧的头部吸筹，规模因子 60 日偏大盘是价格侧的同一件事；两边同向才写"容量抱团得到确认"，一边成立时只写那一边。
- **仓位矩阵（`position_matrix.md`）**：风格因子是辅助读数，**不改变档位**；红利偏好上行叠加成长走弱，只能作为"风险偏好收缩"的旁证写进备忘。
- **Baostock 风格代理指数**（`market_style.indices`）仍在 evidence 里，只作为各指数量价背景；风格方向一律以风格因子为准。

## 数据与口径备忘

- 核心 12 条（国证六个风格格子、国证2000/1000、中证红利、中证全指、中证1000、沪深300）任一条末日不是 asof、有缺失交易日、日期重复、价格非正、观测不足 756、起点晚于最晚允许起点，整块 `available=false`，不生成风格结论。
- 只允许整序列换源（Tushare → Baostock），不拼接；来源与每次尝试写在 `qa[].source/attempts`。Baostock 没有中证全指，全指只能走 Tushare。
- H00985 缺发布当日 2011-08-02 一日，红利全收益核验从 2011-08-03 起（`valid_note` 写明）。
- 发布边界：规模与成长价值 2010-01-04、小市值扩散 2014-03-28、红利与环境指标 2011-08-02。早于边界的回溯段保留在曲线里、只用文字说明，不画阴影，不进分位。
- 日频曲线（2002 年起）旁路写 `reports/style_factors_YYYYMMDD.json`，只给 HTML；evidence 里只有读数，数字溯源门禁对着读数查。
