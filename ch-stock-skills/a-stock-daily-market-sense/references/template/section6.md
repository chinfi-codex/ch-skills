# 6. 策略选股观察清单

==一句话判断：[今天策略层更像"有主线共振、历史有效条件加持的高信心点位"，还是"多为技术命中、缺主线确认/缺画像"？说清整体成色，再点 1-2 个最值得盯的票。]==

> 口径：本节是**观察清单**，不是买卖建议——不含买入/卖出/止损/目标价/仓位。技术命中不等于可操作；
> 历史胜率是回测/样本外的证据扫描，不是承诺。画像缺失的分组（如本轮月线平台突破、10:30 前涨停）只作纯技术观察。

## 6.1 信心分档清单

| 信心 | 股票 | 命中组别 | 满足的有效条件（回测 胜率/样本） | 主线归属(★) | 交叉命中 | 持续性待验证条件 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

按 强 → 中 → 观察 排序。信心档按 `module6_strategy_observation.md` 的锚点 rubric 判（强=有效条件稳健 + 主线/多组共振）。
满足的有效条件写清条件文字 + 回测 `win%`/`N`（如「总市值≥300亿∧量比<1.5　59%/991」）；`cannot_evaluate` 的条件不计入、必要时在备注点明。
主线归属(★) 对照 3.1 主线表：落在 ★★/★★★ 主线写主题名+星级，否则写「暂不在主线」。无任何候选匹配到有效条件时写：今日命中股暂无匹配历史有效叠加条件，仅作技术观察。

## 6.2 本策略样本外战绩

引用 `oos_ledger_stats`（实盘台账已 score 的样本外票，按 T+1尾盘→T+5 相对匹配基准）。一段话讲清：
近多少个样本、整体与各信心档的相对胜率/均值、N 是否还小。**与上面回测画像表现分开说，不要合成一个胜率。**
台账还空（刚起步）时如实写"实盘台账样本尚不足，先记录、后评估"。

> caveat：回测画像表现是样本内、单一市场环境的证据扫描；样本外台账 N 仍在累积。两者都不构成对未来的承诺。
