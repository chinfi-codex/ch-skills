# 业绩预告报告输出模板

按「整体画像 → 报告期行业趋势 → 优秀个股分档 shortlist → 统一 caveat」四段。文风讲人话、同项用 list、每只必带三口径。不给买卖建议。

## 结构

```markdown
# {报告期标签}业绩预告扫描（截至 {ann_window 结束日}）

## 一、这一期预告的整体画像

- 覆盖：已披露 {N} 家（向好 {正向数} / 恶化 {负向数}），样本随披露进度累积——季初偏少，过几天会更全。
- 增速分布：加速（单季>累计）{K} 家；扭亏/低基数弹性 {T} 家；明确减速/预减 {D} 家。
- 扎堆的方向（模型按业务事实临时归纳，不套现成行业标签）：{如“电解液添加剂/VC 涨价链”“养殖周期反转”“资源品涨价”}，共同性不足时写“暂无明显扎堆、个股逻辑各异”。

==一句话判断==：{这季预告整体是普涨还是分化、含金量集中在哪类逻辑}

## 二、报告期行业趋势

**产业结构综述**（与台账 `period_overview` 同一结论，据 `industry_summary` 全样本聚合，方法论 §十）：

1. {结构特征一句话，如“产业结构分化明显”}
   (a) {正向扎堆的宏观组，如“高端制造科技（半导体、新能源材料、精细化工及精密零部件）”}——{依据：正向 x 家/单季增速中位 +x%/断层向上 x 家；共性驱动一句话}；
   (b) {负向扎堆的宏观组，如“消费和地产链”}——{依据：预减/首亏 x 家、原因共性是需求疲软/减值；筑底证据有无（环比中位、减亏占比）}，{前瞻判断 + 证伪条件}。

{样本偏差一句话：预告为触发式披露、偏向剧烈变化，综述反映边际结构；截至 x 月 x 日样本 N 家，随披露累积更新。}

**按主线细看（强/弱表现归因交叉验证）**：

- **{主线名}（判·{向上/向下/分化/证据不足}，强{N}/弱{M}）**：强表现 {成员+跳空幅度}，共性归因是{行业级驱动，如"同一涨价链传导到报表"}；弱表现 {成员}，属{行业级拖累 / 个体事故}。交叉验证：{一句话——方向是否成立、由什么驱动、是全面开花还是龙头独走、下一步看什么证伪}。
- **{主线名}（判·证据不足）**：{为什么判不了——样本少 / 两侧都是个体因素}，不硬给方向。
- 无归属主线但业绩扎堆的方向：{模型临时归纳的 cluster，如"养殖周期反转"}——不落台账，只在报告里点名，是潜在新主线线索。

## 三、业绩优秀个股（强 / 中 / 观察 三档）

### 强（加速 + 主业驱动 + 非低基数）

- **{名称 代码}（{type}）**：当年累计同比 +X%、单季度同比 +Y%（Q{n} {加速/减速}）、环比 +Z%。{一句可持续性判断：主业量价/新产能驱动，最近实际期营收 +R% 同步}。{若取了 cninfo 扣非：扣非 A~B 亿 贴近/低于归母 C~D 亿，含金量高/有水分}。caveat：{如需结合估值、基数、一次性成分}。
- ...

### 中（有亮点有瑕疵）

- **{名称 代码}**：{三口径} + {瑕疵：单季减速/营收没跟上/含一次性/基数偏低}。

### 观察 / 存疑（先别当优秀）

- **{名称 代码}**：{扭亏但靠非经常损益 / 预减 / 环比转弱 / base_consistency=diverge 等，说明为什么先放观察}。

## 四、统一 caveat（必写）

- 净利来自**预告（中值、区间）**，营收来自**最近实际报告期（trailing、滞后一季）**，两者基期不同。
- 扭亏/低基数的高同比是弹性，不等于经营质量；含大额一次性损益的已在上面标注。
- 拆解缺口：{income_missing 的票，单季无法拆}；{base_missing/base_nonpositive 的处理}。
- “没有出现在名单里”≠“业绩差”——很多业绩平稳的公司不触发预告披露。
- 本报告只做业绩优秀度分档与持续性判断，不含买卖建议、目标价、仓位。
```

## 写作要点

- **每只必给三口径**（当年累计同比 / 单季度同比 / 环比）+ 一句可持续性。只丢一个同比数字不合格。
- **单季 vs 累计的方向对比要显性说**：加速还是减速，是这份报告最有信息量的地方。
- **绝对额兜底**：扭亏/负基数用“上年亏 X → 今年盈 Y”讲，不硬套百分比。
- **主线归纳靠业务事实**：同一涨价链/景气方向的票放一起说，别按申万/概念现成标签堆。
- **行业趋势写归因，不写计数**：“强3/弱1”只是入口，报告里要说出强表现的共性驱动是什么、弱表现是行业性还是个体事故、两侧交叉验证后方向是否成立（方法论见 `methodology.md` §九）；与落台账的 `theme_trends` 保持同一结论。
- **区分脑手**：脚本给的是数字与护栏；哪只优秀、原因可不可持续、要不要降档、行业趋势判什么方向，是你（模型）的判断，要写出理由。

## 一个填好的片段示例

> ### 强（加速 + 主业驱动）
>
> - **孚日股份 002083（预增）**：当年累计同比 +60%、单季度同比 +80%（Q2 明显加速）、环比 +18%。家纺主业稳健之外，VC（电解液添加剂）随行业价格中枢上移、毛利率抬升是主要增量，属主业量价驱动；扣非净利 3.62~4.09 亿、几乎贴住归母 3.69~4.18 亿（cninfo，med），说明利润里基本没有一次性水分，含金量高；最近实际期（Q1）营收 +3%、还没完全反映涨价，利润弹性主要来自毛利。caveat：VC 价格是周期变量，需盯价格持续性；估值另判。
>
> ### 观察 / 存疑
>
> - **富祥股份 300497（扭亏）**：上年同期亏 0.07 亿 → 今年 H1 预盈，累计同比因负基数不计百分比；环比 +110% 有改善，但属扭亏低基数，含金量要看 change_reason 是否主业修复而非一次性。先放观察，待单季连续改善验证。
