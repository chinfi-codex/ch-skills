# 基本面 × 资金面交叉验证：这份业绩被定价了多少

选出业绩好的公司只是一半。另一半是看股价对这份业绩反映到了什么程度：市场是还没注意到、正在用跳空确认、早在公告前就涨完了，还是资金已经跑到业绩前面去了。同样是"强"档，处在这四种状态里的含义完全不同。

本文件只讲怎么读 `price_context.py` 给出的量价证据。估值高低的判断在 `pricing.md`，两者最后合并。全部结论描述的是"价格与业绩的关系"，不是买卖点。

## 一、证据（`reports/price_context_<P>.json`）

每只股票按公告锚点分成若干事件（`events.forecast` 预告首次披露、`events.formal` 正式报告披露），每个事件有三段：

| 段 | 字段 | 含义 |
|---|---|---|
| **公告前** | `run_up.d20/d60/d120/d250.ret_pct` | 截至反应日前一交易日收盘的 N 日涨幅（后复权） |
| | `run_up.*.excess_pp` | 同期减去沪深300 涨幅，单位百分点 |
| | `pre_position.pos_pct` / `from_high_pct` | 公告前收盘在近 250 日高低区间的位置；距 250 日最高点的回撤 |
| | `pre_vol_ratio_20_120` | 公告前 20 日均量 / 120 日均量，量能是在放大还是萎缩 |
| **公告时** | `reaction.gap_open_pct` / `day_pct` | 反应日（公告日当天或之后第一个交易日）开盘跳空、全天涨幅 |
| | `reaction.vol_ratio_20d` | 反应日成交量 / 公告前 20 日均量 |
| | `reaction.gap_dir` / `gap_status` | 跳空方向（≥2% 计）与是否回补 |
| **公告后** | `post.since_pct` / `since_excess_pp` | 公告前收盘至今的涨幅与超额 |
| | `post.from_post_high_pct` / `trading_days` | 距公告后最高点的回撤、公告后经过的交易日 |

另有 `current`（今天的区间涨幅、位置、相对 20/60/120 日均线、60 日均线斜率）和 `valuation.decomposition`（近 120 个交易日市值变化拆成 TTM 盈利变化 × PE_TTM 变化，`rerating_share` 是估值变化占市值变化的对数份额）。

## 二、三段读法

### 1. 公告前：市场事先知道多少

业绩不是公告那天才被知道的。行业价格、产业链数据、调研、同行报表都会提前泄露景气，所以先看公告前的涨幅：

- **公告前已显著上涨**：60 日超额超过 +30 个百分点、或 120 日超额超过 +50 个百分点，且位置在区间上部（80% 以上）。这份业绩大概率已被部分甚至充分预期，行业景气型利好尤其如此。
- **事先预期有限**：60 和 120 日超额都在 ±10 个百分点以内，位置中低。
- **事先偏悲观**：明显跑输大盘、位置低。市场要么不相信这份业绩，要么在担心别的事。

这些阈值是读数的参照，不是硬规则：大盘股和小盘股的波动尺度不同，高波动赛道要把阈值放宽，判断时说明用的是哪种尺度。

**涨幅与业绩增速对照**：股价 120 日涨了 150%，而利润只增长 30%，说明涨幅主要来自估值抬升而不是业绩。用 `valuation.decomposition` 量化：

- `rerating_share` 高于 0.6：涨幅主要靠估值扩张（预期、叙事、主线资金），业绩只解释了一小部分。
- `rerating_share` 低于 0.3：涨幅主要由盈利增长推动，属于业绩推动型。
- 只有市值变化超过 10%、且估值和盈利朝同一方向变动时才给份额；否则 `rerating_share` 为空并附 `rerating_note`，这时直接读 `pe_ttm_change_pct` 和 `ttm_earnings_change_pct` 两项：比如市值下跌而盈利大增，说明估值在收缩、市场在给这份业绩打折。
- 注意 PE_TTM 的盈利口径要等正式报告披露才更新，预告期的 TTM 盈利还没计入本季增长，所以预告期算出的 `rerating_share` 会偏高。读的时候要按本季预告增速粗略修正，并在结论里说明。

**量能**：公告前 20 日均量明显高于 120 日均量（比值 1.5 以上）且股价上涨，说明资金提前进场，可能是行业轮动，也可能是信息提前扩散；比值低于 0.7 说明关注度低。

### 2. 公告时：市场怎么回答

| 反应 | 含义 |
|---|---|
| 向上跳空、未回补、放量 | 业绩超出原有预期，资金用真金白银确认 |
| 向上跳空但当天就回补、或高开低走（全天涨幅明显低于开盘跳空） | "利好兑现"：业绩不错，但预期更高或早被买进 |
| 没有跳空 | 要结合公告前：涨幅已大，是已经定价；涨幅很小，是还没被注意到，或者被看穿了问题 |
| 向下跳空而业绩并不差 | 市场预期更高；或者对含金量、现金流有疑虑；或者行业逆风盖过了个股业绩 |

### 3. 公告后：确认还是证伪

- 公告后持续跑赢（`since_excess_pp` 为正且扩大）、离公告后高点不远：定价在延续。
- 跳空后很快跌回公告前收盘下方：断层失效，哪怕业绩很好也要降低"市场认可"的判断。
- `trading_days` 只有一两天时，"未回补"还没经过检验，不能写成"确认"。

## 三、业绩 × 价格的组合判断

把业绩档位和价格状态放在一起，归入下面几类之一（这就是每家公司"市场反映"一段的结论）：

| 组合 | 结论 | 读法 |
|---|---|---|
| 业绩强，公告前平淡或偏弱，公告时向上跳空未回补 | **定价进行中（低位启动）** | 预期差正在修复，后续看正式报告能否把推断变成确认 |
| 业绩强，公告前已有上涨但不极端，公告时继续向上 | **定价进行中（趋势加速）** | 原有趋势被业绩确认，重点看估值是否开始透支 |
| 业绩强，公告前大涨、位置高，公告时无反应或高开低走 | **已基本定价 / 提前透支** | 业绩被提前买进，公告成了兑现点；估值分位高、`rerating_share` 高时偏向"透支" |
| 业绩强，公告前跑输、公告时也没反应 | **尚未定价** | 要分辨是"没被发现"（小市值、冷门行业、信息少）还是"被看穿"（扣非差、现金流差、一次性），后者市场是对的 |
| 业绩中或观察，股价却大涨 | **资金先行** | 市场在交易更远的预期或主线叙事，需要后续业绩接力，一旦接不上回撤风险大 |
| 业绩弱，股价也弱 | **一致偏弱** | 基本面和资金方向一致，没有分歧可言 |

## 四、行业 β 与个股 α

超额收益是相对沪深300 算的，里面包含行业整体的涨跌。行业级景气（比如某种产品全行业涨价）会让整个行业一起上涨，这时个股的大幅超额主要是行业 β，在定价行业景气，而不是在定价这家公司本身。

判断方法：从 `season_<P>.json` 里挑同行业的几家，一起跑 `price_context.py`，比较它们的公告前涨幅。全行业涨幅相近，说明市场在交易行业逻辑；个股明显超出同行，才是对个股业绩的额外定价。

## 五、一个季度的两个锚点

同一家公司一个季度可能有两个锚点：预告和正式报告。

- **预告是第一次获知**：事先涨幅和公告反应以 `events.forecast` 为准，这是"业绩有没有被提前定价"的主要证据。
- **正式报告主要是验证**：如果预告时已经充分反应，正式报告即使符合预期也可能平淡甚至下跌；如果正式报告出现第二次明显跳空，说明质量信息（现金流、毛利率、扣非）超出了预告阶段的预期，方向与质量判断对照着读。
- **只有正式报告、没有预告**：正式报告日是唯一锚点，但公告前涨幅依然是"事先知道多少"的度量。

## 六、局限，必须如实写

- 复权因子取不到时（`adjusted=false`），跨越除权或送转的窗口涨幅会失真，要点明。
- 次新股不足 250 根 K 线，一年位置和 250 日涨幅不可用。
- 停牌期间没有 K 线，复牌后的跳空包含停牌期间的所有信息，不能全部归因于业绩。
- 沪深300 是大盘基准，对小盘股会带风格偏差：小盘普涨时小盘股的超额会被高估。
- 这里只有量价，没有主力资金流向、北向持股这类数据（可靠的高频数据拿不到），不要编造资金流向结论。
