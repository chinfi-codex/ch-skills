# 日报模板

```markdown
# 涨停强势池日报 · {YYYY-MM-DD}

=={一句话结论：池子今天整体偏进攻还是退守；新进几只、移出几只；最值得盯的一两只票和原因。}==

## 介入提醒（形态参考）

{每条信号一个 bullet，按质量从高到低排列。格式见 references/entry_signals.md「提醒的写法」。}
{没有信号时写：今日池内没有出现突破或缩量回踩信号。}
{临近突破单独列在最后，写成"明天盯 XX 价位"。}

> 以上为形态提醒，不构成买卖建议。

## 今日新入池（{n} 只）

{每只一个 bullet：名称（代码），几点封板、成交多少亿、换手多少、含当天的 5 日涨幅；为什么涨停；挂在哪条主线、主线处于什么阶段。}
{如果当日 degraded=true：写明首次封板时间取数失败、今日未执行入池扫描。}
{near_miss 中值得一提的（比如只因为 10:31 封板而落选的大成交额票）可以在节末用一句话带过。}

## 移除与预警

**今日移除**

{每只一个 bullet：触发了哪条规则、关键价位、在池里待了几天、入池以来最终涨幅。人工移除的写明证据来源。}

**预警中**

{每只一个 bullet：触发条件、已经预警几天、明天什么情况下会被移除、什么情况下会解除。手动股命中移除条件的，写"建议移除"。}

## 池内全景

| 代码 | 名称 | 来源 | 入池天数 | 入池以来 | 距高点 | 定性 | 主线 / 阶段 |
|---|---|---|---:|---:|---:|---|---|

{按定性排序：健康 → 分歧 → 预警 → 走坏。表后用两三句话总结池子的整体状态，比如"健康的票集中在机器人主线，分歧的大多是上周入池的算力票"。}

## 消息面

{只写有增量的消息，按票归类。每条写清楚分类（催化兑现 / 新催化 / 题材证伪 / 实质利空）、内容、来源和日期。}
{全池都没有增量消息时写：今日池内无重要公告或消息。}

## 数据说明

{有才写：取数降级、停牌票、主线数据日期和报告日期不一致、跟踪报错的票。}
```

## 写作要点

- 一句话结论用 `==高亮==` 包起来。
- 介入提醒放在最前面，因为它最需要行动。
- 全景表之外，正文里每段最多带两三个关键数字。
- 规则结论（脚本给的 active / watch / removed）和模型定性（四档）分开写，不要混在一句话里。
