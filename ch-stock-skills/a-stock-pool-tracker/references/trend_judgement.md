# 走势四档定性口径

`pool_track.py` 的 `metrics` 是事实，这份文档告诉模型怎么把事实读成"健康 / 分歧 / 预警 / 走坏"。四档是模型的解读，和脚本的规则状态（active / watch / removed）是两套东西：规则管进出，四档管"现在该怎么看它"。

## 先看三条线

涨停股入池后，有三条线决定它的命：

1. **涨停价**（`limit_price`）：涨停实体的顶部。强势票回踩到这里不破，说明涨停当天追进来的资金没跑。
2. **涨停日最低价**（`entry_low`）：涨停实体的底部。跌破它，等于把涨停当天的所有买盘都套住了，规则直接移除。
3. **启动价**（`launch_price`）：涨停前一天的收盘价。跌到这里，这次涨停就算完全白涨了。

`vs_entry_low_pct` 和 `vs_launch_pct` 告诉你现在离后两条线有多远。

## 四档

### 健康

站在 MA5 或 MA10 上方，回撤不深（一般在 8% 以内），下跌的日子缩量、上涨的日子放量。再次涨停（`relimit_today`）或刚创新高的票通常在这一档。

典型写法："连续三天沿 MA5 上行，回撤只有 3%，量能温和，走势很健康。"

### 分歧

出现了一些不协调，但关键位置没破。常见的几种情况：

- 高位放量但收得不好，比如冲高回落、长上影；
- 缩量回踩到 MA10 或涨停价附近，还没确认守住；
- 横盘时间变长，`days_since_peak` 超过 5 天，但量也一起缩。

分歧不等于坏。主线还在"主线确认"或"再聚焦"阶段时，分歧多半是换手；主线进入"高位分歧"或"退潮"时，分歧要往坏处想。

### 预警

已经出现一个明确的负面信号，但还没到规则移除的程度：

- 收在 MA20 下方，或者跌破涨停价；
- 一根放量阴线（`amount_ratio_5d` ≥ 2 且跌幅较大）；
- 横盘超过 10 天，重心在往下走；
- 消息面出现"题材证伪"，比如互动易回复"不涉及"。

规则状态为 watch 的票一般至少是预警档。规则还是 active、但模型看到上面这些情况，也可以判为预警，并写清楚理由。

### 走坏

逼近或跌破涨停日最低价、回撤超过 15%，或者主线已经退潮而个股放量下跌。规则当天把它移除的，自然是走坏档。手动股命中移除条件但规则只给了 watch 的，也写"走坏"，并注明"建议移除"。

## 量能怎么读

- `amount_ratio_5d` 是今天成交额对前 5 日均额的倍数。下跌日小于 0.7 是缩量，大于 1.5 是放量。
- `amount_vs_entry` 是今天对涨停日成交额的比例。回踩时降到 0.5 以下，说明卖盘已经很少了。
- 放量下跌比放量上涨更值得重视：一根 2 倍量的阴线，往往比三根小阳线更能说明问题。

## 主线背景

`theme_state.state` 来自 daily-market-sense 的主线生命周期：

| 主线状态 | 对个股定性的影响 |
|---|---|
| 低位启动 / 在场候选 | 个股的分歧可以宽容，主线还在找方向 |
| 主线确认 / 再聚焦 | 最有利的环境，缩量整理大多是蓄势 |
| 高位分歧 | 个股和主线一起分歧时，降一档看 |
| 退潮 / 沉寂 | 除非个股有独立催化，否则健康也只看成分歧 |
| 修复 | 看个股能不能比主线先站回 MA10 |

`theme_state` 为空，说明这只票还没挂主线，或者当天的主线数据缺失。报告里要说明是哪一种。
