# 正式财报解读与"优秀个股"判断细则

SKILL.md 只放纲要，这里放判断锚点、拆解语义、字段字典和边界处理。模型据此**逐股判断并排序**，脚本不替你下结论。

## 一、三口径 × 四条线：定义与拆解语义

预告只给一个累计净利区间。正式财报给的是四条线各自的完整时间序列：

| 线 | 字段来源 | 为什么要单独看 |
|---|---|---|
| **营收** | `income.revenue` | 增长的源头。利润涨而营收不涨 = 靠降本或一次性 |
| **归母净利** | `income.n_income_attr_p` | 表观利润，市场先看它 |
| **扣非净利** | `fina_indicator.profit_dedt` | 剔除处置/补助/公允价值后的主业利润，含金量的权威口径 |
| **经营现金流** | `cashflow.n_cashflow_act` | 利润有没有变成钱。利润的测谎仪 |

每条线都拆成三个口径：

- **当年累计同比**：本报告期累计 vs 上年同期累计（H1 vs 去年 H1）
- **单季同比**：最新单季 vs 去年同一单季（Q2 vs 去年 Q2）
- **环比**：最新单季 vs 上一单季（Q2 vs 当年 Q1）

**拆解公式**（单季 = 当期累计 − 上一累计期）：

- Q1：单季 = 累计本身；上一单季要**跨年**取上年 Q4 = 上年年报累计 − 上年三季报累计
- Q2：单季 = H1 − Q1；Q3：单季 = 三季报 − H1；Q4：单季 = 年报 − 三季报

**缺基数就是缺。** 上一累计期取不到时 `single_q_*` 为 `null`（`*_note=cur_missing/base_missing`），脚本不会拿累计冒充单季——那会把 H1 的利润当成一个季度报出去。次新股、刚上市或上游未收录的都会命中这条。

**为什么单季比累计重要**：累计被上半段拖累或抬高，最新单季才反映当下经营。口诀：
- 单季同比 > 累计同比 → **加速**（`hits` 里的 `np_accelerating` / `rev_accelerating`）
- 扣非单季同比 > 归母单季同比 → 核心经营比表观更强，加分
- 营收与利润单季同时加速 → 量价共振，比"利润独秀"健康得多
- 单季同比 < 累计同比 → 高增在减速，哪怕累计仍是大正数也要点破

## 二、利润质量三件套（季报独有，最该先看的一块）

预告只能靠读变动原因文本猜含金量。正式财报可以直接量。三项一致向好才叫"扎实"（`quality_call=扎实`），任一背离就要降档并写明。

### 1. 扣非占归母 `quality.dedt_ratio_pct`

- **≈ 90%–100%**：利润几乎全是主业，含金量高。
- **明显低于 80%**：`quality.non_recurring_yi` 就是那笔差额。要追问它是什么——`report_pdf.py --sections nonrecurring` 直接读非经常性损益明细表，看是资产处置、政府补助、投资收益还是公允价值变动。**不要凭差额大小猜性质**。
- **扣非 ≤ 0 而归母 > 0**：利润全部来自非经常损益，这是比任何 PE 都强的警示，必须写出来。
- **扣非增速 > 归母增速**：上年同期一次性收益多、今年主业顶上来了，是加分项。

### 2. 经营现金流覆盖 `quality.ocf_to_np_pct`

- **≥ 100%**：利润全部甚至超额变成了现金，最健康。
- **60%–100%**：正常区间，尤其季节性备货或回款周期长的行业。
- **< 50% 且利润高增**：要警惕。结合 `cash_sales_to_revenue_pct`（销售商品收到的现金 / 营业收入）和应收增速一起看。
- **为负而利润为正**（`hits` 的 `ocf_negative_while_profitable`）：典型的纸面利润信号。**但单季 OCF 波动很大**——工程类、季节性备货、集中付款都会造成单季为负，要看累计口径和历史同期，不要只凭一个季度定性。

### 3. 应收与存货 vs 营收 `balance_signals.*_vs_revenue_gap_pp`

`gap_pp = 该科目同比 − 营收累计同比`：

- **应收 gap 明显为正**（默认阈值 +20pp）：收入确认了但钱没回来，可能放宽了信用政策换收入。
- **存货 gap 明显为正**：分两种——为下一季度放量备货（配合合同负债上升、订单饱满）是好事；卖不动积压（配合营收下滑、毛利率下行）是坏事。**必须结合合同负债和毛利率方向一起判**，单看存货增速会误判。
- **两项都为负**：收入质量好，回款和周转都跟得上。

**`quality_call` 判定参考**：三项都好 = 扎实；一项轻微背离且能解释 = 尚可；一项明显背离（OCF 为负 / 扣非占比 < 60% / 应收 gap > 30pp）= 存疑；两项以上背离，或利润高增全靠非经常损益 = 虚高。

## 三、盈利能力边际（水平之外看方向）

- **单季毛利率**（`margins.gross_margin_single_pct`）由累计差分自算：`(单季营收 − 单季营业成本) / 单季营收`。**不用 `fina_indicator.grossprofit_margin`**，那是累计率，会把季度拐点抹平——而拐点正是要找的东西。
- `gross_margin_single_yoy_pp` / `gross_margin_single_qoq_pp` 是同比/环比的**百分点**变化。抬升 ≥ 1pp 命中 `margin_expanding`。
- **金融类公司没有 `oper_cost`**，毛利率一律为 `null`，不是数据缺失，是口径不适用，报告里别硬套。
- **四项费用率**（销售/管理/研发/财务，占营收比）与其同比 pp：毛利率抬升 + 费用率下降 = 经营杠杆；毛利率抬升但费用率同步上行 = 增长是花钱买的，要问投入产出。
- **研发费用与增速**：成长股的投入前置证据。研发增速远高于营收增速可能压当期利润但换未来，要和管理层的在研项目表述（`report_pdf.py --sections rd`）对上。
- **ROE**：`roe_cum_pct` 是累计口径**未年化**；`roe_annualized_pct` 是 ÷季数×4 的简单年化，**未调季节性**——白酒 Q1 重、空调 H1 重、出版教育下半年重的公司会被系统性高/低估。引用时标口径。

## 四、资产负债表前瞻信号（利润表读不出来的下几个季度）

| 信号 | 字段 | 怎么读 |
|---|---|---|
| **合同负债** | `balance_signals.contract_liab`（缺失回落 `adv_receipts`） | 客户已付款未交货 = 在手订单，营收的领先指标。同比 ≥ +20% 命中 `orderbook_building` |
| **在建工程** | `cip`（`cip_total` 优先） | 扩产周期。同比 ≥ +30% 命中 `capex_cycle`，意味着中期产能兑现，也意味着当期折旧压力在后面 |
| **固定资产** | `fixed_assets` | 在建工程转固的去向，和 cip 一起看扩产节奏 |
| **存货** | `inventories` | 结合 gap_pp 与合同负债分辨备货/滞销（见 §二.3） |
| **应收** | `receivables`（含票据口径优先） | 收入质量（见 §二.3） |
| **商誉** | `goodwill_yi` / `goodwill_to_equity_pct` | 占净资产越高，减值风险越大，尤其并购驱动增长的公司 |
| **资产负债率** | `debt_ratio_pct` | `total_liab / total_assets` |
| **净现金** | `net_cash_yi` | 货币资金 − 短期借款 − 长期借款 − 一年内到期非流动负债 |

**时点口径提醒**：资产负债表科目是时点值，不是期间值。它们的"环比"对的是上一个资产负债表日——Q1 的环比对的是**上年末**，不是上年 Q1。脚本已按此处理。

## 五、兑现度（对预告/快报的回测）

`fulfillment.forecast`：

- `in_range`：`above`（超预告上限）/ `within`（落在区间内）/ `below`（低于下限）
- `range_position`：落在区间的哪个位置，0 = 贴下限，1 = 贴上限
- `vs_median_pct`：相对预告中值的偏离百分比
- `change_reason`：预告原文的业绩变动原因，可以拿来对照实际报表验证公司当初的说法

判断要点：
- **超上限 + 现金流同步**：强档的硬证据，公司当初还保守了。
- **贴下限压线（`range_position` 接近 0）+ 营收没跟上**：即便同比亮眼也该降档——公司自己的乐观预期都没兑现足。
- **低于预告**：`hits` 命中 `miss_forecast`，必须在报告里点名，并看股价是否已经反应（`price_reaction`）。
- **无预告**（`fulfillment=null`）：多数公司都没有强制预告义务，这是常态，不是负面信号。`fulfillment` 判 `无预告`。

`fulfillment.express` 是业绩快报与正式报告的差异，通常很小；差异大说明快报口径未经审计调整，值得一提。

## 六、估值：真实 TTM 与年化 PE

正式财报的分子是**已实现的利润**，不像预告是区间中值的估计。两个口径：

- **TTM（头条口径）**：`np_ttm = 上年年报 + 本期累计 − 上年同期累计`，扣非同理。滚动四个季度**已消化季节性**，是正式财报最该用的口径。`pe_ttm_dedt` 是头条，`pe_ttm_np` 作对照。
- **年化（对照口径）**：`本期累计 ÷ 季数 × 4`。**未调季节性**，淡旺季分明的行业会被系统性高/低估。只作对照，引用必须注明。
- `pe_ttm_market` 是 `daily_basic` 的市场口径 PE-TTM。它和 `pe_ttm_np` 应当接近；**明显不一致时以市场口径为准并检查报表取数**（实测格力 7.77 对 7.77、兆易 111.56 对 111.56，这是一条有效的自检线）。
- **`*_note` 要读**：`np_nonpositive`（亏损，不给 PE）、`np_missing`、`mv_missing`。扭亏但绝对利润很小的票年化 PE 会飙到数百上千倍——那是低基数失真，不是"贵"，改讲绝对额。
- 红线：PE 只是估值参照证据，"贵不贵、值不值"要结合成长性与质量由模型判断（个股估值深判用 `a-stock-analyzer`）。

## 七、字段字典（`report_scan.py` 输出）

日期口径先看 `meta`：`ann_cutoff` 是本次披露截止日；`ann_cutoff_stock_count` 是当日新披露家数；`clock_timezone` 固定 `Asia/Shanghai`；`generated_at` 带 `+08:00`。`disclosure_progress_pct` 是披露进度，**写任何结构性结论都必须交代它**。

- 单位：金额类字段一律**亿元**（`*_yi`），已从报表的元统一换算；比率是百分比（`*_pct`），百分点差是 `*_pp`。
- `growth.<line>`：`cum_yi` / `cum_base_yi` / `cum_yoy_pct` / `cum_note`、`single_q_yi` / `single_q_base_yi` / `single_q_yoy_pct` / `single_q_note`、`prev_single_q_yi` / `qoq_pct` / `qoq_note`。`<line>` ∈ `revenue` / `np` / `dedt` / `ocf`。
- `*_note` 枚举：`ok` / `cur_missing`（本期取不到）/ `base_missing`（基数取不到）/ `base_nonpositive`（基数 ≤ 0，百分比无意义，改讲绝对额）。
- `source.sources`：本期已落地哪几个接口（`income` / `fina` / `cashflow` / `balance`）。缺哪个，对应字段就是 `null`——上游滞后所致，下次重跑自动补。
- `screen.hits`：机械阈值命中，全部可由 `--th-*` 调整。正向 `rev_single_yoy_ge` / `np_single_yoy_ge` / `dedt_single_yoy_ge` / `np_accelerating` / `rev_accelerating` / `np_qoq_positive` / `dedt_clean` / `ocf_backed` / `roe_ge` / `margin_expanding` / `orderbook_building` / `capex_cycle` / `gap_up` / `beat_forecast`；负向 `ocf_negative_while_profitable` / `margin_compressing` / `receivable_outpacing_revenue` / `inventory_outpacing_revenue` / `loss_making` / `revenue_declining` / `gap_down` / `miss_forecast`。
- `screen.rank_score` = 增长分×2 + 质量分×2 + 边际分 + 市场分 − 罚分。**它只是把 5500 家收敛成模型能读的候选池的排序，不是优秀度结论。** 换阈值就换排名，这是设计使然。

## 八、业绩-股价断层（正式财报版）

核心命题和预告一致：观察的不是业绩本身，而是「业绩 × 股价反应」。锚点是**实际披露日**（`price_reaction.anchor_ann_date`），正式财报多在盘后披露，反应落在次一交易日。

| 字段 | 含义 |
|---|---|
| `gap_open_pct` | 反应日开盘 vs 前一交易日收盘的跳空幅度 |
| `r_day_pct` / `r_vol_ratio` | 反应日全天涨幅 / 相对前 20 日均量的放量倍数 |
| `pre_pos_pct` + `pre_pos_bars` | 披露前收盘在窗口内高低区间的分位，以及该分位是用多少根 K 线算的 |
| `pre_mom_20d_pct` | 披露前 20 个交易日动量 |
| `since_ann_pct` | 披露前收盘至最新收盘的累计涨幅（是否已充分定价） |
| `gap_dir` | `up` 超预期 / `down` 不及预期 / `null` 无断层 |
| `gap_status` | `intact` 未回补 / `filled` 已回补 / `none` / `pending`（披露后尚无交易日） |
| `trading_days_since_r` | 断层后经过的交易日数 |

判断要点：

- **有效性看"未回补"**。`intact` 且放量 = 市场用真金白银确认；`filled` = 断层失效，哪怕业绩很好也降档观察。
- **新鲜度必须诚实标注**。`trading_days_since_r` 只有 1–3 天时"未回补"没经过检验，别写成"断层确认"。
- **`pre_pos_bars` 决定分位可信度**。默认 `--price-lookback 380` 约给一年样本；不足 240 根时分位只是"窗口内位置"，不是年内位置，要说明。
- **"未反应"是另一类机会**。业绩判强、却无跳空且 `since_ann_pct` 很小 = 市场还没定价。这类要结合质量三件套分辨是"未被发现"还是"被识破"（质量有硬伤的高增长，市场不给反应是对的）。
- **主线加持是胜率放大器**。断层 + 在场主线内 + 强档排最前；断层但无主线归属的，是待验证的独立逻辑。

## 九、报告期行业趋势：强/弱表现分别归因 + 交叉验证

观察单位是主线，窗口是一个报告期。一条主线里的股票按断层方向分成**强表现**（向上断层）与**弱表现**（向下断层）两组。`verdict.py context` 的 `to_judge_themes` 已分好组。

**第一步：强表现组归因。** 逐只看驱动因子——涨价 / 放量 / 新客户 / 降本 / 一次性。判断组内有没有**共性**：多只指向同一行业级驱动 = 行业向上的正面证据；各说各话或主要靠一次性收益 = 只是个股 alpha 扎堆。

**和预告 skill 的差别**：预告自带《业绩变动原因》文本，归因可以直接读。正式报告只给数字，叙事在管理层讨论里。所以归因材料是 ①上一轮模型自己写的 `reason`、②机械 `hits`（比如"三只都命中 margin_expanding + orderbook_building"本身就是共性证据）、③**不够就用 `report_pdf.py --sections mdna` 把管理层原话调出来**。不要靠数字编驱动故事。

**第二步：弱表现组归因。** 分辨是**行业级拖累**（价格战、需求走弱、成本挤压、库存过剩）还是**个体事故**（单一客户流失、减值、停产、诉讼、高基数错杀）。后者反衬"行业没问题、是它自己的问题"。

**第三步：交叉验证定方向。**

| | 弱侧=个体事故 / 无弱表现 | 弱侧=行业级拖累 |
|---|---|---|
| **强侧=行业级共性** | **向上**：行业景气确立，方向与驱动互相印证 | **分化**：行业在换挡——找强弱分界线（环节/价格带/客户结构/技术路线） |
| **强侧=个体因素** | **证据不足**：只有个股逻辑，无行业级信号 | **向下**：行业基本面恶化，强表现是特例，对组内强档要额外挑剔 |

**第四步：用质量和主线状态再校验。**

- 强表现若主要靠一次性损益（`quality_call=虚高`）→ 从"行业级共性"里剔除。
- 强表现若 OCF 普遍跟不上利润 → 行业方向可以判"向上"，但要在 `cross_validation` 里写明"利润先于现金，下一期盯回款"。
- 已回补的断层降权。
- 与主线生命周期交叉：向上 + 主线在场（★）= 基本面与资金共振；向上 + 主线退潮/无主线 = 基本面领先于资金，潜在新主线线索；向下 + 主线仍热 = 警惕补跌。

**输出与克制**：结论写进 `theme_trends[]`（格式见 `verdict_and_html.md`）。样本 ≤2 只就标 `confidence=low`；"证据不足"是合法结论。

## 十、报告期产业结构综述（全样本 → 宏观分组 → 强弱结构）

§九是"一条主线内"的显微镜，这一节是"整个报告期"的广角镜。原料是 `industry_summary`（按行业的确定性计数与中位数）。

**关键差异：季报没有样本偏差。** 预告是触发式披露，只有大增大减的公司会出现，所以那份综述只能谈"边际变化的结构"，还得写"某行业缺席≠没事"。**正式财报是强制全市场披露，5500 家全在样本里**——所以这份综述可以直接谈全经济体量的结构。代价是必须交代**披露进度**（`meta.disclosure_progress_pct`）：进度 30% 时早披露的多是小盘和业绩好的，结构判断会失真；进度 95%+ 才谈得上全貌。

**第一步：分侧扫描。** 把行业分三桶——正向扎堆（`growth_n` 占比高、增速中位数高、`gap_up_n` 多）、负向扎堆（`decline_n` / `loss_n` 聚集、`gap_down_n` 多）、分化或样本少。

**第二步：聚宏观组。** stock_basic 行业口径太细（半导体/元器件/通信设备/专用机械是四个行业），综述要按**业务事实**聚成宏观组。分组以当期样本实际为准，不硬套固定名字。

**第三步：组内强弱结构判断。**

- **强组**要说清共性驱动，且驱动要能被组内多个行业的个股交叉印证；顺带看 `gap_up_n`（市场认不认）和 `ocf_backed_n`（利润有没有现金支撑——这是季报综述比预告综述更硬的一层）。
- **弱组**读负向共性，再找筑底证据：`np_single_yoy_median` 是否在收窄、`margin_up_n` 占比是否回升、`orderbook_n`（合同负债在建）是否抬头。有证据才说"接近筑底"。
- 与主线台账交叉：强组同时是在场主线 = 置信更高；强组完全不在主线注册表里 = 基本面领先于资金，值得点名。

**第四步：写综述（(a)(b) 式分条 + 前瞻有据）。** 每条 = 宏观组 + 方向 + 依据（家数/增速中位/断层计数/现金覆盖家数）+ 一句前瞻判断与证伪条件。结论成文落 `period_overview`，HTML 页首与 Markdown 报告开头展示同一结论。红线不变：只判产业方向与基本面变化，不给配置/买卖建议。
