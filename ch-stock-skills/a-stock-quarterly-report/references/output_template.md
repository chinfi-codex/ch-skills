# Markdown 报告模板（叙事版）

HTML 是一期一页的可交互产物；需要叙事版时按这个骨架写。两者同源于 evidence + verdict 台账，结论必须一致。文风要求见 SKILL.md「输出规范」——讲人话，同项用 list 但每条说完整话，不要横杠拼字段。

---

## 骨架

```
# {period_label} 正式财报观察（截至 {ann_cutoff}）

## 一、这一期看下来
## 二、产业结构综述
## 三、优秀个股 shortlist
## 四、需要警惕的
## 五、口径与缺口
```

---

### 一、这一期看下来

三到五句话把整体判断说清楚，必须包含：

- **披露进度**：已披露 N 家 / 全市场 M 家（X%）。这是全篇的置信度前提——进度 0.4% 和 99% 的结论不是一回事，早披露的天然偏向业绩好、体量小的公司。
- 本期最一致的信号是什么（比如"利润表比现金流量表好看，且集中在制造业中游"）。
- 强档有几只、质量真正扎实的有几只——**这两个数不该相等**，差额本身就是信息。

不要在这一节堆数字，也不要写"总体来看""值得注意的是"。

### 二、产业结构综述

直接用落台账的 `period_overview` 全文，保持同一口径。分条写，每条 = 宏观组 + 方向 + 依据（家数 / 增速中位 / 断层计数 / 现金覆盖家数）+ 前瞻判断与**证伪条件**。

季报是强制全市场披露，**不需要**预告那套"触发式披露、样本偏向剧烈变化"的 caveat；但披露进度必须交代（见上）。

### 三、优秀个股 shortlist

按「强 / 中 / 观察」分档，每档一个 list。**每只必须同时交代增长与质量**——只报同比不报质量是这个 skill 最不该犯的错。

每只的写法（一段完整的话，不是字段拼接）：

> **益生股份（002458.SZ）· 强 · 扎实**
> Q2 单季营收 9.13 亿、同比 +30.8%，归母 2.04 亿、同比 +957%，环比还翻了近一倍。质量三件套全绿：扣非占归母 99.7%，经营现金流覆盖净利 150%，存货增速比营收慢 26pp。单季毛利率 32.1%、同比抬升 18.7pp，是养殖周期价格上行直接传导到报表。实际数超出自家预告上限 7.9%。
> *caveat*：同比 957% 是上年同期几乎不赚钱的低基数镜像，绝对额 2 亿才是真实体量；扣非 TTM PE 25 倍已隐含景气延续的假设；披露日跳空 +3.4% 当天就被回补，市场并没有为这份超预告的报表付更高的价。

要点：

- 三口径给**单季**为主（累计只在有必要时补），营收和利润都要给。
- 质量三件套（扣非占比 / 现金覆盖 / 应收存货 vs 营收）一句话带过全部三项，任一背离必须点破。
- 有预告的必须写兑现度落在哪一侧、离中值多远。
- PE 用**扣非 TTM**，年化只作对照且标"未调季节性"。
- 有断层的写幅度 + 是否回补 + 新鲜度（D+n）；`trading_days_since_r` 只有几天时不要写成"断层确认"。
- 归属主线写清楚，`null` 就写"暂无主线归属"——那是"业绩强但没人看"的正向信号，不是缺陷。
- caveat 单起一行，必须有。没有 caveat 的强档通常是没看仔细。

### 四、需要警惕的

不是把"剔除"档抄一遍，而是挑**有教育意义**的组合写成 list：

- 高增长但现金流为负的（利润先于现金）
- 营收下滑靠毛利率撑利润的（改善走不远）
- 存货或应收明显跑赢营收的（收入质量存疑）
- 落在预告区间下沿压线的（公司自己的乐观预期都没兑现足）
- 扣非远低于归母的（要说清那笔差额是什么，查过 `nonrecurring` 才有资格说）

每条点名具体公司 + 那个刺眼的数字 + 一句为什么它重要。

### 五、口径与缺口

as-is 列出来，不要藏：

- 披露进度与样本家数
- 上游未收录本期报表的家数（`meta.statements_incomplete`）——空值不是零增长
- 基础信息缺失的代码（新上市股）
- 金融类公司无 `oper_cost`，毛利率为空是口径不适用
- `pre_pos_bars` 不足一年时，位置分位只是窗口内位置
- `base_nonpositive` 的公司只能讲绝对额，不能讲同比
- 主线台账为空时（daily-market-sense 没跑）主线归属一律缺失

## 红线

不写买入/卖出/止损/目标价/仓位。可以写"业绩优秀度分档""质量成色""持续性待验证条件""需结合估值另判"。

数字之外的话（某产品线放量、管理层指引、大客户占比）必须来自 `report_pdf.py` 取到的原文，并标公告标题 + 页码区间；没取原文就只讲数字能支持的结论。
