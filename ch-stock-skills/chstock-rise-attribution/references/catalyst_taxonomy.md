# 归因两大角度细则

本文档定义个股单日上涨归因的两大角度六个子项。每个子项列出**判定锚点**、**可支撑证据**、**不可支撑证据**、**置信度上限**。SKILL.md 的工作流第 9 步对照本文件给每条催化打分档；最终回答**只输出高 / 中置信**，低置信、推测、未解释一律不进回答（仍写入 Pack 内部记录）。

判定要求遵守**成对原则**：

- **时间窗口对齐** + **逻辑机制可解释** → 高 / 中置信 → **进回答**
- 任一缺失 → 低置信 → **不进回答**（只记 Pack）

输出回答时**强制按"基本面 / 资金面"两段**分别呈现，每条前缀标 `[A1/A2/A3/A4/B1/B2]` 子项标签。

---

# 角度 A · 基本面

按**优先级降序**：A1 > A2 > A3 > A4。多个子项命中时按此优先级排序。

## A1. 产业信息（最高优先级）

**典型催化**：

- 公司公告：业绩快报 / 预告、重大合同 / 订单、回购、股权激励、收购、定增过会、问询回复消除压制、监管函解除、重要股东增持；
- 产业链上下游：核心客户 / 供应商动态、上游原材料价格信号、下游需求拐点；
- 海外对标公司：海外同业财报、海外大客户 CapEx 指引、海外政策影响；
- 公司主动披露：互动易 / IR 明确承认订单、客户、产能（**模糊表述不算**）。

**判定锚点**：

- 公告时间在 T-1 盘后到 T 日盘前（包括 T-1 18:00 后至 T 日 09:25）；
- 涨幅与事件量级匹配（亿元级订单 vs 千万级订单）；
- 公告主体明确为该公司或其关键子公司（持股 > 5%）。

**可支撑证据**：

- 巨潮公告 PDF + 标题；
- 公司官网 IR；
- 互动易 / P5W 明确承认型回复；
- 海外公司财报 / 业绩指引。

**不可支撑证据**：

- 仅有公告标题命中无正文核对；
- 公告发布在 T 日盘后（不构成日内催化）；
- 互动易模糊表述（"持续关注"、"有望"）；
- 旧消息复用（互动易回复时间在 T-15 之外，机制对齐时间不对齐）。

**置信度上限**：高（公司公告 + 海外对标交叉验证）。

---

## A2. 高权重研报

**典型催化**：

- 高权重机构发布深度报告：Citi / 中金 / 华泰 / 东吴 / 国信 / 申万 / 中信 / 高盛 / 摩根士丹利 / 摩根大通 / UBS / Bernstein 等；
- 目标价上调、评级上调；
- 行业首推 / 重点推荐组合纳入；
- 卖方电话会要点流出。

**判定锚点**：

- 研报发布时间在 T-3 ~ T 日；
- 研报核心结论与公司基本面 / 产业变化有可解释的传导机制；
- 多家高权重机构同向（提升置信度）。

**可支撑证据**：

- 研报 PDF（路径 + 机构名 + 报告日期）；
- 多家机构同期同向报告；
- 同一机构连续两份报告口径一致。

**不可支撑证据**：

- 小券商孤证；
- 仅有标题流出无报告原文；
- 与公司公告口径明显矛盾。

**置信度上限**：高（两家高权重机构同向）。单家高权重最多到中。

---

## A3. 行业重要边际变化

**典型催化**：

- 行业景气度拐点（库存周期、需求边际改善 / 恶化）；
- 渗透率突破关键阈值（如 NEV 渗透率破 50%）；
- 技术路线切换（如 800V → 全固态、HBM3 → HBM4）；
- 新规 / 标准出台、产业政策、补贴目录；
- 价格指数拐点（如锂价、硅料、PCB 铜价、海运指数）；
- 关键节点会议（如某车展、某行业大会、某领导人讲话）。

**判定锚点**：

- 边际变化的公开披露时间在 T-3 ~ T 日；
- 该股业务与边际变化的传导机制明确；
- 同板块多只股票同向反应（说明市场已识别）。

**可支撑证据**：

- 行业协会数据、海关数据、统计局数据、Wind / iFind 行业指标；
- chstock-macro-monitor 宏观证据包；
- wiki/02-概念词条、wiki/03-产业链图谱 既有判断；
- 同板块多家公司同步反应的量价证据。

**不可支撑证据**：

- 仅有自媒体观点无第三方数据；
- 边际变化已发酵超过 1 个月（旧消息）；
- 该股业务与变化传导机制弱（强行归因）。

**置信度上限**：中（边际变化往往多源解释才稳）。

---

## A4. 主题概念炒作

**典型催化**：低空经济 / eVTOL / 飞行汽车、人形机器人 / 具身智能、固态电池、AI 算力 / CPO / HBM、AI 应用、华为汽车、小米汽车、出海、国产替代、央国企改革、并购重组等。

> **设计说明**：主题炒作虽然带"炒作"二字，但本质是市场对"未来基本面变化"的预期定价（资金愿意提前为产业趋势付费），因此归入**基本面**而非资金面。

**判定锚点**：

- 主题在 T-3 ~ T 日有新催化（事件、新闻、龙头股表现、监管口径）；
- 该股有可验证的主题暴露（公告、互动易、官网披露过该主题相关业务）；
- 同主题龙头股同步反应（说明资金切到该主题）。

**可支撑证据**：

- 互动易 / 公告披露主题暴露（**即使是旧消息也算，主题切换会重新挖掘历史线索**）；
- WebSearch 命中主题切换的同期新闻 / 龙头股表现；
- 财联社 / 金十电报关于主题异动的快讯。

**不可支撑证据**：

- 公司无主题相关业务披露（强行套主题）；
- 主题已炒作超过 1 个月且龙头已破位（主题切换中）；
- 仅单家自媒体提及，无龙头股配合。

**置信度上限**：中（主题炒作天然带不确定性）。多主题叠加共振时可分子条目罗列，每个子条目独立计分。

# 角度 B · 资金面

## B1. K 线 / 个股资金流

**典型催化**：

- 个股 LV1 资金流：主力 / 游资 / 散户净流入流出（来自证券之星 / 东方财富汇总，非 L2 龙虎榜明细）；
- 量价形态：突破关键阻力、放量加速、缩量回踩、首板 / 连板；
- 技术指标：量比、换手率、连涨节奏；
- 涨停状态：是否封板、几点封板、封单量。

**判定锚点**：

- 量价数据来自 Tushare daily + daily_basic（确定性高）；
- LV1 资金流（主力 / 游资 / 散户）来自当日证券之星 / 东方财富汇总报道；
- 形态描述要可量化（"放量"必须给量比数值，"放量加速"必须给连续 N 日量比走势）。

**可支撑证据**：

- price_window_snapshot.py 输出的 daily / daily_basic；
- WebSearch 命中证券之星 / 东方财富的 LV1 资金流报道；
- 涨停板封单量、封板时间。

**不可支撑证据**：

- 纯主观图形描述（"形态优美"、"走出 N 字"）；
- L2 龙虎榜机构 / 游资席位明细（本 skill 不接 L2，无此能力时不要假装）；
- 单纯 RSI / MACD 等次级指标（不构成催化）。

**置信度上限**：高（量价数据本身确定性高，但解释力中等）。

---

## B2. 板块资金流

**典型催化**：

- 申万一级行业当日 pct_chg、中位数、涨停家数；
- 概念板块异动（同花顺 / 东方财富概念）；
- 板块龙头封板情况；
- 板块净流入 / 北向流入。

**判定锚点**：

- 同申万一级行业 pct_chg 均值显著为正（建议 ≥ +1.5%）；
- 该股涨幅是否在板块涨幅区间内（普涨）还是显著超出（孤立大涨）；
- 板块封板龙头与该股是否同子赛道；
- WebSearch 命中板块异动新闻。

**可支撑证据**：

- price_window_snapshot.py 输出的 industry_peers_on_date；
- WebSearch 命中板块表现、龙头股名单；
- 同板块其他股票同步反应的量价数据。

**不可支撑证据**：

- 板块普涨但该股涨幅显著超出（此时 B2 解释力弱，要回到 A1~A4）；
- 板块封板龙头与该股完全不同子赛道（联动机制弱）。

**置信度上限**：中（板块联动是辅助解释，单独不足以支撑核心结论）。

---

## 优先级与组合规则

1. **孤立大涨**（该股涨幅 >> 板块均值）：基本面权重提升，B2 自动降级到辅助；
2. **板块普涨**（该股涨幅 ≈ 板块均值）：B2 + A3/A4 权重提升，A1/A2 即使有也降级；
3. **板块龙头封板 + 该股同子赛道**：B2 升主因；
4. **多主题叠加共振**：A4 分子条目罗列，每个子条目独立判定置信度，但合计不超过单段 3 条主条目限制。
