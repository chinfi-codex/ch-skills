# 池外新方向主动挖掘

目标：把"现有观察池之外、今晚有赚钱效应的新方向"主动挖出来并给纳入建议。这是本 skill 相对纯逐股复盘的增量价值——你不只想知道自己的票，还想知道纳指科技里**有没有你没覆盖的方向正在起来**。

判定基础：一个"新方向候选" = 模型命名的主题，今晚在纳指科技里有赚钱效应（dollar-volume + 广度，见 `sector_money_effect.md`），而观察池覆盖不到或覆盖不全。

## 三档（按优先级）

1. **新主题缺口**（最高优先）：某主题有 ≥ 3 只强势票、真有 dollar-volume，而观察池**没有任何一组对应它**。
   → "你没覆盖 X 方向，今晚它在纳指科技跑出来了，代表票 A / B / C。"
2. **主题内龙头缺口**：池里有这个组，但今晚**领涨 / 最大 dollar-volume 的票不在池里**。
   → "你 Semi 组覆盖了设备端，今晚领涨的是 AI 互联的 ALAB，不在池里。"
3. **邻接个股补充**：单只强势票，主题贴近某个 pool 组但你没持有。

## 纪律

- **必须有赚钱效应证据**：过 dollar-volume 下限、不是单只低流动性脉冲。先用 `--enrich-tickers` 拿 52 周位置 / 量比 / vs-QQQ 再下结论。
- **必须联网核查**：进建议清单的票走和异动票同一套联网核查（**Tavily 优先**，`python scripts/web_search.py`，WebSearch 兜底；查询同样是事件 / 财报 / 中文补充三套，见 SKILL.md §6），分清是真驱动还是逼空；查不到写"未检索到明确催化，仅价格信号"。
- **区分一日脉冲 vs 多日持续**：`position_52w` 新高 + 放量（量比 ≥ 1.5）+ vs-QQQ 为正 + 有催化 = 强候选；单日跳、量比 < 1、无催化 = 标"单日脉冲，待持续验证"。
  - 反例提醒：52 周新高但**缩量**（量比 < 1）是未确认突破，不能当强候选——如某夜 CRDO +9% 创新高但量比 0.96。
- **只到"建议纳入观察 / 值得下钻"**，不写买卖、不写目标价。
- **纳入理由落到证据**：主题、dollar-volume、vs-QQQ、位置、催化，一条一句人话，别堆字段。

## 跨日持续性（用跨日台账查证）

- 同一新方向连续 2–3 个交易日出现在赚钱效应池 = 更强的纳入候选；单晚出现先观察。
- 用 `scripts/theme_ledger.py`（见 `references/cross_day_ledger.md`）查证持续性：`context --asof` 拿到该主题近期状态与首现日，据此把新方向票标注 `首现` / `连续 N 晚` / `已建议待跟踪`。
- 闭环：上次 `is_new_direction` 的票，本次是延续、纳入还是转冷，写一句——别让建议发完就忘。
