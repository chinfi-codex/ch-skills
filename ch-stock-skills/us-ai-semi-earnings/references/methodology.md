# 判断细则：一家美股 AI/半导体公司的这个季度到底怎么样

SKILL.md 只留了纲要。本文是逐条的判断规则、口径陷阱和分档锚点。

---

## 〇、先认清"这一季"是哪一季

美股这个宇宙里**财年错位是常态而不是例外**。NVDA 的财季二月到四月，AVGO 二月到五月，MU 三月到五月，LRCX 财年六月底结束。三家都管自己那一季叫"Q1"，但它们覆盖的经济时段完全不同。

脚本已经按 **区间中点落在哪个日历季** 做了统一对齐（`CY2026Q2` = 2026 年 4-6 月），和 SEC 自己的 CY frame 口径一致。你要做的是：

- **横向比较只用 `frame`，永远不要用公司自报的 "Q1/Q2"。** 写报告时说"日历二季度"而不是"NVDA 的一季度"，除非在讲这一家自己的事。
- **注意披露节奏差异**。同一个 `CY2026Q2`，TSM 七月中旬就报了，NVDA 要等到八月底。所以任何一天的"本季图景"都是残缺的，`meta.reported_count / universe_size` 必须交代。
- **同比基数由脚本按 `prior_year_frame` 取**，跨年也对得上；环比取 `prior_quarter_frame`。若某项 `*_note` 是 `base_missing`，说明去年同期该公司还没这个 tag，不是零。

## 一、两阶段事实：现在手上的到底是什么

| 阶段 | 什么时候 | 有什么 | 没有什么 |
|---|---|---|---|
| `press_release_only` | 财报当晚 ~ 10-Q 落地前 | 营收、EPS、**下季指引**、管理层措辞 | 现金流、资产负债表、扣除项明细 |
| `xbrl` | 10-Q/10-K 落地后（当晚起 0-10 天） | 三张表全量、逐季拆解 | 指引（XBRL 永远没有指引） |

**这决定了你能写什么。** `data_stage=press_release_only` 时：

- 可以写增长、可以写指引、可以写市场反应；
- **不能**写"经营现金流覆盖不了利润"——你根本没有现金流；
- 报告里必须点明"三张表未落地，现金流与资产负债表待 10-Q 验证"。

ADR（TSM / ASML / ARM / UMC / STM / ASX）是个长期的 `adr_limited`：它们交 20-F/6-K 不交 10-Q，季度 XBRL 覆盖稀疏甚至没有。这些公司的数字要从 `press_release_head` 和电话会议读，`statement_source_note` 已经写明。**不要把 ADR 的空白报表块说成"数据缺失"**——是披露制度不同。

## 二、增长：三口径 × 四条线

营收 / 毛利 / 经营利润 / 净利润 / 经营现金流各有 `value_musd`、`yoy_pct`、`qoq_pct`。

`value_musd` 只在 XBRL 单位明确为 USD 时出现。ADR/IFRS 若披露本币，脚本保留 `unit` 与 `value_local_millions`；引用时按原币种写，不能把 TWD/EUR 等本币数值加上美元符号。

1. **环比比同比重要。** 半导体是周期品，同比含去年基数的故事，环比才是当下动能。营收环比转正且加速 = 周期在走上行；同比很高但环比掉头 = 见顶信号，这在存储和设备上尤其准。
2. **毛利增速 > 营收增速 = 结构在变好**（涨价、mix 上移、良率爬坡）；反过来是在用价格换量。
3. **经营利润增速 > 毛利增速 = 费用杠杆在起作用**；AI 链上很多公司毛利改善但经营利润没跟上，钱花在了研发抢代际。
4. **`derived` 标记要看。** 带 `cumulative_diff` 的行是脚本从年初至今差分出来的（现金流几乎都是），带 `fy_minus_9m` 的 Q4 是年报减前三季。数值可信，但**遇到公司当年做过追溯重述，差分会把重述额一次性甩进某一季**——如果单季现金流出现无法解释的尖峰，先怀疑这里。
5. **基数为负要说人话。** `yoy_note=base_nonpositive` 意味着去年同期是亏的，"净利同比 +800%" 是算术不是增长，改写成"从亏 X 转为盈 Y"。

## 三、GAAP 与 non-GAAP：美股最容易被糊弄的一处

**这是 A 股没有的坑，必须每次都处理。**

- XBRL 里的一切都是 **GAAP**。
- 卖方一致预期、公司自己吹的 EPS、`surprise_pct` 对的是 **non-GAAP**。
- 两者的差额主要是：**股权激励（SBC）**、并购无形资产摊销、重组费用、投资损益。

所以：

1. **`eps_surprise_pct` 和 `growth.eps_diluted` 不是一回事，不能放在一句话里对比。** 前者是 non-GAAP 对预期，后者是 GAAP 实际。同时引用时必须标口径。
   - **百分比超预期在一致预期接近零时会失真**：一致预期 0.10、实际 0.30，印出来就是 +200%，听起来惊天动地，实际差 20 美分。脚本在 `surprise.surprise_pct_unstable=true` 时已标出（阈值 |一致预期| < 0.25），**此时报告只写美分差额，不写百分比**。
   - 反过来，超预期百分比极大且一致预期正常（比如 GOOGL 实际 9.11 对预期 2.88），通常意味着实际数里有大额一次性收益，或供应商的一致预期口径与公司报的口径不同。**这种情况要去新闻稿里找那笔一次性，不要直接当成经营超预期。**
2. **看 `margins.sbc.pct`（股权激励占营收）**。这是 GAAP 与 non-GAAP 差距的主要来源，也是"non-GAAP 利润好看"的成本。软件与 AI 应用类常年 15-25%，半导体多在 3-10%。**SBC 占比高且在抬升 = non-GAAP 的漂亮有相当部分是股东在稀释中买单**，这一点该写出来。
3. **GAAP 巨亏 + non-GAAP 大超预期**是这个宇宙的经典组合（减值、重组、诉讼）。两个都要报，并说清差在哪。只报一个是误导。

## 四、利润质量：钱是不是真的

1. **`ocf_to_net_income_pct`（经营现金流 / 净利润）**。长期看应该 ≥ 100%（折旧摊销大于营运资本占用）。持续低于 60% 而利润高增 = 纸面利润的经典形态。**净利为负时脚本返回 null**——不是缺数据，是分母无意义，此时直接看 `ocf_musd` 绝对值。
2. **`inventory_vs_revenue_gap_pp` / `receivable_vs_revenue_gap_pp`**（存货、应收增速减营收增速）。明显为正 = 资产负债表比收入涨得快。
   - **这里必须克制**：正的 gap 在半导体里有两种完全相反的含义——**为确定的订单备货**（好）和**卖不动积压**（坏）。数字本身分不出来，**只有电话会议能分**（管理层会主动解释备货，或被分析师追问库存天数）。没读电话会议就别对库存下结论，写"存货增速快于营收 X pp，管理层未解释/解释为 Y"。
3. **`free_cash_flow_musd` 与 `capex_to_revenue_pct`**。AI 基础设施正处在重资本周期，capex/营收 20%+ 在代工和数据中心是常态。看的不是孤立水平而是公司自身的方向：capex 大幅抬升说明管理层正在为未来需求提前投入，也会压低当期自由现金流。
4. **`rpo`（剩余履约义务）**。美股最接近"在手订单"的字段，但**只有部分公司 tag**。有 RPO 且同比大幅增长 = 收入能见度在拉长，对 AI 云与软件尤其关键。没有这个字段不是坏消息，是没披露。

## 五、指引：美股财报的第一位信息

**A 股没有这个东西，而美股股价当天的涨跌，六到七成由指引而不是已发生的季度决定。**

- 指引只在 **8-K/6-K 新闻稿**（`guidance_excerpts`）和**电话会议**里，XBRL 永远没有。
- `guidance_excerpts` 是脚本机械摘出的前瞻性数字句，**没有解析成结构化数值**——因为"$10.5B 到 $11.1B，上下浮动 $300M"里哪个是中值是判断不是提取。你自己读句子。
- 判 `guidance_call` 的四个动作：
  1. **和上季指引比**：这季实际落在上季指引的哪一侧？（超上限 / 上沿 / 中值 / 下沿 / 低于）
  2. **和市场预期比**：下季指引中值 vs 卖方一致预期（一致预期要么在 `surprise` 的 `eps_estimated` 里有 EPS 口径，要么得联网查营收口径）。
  3. **看全年指引动了没**：上修全年 > 只给下季好指引 > 维持全年 > 下修。
  4. **看毛利率指引**：营收指引好但毛利率指引下滑，通常意味着 mix 恶化或在用价格抢份额。
- **股价与指引背离最有信息量**：`price_reaction` 显示超预期却大跌，几乎总是指引问题；不及预期却大涨，几乎总是指引超预期或利空出尽。日报里这类公司要优先解释。

## 六、市场反应怎么读

`price_reaction` 同时给 `same_day_pct` 和 `next_day_pct`，因为 8-K 不说是盘前还是盘后发的——**美股科技盘后发居多，所以多数公司要看次日**，但盘前发的（部分欧洲 ADR）看当日。挑绝对值大的那一天当作反应日。

- `gap_open_pct` + `gap_status`：跳空幅度与是否回补。**`intact` 且 `trading_days_since` 只有一两天，等于没经过检验**，脚本已经在 `note` 里提示，写报告时别说成"缺口未回补，趋势确认"。
- `vol_ratio`：放量的方向更可信，缩量的涨跌意义打折。
- `position_52w`：0.9 以上是高位兑现的语境，0.3 以下是低位修复的语境，同样的超预期在两个位置含义不同。

## 七、分档锚点

模型据此判 `tier`，不是脚本。

**强**
- 营收同比与环比双双加速，且**指引上修**；
- 毛利率同比抬升，经营利润率同步改善；
- 现金流跟得上（OCF/净利 ≥ 100%，或阶段性资本开支能解释缺口）；
- GAAP 与 non-GAAP 差距没有扩大；
- 电话会议里有**具体的**需求证据（客户、订单、产能承诺），不是"我们对 AI 长期机会感到兴奋"。

**中**
- 同比亮眼但环比减速；或
- 指引只是维持；或
- 利润质量三件套有一项背离；或
- 增长真实但已被股价充分反映（超预期却跌）。

**观察**
- 数据阶段还是 `press_release_only`，关键问题要等 10-Q；或
- 电话会议 `pending`，指引判断没有依据；或
- 单季有一次性因素（税、诉讼、处置），常态盈利能力看不清。

**剔除**
- 营收下滑且指引继续下修；
- 净利高增全靠一次性收益，扣掉后主业在退；
- 现金流为负且应收存货双双跑赢营收，管理层在电话会议上回避追问。

---

## 八、必须点破的事（写了就不算合格报告的反面清单）

1. 用 GAAP 数字讲"超预期"，或把 `surprise_pct` 和 GAAP EPS 增速混为一谈。
2. `press_release_only` 的公司却评论了现金流或资产负债表。
3. 库存/应收 gap 为正就说"积压"，没读电话会议、没看管理层解释。
4. 电话会议 `pending` 却写出了"管理层表示……"。
5. 只讲已发生的季度不讲指引。
6. 把 Motley Fool 页面上的 TAKEAWAYS / SUMMARY 当成管理层原话——那是网站自己的编辑内容，`publisher_notes_warning` 已标明。
7. 拿"净利同比 +800%"当成长性，而基数是去年的亏损。
8. 忽略 `not_reported` 的名单，把已披露的一小半说成"本季全貌"。
