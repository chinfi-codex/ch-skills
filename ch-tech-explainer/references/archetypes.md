# 概念拆解：诊断形状 → 概念驱动地拆 → 投研锚点兜底

这份文档是本 skill 的方法论核心。**它不是一张填空表**——不存在一套适用所有概念的固定模板。它给的是：一套判断"这个概念该怎么讲"的诊断方法、一个可参照可拼接的骨架库、以及一组无论如何都要答到的投研问题。

> 为什么不用固定模板：玻璃基板(换材料)、HBM(换架构)、"某技术的产业链增量"(算账)本质是三种完全不同的问题。用同一个"是什么→为什么→怎么做→谁受益"去套，会把每个概念都削成一样的形状，丢掉它真正反直觉、真正值钱的那个点。

---

## 第一步：诊断概念的"形状"

先问一句话：**这个概念的"新"到底新在哪？** 顺着下面的判别走，落到一个(或几个)archetype：

- 它把**一种材料 / 工艺换成了另一种** → 「材料 / 工艺替代」型(玻璃基板、铜互联→光互联、湿法→干法)。
- 它在**性能上跨了一个台阶、靠的是结构 / 架构创新** → 「架构 / 性能跃迁」型(HBM、chiplet、存算一体)。
- 它的突破在**材料体系 / 物理机理本身** → 「物理机理 / 新材料」型(钙钛矿、固态电池、碳化硅、硅光)。
- 它本质是**一套大家约定的规则 / 接口** → 「标准 / 协议」型(UCIe、CXL、PCIe、Wi-Fi 7)。
- 用户问的根本不是"是什么"，而是**"这事让谁多赚钱、增量在哪段"** → 「价值流 / 产业链增量」型。
- 它是**一个新的产品品类 / 终端形态** → 「新产品 / 新物种」型(AI 眼镜、人形机器人、AI PC)。
- 它是**制造环节里的一个工艺 / 节点升级** → 「制程 / 工艺节点」型(先进封装、N2、GAA、HBM 的 TSV / 混合键合)。

一个概念可能同时占两型(HBM 既是架构跃迁，其量产瓶颈又落在制程型的先进封装)——**允许拼接**。库里没有的，就地诊断它最像哪一类、按那类的骨架现搭。

---

## 第二步：概念驱动地拆(具体问题具体分析)

诊断出形状后，用对应骨架起步，但**细节由概念自己决定**。几条手法(是手法不是顺序)：

- **找那个关键的反直觉点**：每个值得讲的概念都有一个"咦，原来如此"的转折(HBM 是"内存为什么要叠起来"；玻璃基板是"玻璃这么脆凭什么做基板")。整段拆解围着它转。
- **围绕一个核心机制展开**，不要面面俱到：选最能解释"为什么更好"的那一个机制讲透，其余一笔带过。
- **类比 + 数量级**：把陌生映射到日常(TSV=楼里的直梯)，把裸参数翻译成能感受的倍数(带宽差 5 倍≈单车道 vs 五车道)。
- **先问题后方案**：先把旧世界的痛点 / 墙立起来，再把新技术作为"答案"揭出来——这是最好用的叙事钩子。

### 七型 archetype 库

每型给：识别信号 / 最自然的讲解骨架 / 这一型特有的坑。骨架是起点，不是模板。

**1. 材料 / 工艺替代**
- 识别：A 换成 B，卖点是 B 的物性更好。
- 骨架：旧材料在新场景下撞到的物理极限 → 新材料凭哪几条物性破这些极限 → 换材料带来的新工艺难点(往往是新增量来源) → 谁受益。
- 坑：只夸新材料好，不讲它难在哪、谁能做出来——难点才是壁垒和弹性所在。

**2. 架构 / 性能跃迁**
- 识别：性能跨台阶，靠的是"换了种组织方式"而非材料。
- 骨架：先立性能墙(带宽 / 算力 / 功耗) → 结构创新怎么破墙 → 跟旧架构量化对比 → 产业链。
- 坑：把它讲成纯性能参数堆砌，丢了"为什么非这么改不可"。

**3. 物理机理 / 新材料体系**
- 识别：突破在材料 / 物理本身，常有路线之争。
- 骨架：为什么这个材料体系性能更好(讲到机理但点到为止) → 量产卡在哪(良率 / 一致性 / 成本) → 路线之争 → 谁卡位。
- 坑：陷进物理细节讲不出头；忘了讲"离量产还有多远"。

**4. 标准 / 协议 / 接口**
- 识别：本质是一套约定，解决"各家不互通"。
- 骨架：碎片化的痛点 → 标准规定了什么(定义边界) → 迁移 / 兼容成本 → 谁主导、谁被颠覆、谁躺赢。
- 坑：把协议条款讲成说明书；标准型的价值在"谁掌握话语权"，要落到格局。

**5. 价值流 / 产业链增量**
- 识别：用户问的是"增量在哪、谁受益"，不是"是什么"。
- 骨架：拆环节(上中下游 / BOM) → 每个环节的增量从哪来(新设备？新材料？ASP 提升？渗透率？) → 按弹性与确定性排序 → 卡点 / 瓶颈环节。
- 坑：罗列"上游材料中游制造下游应用"却不算账；核心是**增量的来源**和**弹性排序**，不是环节名词。

**6. 新产品 / 新物种**
- 识别：一个新终端形态。
- 骨架：它能干什么、解决谁的什么需求 → 关键部件 BOM 与技术难点 → 成本 / 成熟度曲线在哪 → 谁供货、谁卡脖子。
- 坑：被概念噱头带跑，不讲成熟度和成本现实。

**7. 制程 / 工艺节点**
- 识别：制造环节里的一段工艺 / 节点升级。
- 骨架：上一代工艺的瓶颈 → 这道工艺怎么解 / 难在哪 → 良率与成本含义 → 设备 / 材料 / 产能谁受益。
- 坑：只讲工艺名词不讲它卡住了什么、为什么是瓶颈。

## 第三步：通用投研锚点(强制兜底，五条)

这是你要保留的"通用、投研所需的关键知识结构"。无论概念是哪一型、怎么拆，**最后都要答齐这五条**；但答的顺序、篇幅、轻重由概念决定。

1. **痛点**：它解决的是什么真实瓶颈 / 墙？(说清"不解决会怎样")
2. **vs 旧世界的增量**：相对上一代，多出来的价值具体是什么？(尽量给数量级，不是形容词)
3. **卡点 / 壁垒**：难在哪、谁能做、为什么别人做不了？**卡点常常就是价值与弹性所在。**
4. **谁吃到肉 + 弹性排序**：沿产业链谁拿到新订单 / 新 BOM / ASP 提升，按"弹性大小 × 确定性"排序，并说清逻辑(这是产业结构判断，不是荐股)。
5. **节奏与证伪**：现在到哪一步了(路线图)，往后要盯什么信号，什么情况会证伪这个故事(风险 / 过剩 / 替代)。

> 取证：第 2、3、5 条的关键数字与事实必须联网核验、带出处；查不到就写"未检索到明确数据 / 待验证"，不许编。

## 三个例子，三种骨架(证明适配)

**玻璃基板 →「材料 / 工艺替代」型**
- 痛点：AI 大芯片越做越大，有机基板 / 硅中介在大尺寸下翘曲、互联密度和可做面积都到顶。
- 拆：玻璃凭平整度、热膨胀可控、可做大板破这些极限 → 但玻璃脆、要在玻璃上钻孔(TGV)、镀铜、防裂，这是全新工艺难点 → 难点=新增量(玻璃基板厂、钻孔 / 镀铜设备、载板厂)。
- 锚点收尾：弹性最大在"能良率稳定量产 TGV 的环节"，节奏看各家试产 / 良率 / 大客户认证。

**HBM →「架构 / 性能跃迁」型**(≈ 之前那套六问，但它只是一种型)
- 痛点：内存墙——GPU 算得快、喂不饱。
- 拆：把 DRAM 叠楼 + TSV 直梯打通、紧贴 GPU → 带宽跨一个量级 → 增量与瓶颈落在先进封装(制程型)。
- 锚点收尾：弹性在先进封装产能 + TSV / 键合设备，节奏看 HBM3e→HBM4 量产 / 良率 / 认证。

**"某技术的产业链增量" →「价值流 / 产业链增量」型**
- 这压根不是"是什么"：直接拆环节 → 逐环算增量来源(是多了一道新设备？换了更贵的新材料？单价提升？还是渗透率从 0 起步？) → 按弹性 × 确定性排序 → 指出卡点环节。
- 锚点天然就是主体，"痛点 / vs 旧世界"压缩成一句背景即可。

> 再补一型证普适：**新标准(UCIe / CXL) →「标准 / 协议」型** = 先讲 chiplet / 内存扩展的碎片化痛点 → 标准规定了互联的什么 → 迁移兼容成本 → 谁主导生态、谁被颠覆。
