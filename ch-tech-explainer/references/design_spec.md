# 视觉规范

管"画面长什么样"。动效见 `motion_spec.md`，图元的参数化渲染见 conceptkit(shared/html_report，建设中)。

## 色板与三态

- **语义化色板**：沿用主题 ramp，暗色自适应。颜色编码类别，不做装饰；info / success / warn / danger 这类语义色只在真有该语义时用。一镜内 ≤2 个色系。
- **三态(核心)**：每一镜主角唯一，靠颜色 + 动效一起标"现在看谁"。
  - **聚焦态**：当前讲解对象，高饱和 / 高亮。
  - **背景态**：讲过的、作陪衬的，降饱和。
  - **对比态**：旧方案 / 参照系，恒为中性灰。

## 版式

- 一镜一焦点，留白充足。
- 字号层级：标题 / 标注 / 字幕 / 旁白，分明不混。
- 中文无衬线；圆角与描边统一(细描边走 0.5px 档)。

## 知识图元库

固定一套基础图元，跨镜复用、统一画法(圆角 / 描边 / 深度向量)：层(stack)、箭头(arrow)、通道 / 管道(pipe)、粒子(particle)、坐标轴(axis)、节点盒(node)。新画面优先用这些拼，不要每镜另造一套样式。

## 隐喻一致性(全 skill 不串台)

同一类抽象，永远用同一种视觉隐喻：

| 抽象概念 | 视觉隐喻 |
|---|---|
| 带宽 / 吞吐 | 通道宽度 + 流动粒子 |
| 堆叠 / 集成 | 楼层 |
| 流程 / 转化 | 管道 + 沿管流动 |
| 数据 / 信号 | 粒子 |
| 时间 / 路线 | 横轴时间线 |
| 份额 / 占比 | 面积 / 堆叠条 |
| 层级 / 协议栈 | 自下而上的层 |

> 隐喻一旦在某个概念里用过(带宽=通道宽度)，后续所有概念沿用，读者的视觉直觉才能复利。
