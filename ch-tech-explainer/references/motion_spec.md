# 动效规范

这份规范管"画面怎么动"。一条总原则压在所有细则之上：

> **动效必须承担教学职能，不是装饰。** 信息增益测试——把这个动效去掉，理解会不会变难？不会，就删掉它。

---

## 一、动效语法(六类动作，每类绑定一个教学职能)

写 scene 的 beats 时，每个动作都从这张表里选，并写清它在教什么：

| 动作 | 教学职能 | 触发场景 | 实现手法 | 缓动 / 时长 |
|---|---|---|---|---|
| 引入 introduce | 把新对象带进画面、引导注意 | 一个新元素第一次出现 | 生长 / 淡入 / 从画外滑入 | `power2.out`，中(400ms) |
| 强调 emphasize | "现在看这里" | 要点名某个已有元素 | 脉冲(scale yoyo)、描边走线、高亮变色 | `sine.inOut`，快(200ms)×2 |
| 对比 contrast | 量化新旧 / 大小差 | 讲"凭什么更好" | 双条形增长、数字滚动、并排缩放 | `power2.out`，中(400ms) |
| 形变 transform | 展示机理、A 怎么变成 B | 讲转化 / 过程 | morph 路径、位移重排 | `power1.inOut`，慢(800ms) |
| 流动 flow | 展示流向(数据 / 物料 / 信号) | 讲通道 / 管道 / 链条 | 粒子或虚线沿路径平移 | `none`(线性)，循环 |
| 揭层 reveal | 渐进披露，一次只上一个新概念 | 分层 / 分步结构 | 逐个淡入、遮罩滑开 | `power2.out`，中(400ms)，stagger |

**配色协同(呼应 design_spec 三态)**：被 introduce / emphasize 的对象进入"聚焦态"(高亮)，讲完退回"背景态"(降饱和)；旧方案恒为"对比态"(中性灰)。动效和颜色一起表达"现在的主角是谁"。

---

## 二、节奏

- **一镜一个新概念**：一个 scene 只推进一个理解单元。塞两个就拆成两镜。
- **动效与口播对齐**：beats 的时间点踩着口播的语义节拍——口播说到"叠起来"，dies 正好在落；说到"打通"，TSV 正好在画。scene 时长 ≈ 口播时长 + 收尾停顿。
- **三档时长**：快 200ms(强调 / 微反馈)、中 400ms(常规引入 / 对比)、慢 800ms(形变 / 需要看清的过程)。不在这三档之外随意取值。
- **留白**：每个动作之间留 ≥150ms 的视觉停顿，别让动效连成一团糊。

---

## 三、缓动

- 默认 `power2.inOut`；引入用 `power2.out`(快进慢出，自然落定)。
- 强调用克制的脉冲(scale 1→1.06→1，yoyo)。
- 流动用 `none`(线性匀速)，循环要无缝(位移量 = 虚线周期的整数倍)。
- **禁止**：elastic / bounce 等过度弹跳缓动(教学场景显得轻浮)；同一镜里混用多种风格迥异的缓动。

---

## 四、伪 3D 规范(不引入真 3D)

全部用 SVG 等距画法 + CSS 3D transforms 伪造立体，**不引入 Three.js**。统一这几样，避免每镜风格漂移：

- **等距角统一**：固定一个等距投影角(如 30°)，深度向量在全 skill 用同一比例(如 `dx:16, dy:-9`)。所有"立体块"都按这个向量画顶面 / 侧面。
- **光源方向统一**：明面 / 暗面固定一个方向(如光自左上)。用透明度 / 明度差表达体积(顶面最亮、正面中、侧面最暗)，**不做真实光照渲染**。
- **层叠 parallax 深度档**：前景位移系数 1.0、中景 0.6、远景 0.3，转场平移时按系数差产生纵深感。
- **禁止**：同一系列里换等距角、换光源方向、给单个块做透视旋转(那是真 3D，不在 scope)。

---

## 五、可达性(硬约束)

- **尊重 `prefers-reduced-motion: reduce`**：检测到就渲染**静态末帧**(timeline 直接 `progress(1)`)，不播放。
- **关键信息必须在末帧可见**：任何信息都不能只存在于运动过程中——reduced-motion 用户看到的是末帧，末帧丢了信息就是 bug。这也意味着图集(静态)永远是视频的合法降级。
- **动效不承载唯一信息**：颜色 / 运动之外，必须有文字标注 / 字幕兜底。
- **不闪烁**：避免高于 3Hz 的闪动。

---

## 六、与时间轴的衔接

- 模型在 scene 的 `beats` 里写"什么时候、对谁、做哪类动作、什么缓动"——这是教学编排(脑)。
- GSAP 时间轴执行插值(手)。组件(conceptkit)给常见镜型预置默认 beats，模型微调即可；特殊概念用 custom 手绘 + 手写 beats。
- 时间轴必须**有限且可 seek**(`__tl.seek(t)`)，这样同一条动画能确定性逐帧导出成视频(见 `tech_stack.md`)。流动类循环用"有限次平移"实现，别让无限 repeat 把总时长撑成无穷。
