# 金库产业链简报

## 目标

1. **做什么**：把 AlphaVault 一个时间窗内的摄取增量（来源登记表）、词条结论增量（wiki 可产出结论）、催化事件与地缘台账，叠加 PG 里的宏观快照，组织成一份「宏观地缘 + 产业信息进展 + 跨产业链共同信号」的日报或周报。重心在产业，宏观地缘只占开头很短一段。
2. **不做什么**：不采集任何外部新闻（金库外的东西不进这份报告）、不改写金库页面、不给买卖建议 / 目标价 / 仓位、不替代个股或盘后复盘类 skill。**不写 A 股盘面复盘，也不写主线状态机**——那是 a-stock-daily-market-sense 的活，这份报告里一行都不要出现。
3. **给谁用**：面向已经在维护 AlphaVault、需要定期把碎片化摄取收敛成产业链视角结论的研究者本人。

## 适用场景与边界

| 适用 | 不适用 |
|---|---|
| 「本周 ingest 和 raw 更新了什么」 | 「帮我分析 XX 股票」→ a-stock-analyzer |
| 「按产业链出一份周报 / 日报」 | 「今天 A 股盘面怎么样」→ a-stock-daily-market-sense |
| 「宏观地缘 + 产业进展合成简报」 | 「今天 A 股主线走到哪了」→ a-stock-daily-market-sense |
| 「哪些结论本周被上修 / 出现分歧」 | 「把这份报告推到微信」→ md-pushplus |
| 「核心公司的假设变了没有」 | 未入库的临时资料、自由主题研究 |

**前置条件**：金库根目录可读（`ALPHAVAULT_ROOT`）；PG 可连（`ALPHA_PG_URL`）。任一不可用时按降级路径走，见「数据获取」末尾。

## 领域方法论

五条贯穿全篇的规矩，细则见 `references/chain-framework.md`。

1. **权重决定话语权，不决定篇幅。** 🟢 高权重来源可单独支撑事实；🟡 需要同向佐证；🔴 只能作线索、永远不得单独推翻 🟢。同一条事实被两个独立环节（如模型侧与封装侧）各自命中时，交叉验证的价值高于任何单一来源的权威性——这类共振要单独拎出来讲。

2. **分歧比共识更值钱。** 几家高权重机构在同一变量上给出相反判断时，不要挑一个写、也不要和稀泥，而是把分歧结构化：谁判什么、依据是什么、裁决点在哪一天。裁决点没到之前，分歧本身就是结论。

3. **事实与推断必须可分辨，但不分列。** 事实带数字与来源、推断用 `→` 引出并跟在触发它的事实后面。**不要**把一段拆成「事实：…／推断：…」两个小标题——那样读起来像填表。

4. **说人话，不说行话。** 报告是写给人看的，不是给系统看的。内部字段名、表名、状态机术语、代号一律翻译成日常说法再落笔，具体对照见 `references/macro-geo.md` 的「措辞」一节。判断力体现在把事情讲透，不在于用了多少专业词。

5. **地缘台账是可变的，落笔前必须重读。** 地缘 `status.json` 当天会被就地改写。凡引用它，一律以撰写当刻脚本返回的值为准；若与本次会话早前读到的不同，直接用新值，并在「关键变化」里顺一句以哪一天的口径为准。

## 工作流程

按可独立验证的产物切五步。

1. **定窗口与体裁**
   周报默认取结束日所在自然周（周一起），日报取单日。用户没说就按周报，并在报告头写清窗口。

2. **取金库增量**
   跑 `vault_delta.py`，拿到摄取登记、结论增量、催化事件、地缘状态四段。先看三个总量——摄取条数、结论条数、权重分布——判断这个窗口是「有料」还是「流量周」。

3. **取宏观核心指标**
   跑 `macro_snapshot.py`，拿到几个核心指标的区间变动。**先看数据健康那一段**：哪个数卡住了、最新一天缺了什么、有没有漏天、中国的月度数据停在哪个月——这些都要在报告里说一句，不能拿卡住的数当行情讲。

4. **归类与填维**
   把结论增量按 `wiki/03-产业链图谱` 的实际类目分章（脚本已给出 `chains_touched` 与逐条页面归属，但个股页与概念页要由你判断挂到哪条链上）。每章按五维填充，只写有新证据的维度，没有就跳过、不要凑数：
   - 供需关系 / 价格锚定 / 订单变化 / 上下游权重迁移 / 其他（政策、技术路线、估值方法）
   每章收在一张「核心公司假设变化」表：原假设 → 本周新假设 → 触发证据。这张表是整份报告的落点，不能省。

5. **写开头与结尾**
   开头的宏观地缘只写两块——**关键变化**（3-5 条，一条一句话）和**核心指标**（一张小表）。地缘的框架档位、路径概率、战线清单这些内部口径不要搬进报告，只讲"什么变了、意味着什么"。
   结尾把跨产业链同向的证据收成 3-5 条共振结论，把有明确日期的验证点排成观察日历，报告到此为止。**不写"口径与数据缺口"章，也不写"未决项"清单**——口径说明贴着它修饰的那个数就地交代，具体放哪见 `references/report-template.md` 的「口径说明放在哪」。

## 数据获取（脚本抓手）

| 脚本 | 职责 | 调用方式 | 返回 |
|---|---|---|---|
| `scripts/vault_delta.py` | 按时间窗提取金库摄取登记、wiki 结论、催化事件、地缘状态 | `python3 scripts/vault_delta.py --since 2026-08-03 --until 2026-08-08` | JSON |
| `scripts/macro_snapshot.py` | 按时间窗提取宏观核心指标的区间变动，并做数据健康检查 | `python3 scripts/macro_snapshot.py --start 2026-07-31 --end 2026-08-07` | JSON |

常用变体：

- `vault_delta.py --part registry|conclusions|catalysts|geo` 只取一段，日报时能省不少 token。
- `vault_delta.py --days 1` 取日报窗口；不带 `--since` 时默认按结束日所在自然周。
- `macro_snapshot.py --start` 填**区间起点当天**，变动幅度以它为基准。
- `--indent 2` 便于人工核对。

环境变量：

```bash
ALPHAVAULT_ROOT=/path/to/1-AlphaVault      # vault_delta.py 必需（也可用 --vault 传）
ALPHA_PG_URL=postgresql://user@/alpha_data?host=/tmp   # macro_snapshot.py 必需
```

降级策略：

- `vault_delta.py` 缺配置返回 `MISSING_CONFIG`（退出码 2），路径不存在返回 `VAULT_NOT_FOUND`。缺哪个 part 就在该 part 里返回 `available: false` 与原因，不要因为一段缺失就放弃整篇。
- `macro_snapshot.py` 连不上库返回 `DB_UNAVAILABLE`（退出码 3）。此时保留产业信息进展与地缘两段，核心指标那张表写明"本期取不到宏观数据"，不要用记忆里的旧数字补。
- 两个脚本都只做取数与确定性计算，**任何聚类、命名、归因、结论都不在脚本里**，也不要要求脚本去做。

## 输出规范

| 维度 | 怎么做 | 为什么 |
|---|---|---|
| 结构 | 固定四段：摘要 → 宏观地缘（只有「关键变化」+「核心指标」两块）→ 产业信息进展 → 跨产业链共同信号 + 接下来看什么。产业段按产业链类目分章，章内五维、章末假设变化表 | 结构稳定才能跨周对比 |
| 配重 | 宏观地缘控制在全篇 15% 以内，产业信息进展是主体 | 这份报告的价值在产业，开头只交代背景 |
| 不写 | A 股盘面复盘、主线状态机、指数与行业涨跌榜，一律不出现 | 各有专门 skill，混进来只会稀释重点 |
| 段落 | 段内按语义单元断行，一行一个论点簇，`→` 推断独立成行 | 长段落在终端和微信里都读不动 |
| 长度 | 日报 1500-3000 字；周报不设上限但每条产业链不超过 5 个维度小节 | 防止把结论堆成流水账 |
| 语言 | 讲人话。不出现脚本字段名、数据库表名、地缘路径代号、结论编号、状态机术语；专业词只在没有等价日常说法时才用，且第一次出现要顺带解释 | 报告是给人读的，行话只会增加阅读成本 |
| 风格 | 中立分析性。同项罗列用 list 且每条写成完整句子；只有「机构 × 判断」「指标 × 数值」这类对照才用表格 | 仓库级文风默认 |
| 数据呈现 | 金额留原始单位与口径（亿元 / 亿美元 / EB / $/Gb 不混用）；百分比两位小数；每个关键数字后跟来源与权重符号 | 跨来源拼装最容易在单位上出错 |
| 口径 | 报告头留一行说明覆盖范围与截止时间；其余口径说明**贴着它修饰的那个数就地写**，不单独成章、不设未决项清单 | 读者看到数的同时就知道能不能用，省掉一次回翻 |
| 附加要求 | 不出现买卖建议、目标价推荐与仓位 | 守住 skill 边界 |

**引用格式**：`（GS 8/5🟢）`——机构 + 日期 + 权重符号，够用即可。只有还没定去处、需要你后续处理的材料才给文件路径。
