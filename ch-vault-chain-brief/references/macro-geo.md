# 开头那一段：关键变化、核心指标、怎么说人话

写报告开头的「宏观与地缘」时读本文。

**先记住这一段的定位**：它是背景交代，不是独立报告。全篇 15% 以内，两块内容——**关键变化**（3-5 条，一条一句话）和**核心指标**（一张小表）。产业才是主体。

**这一段里不写的东西**：A 股盘面复盘、主线状态机、指数与行业涨跌榜。这些各有专门的 skill，混进来只会把重点冲淡。

---

## 一、关键变化怎么挑

地缘台账（`vault_delta.py --part geo`）返回的是一整套框架状态。**绝大部分字段不进报告**，它们是给判断用的，不是给读者看的。

只写这三类：

1. **方向变了**——局势是在升级还是降级，用一句话说清从什么状态变成了什么状态。不要写路径代号，写"美伊直接交火基本停了"这样的话。
2. **说的和做的对不上**——这是最有价值的一类。外交层面宣布停火、市场也这么定价，但通道实际还堵着、船还是过不去，这种背离本身就是结论。判断它靠的是把停火概率和实际通航数放在一起看。
3. **有明确日期的验证点**——什么时候能知道答案。这些不要在这一段展开，直接挪到结尾的「接下来看什么」。

其余的（各条战线状态、传导渠道清单、信号清单、证伪条件）留在你脑子里做判断，不落到纸面。**判断力体现在挑出哪几条，不体现在把台账抄一遍。**

有一条经验：不要因为局势降级就写"风险缓解"。降级说的是打不打，通道状态说的是货能不能走，两件事经常反着来。

## 二、核心指标怎么给

`macro_snapshot.py` 返回几个指标的区间变动。表格里只放**这一期真正动了的**，通常四行以内：

| 指标 | 什么时候值得写 | 怎么读 |
|---|---|---|
| 布伦特原油 | 几乎每期 | 和通道是否通畅对着看 |
| 黄金 | 涨跌超过 3% | 和美债、就业数据一起看，才能分清买的是战争风险还是衰退风险 |
| 美债 10 年期 | 变动超过 5 个基点 | 给区间内的高点和低点，不要只给首尾 |
| 人民币汇率 | 有明显方向时 | 小数留到万分位 |
| 天然气 / 比特币 | 只在能佐证主线时 | 都不单独立论 |

当期公布的重要数据（就业、通胀）单起一段给数值和修正值，比表格更清楚。

**表述上的一个准确性要求**：这些数是「已经采集入库的每日快照」，不是实时行情。写"截至 X 日"，不要写成"实时调用"。真要盘中最新值，那是 `chstock-macro-monitor` 的活。

## 三、数据健康：落笔前必看

脚本会按固定规则算出四类问题，**都要在核心指标表下面就地交代一句**（不另起章节），用日常说法写，别搬字段名。

1. **某个数卡住了**——连续三天以上一模一样。实测遇到过原油的一个报价连续 6 天不动、而另一个报价正常波动的情况。这种数**不能用来算涨跌幅、不能用来算价差**，就在表下面点名说明本期改用哪个口径。
2. **最新一天缺值**——不要往前找个有值的日子冒充"最新"，缺就说缺。
3. **漏天**——宏观快照按自然日入库（含周末），漏天说明当天采集任务没跑成。
4. **中国的月度数据滞后**——把实际停留的月份写出来。如果落后两个月以上，或者物价、景气数据是空的，直接写"中国这一块本期是空白"，比含糊带过有用得多。

**通用原则**：宁可写"这个数没有"，也不要用记忆里的旧数字补。补出来的数会污染后面所有的跨周对比。

## 四、措辞：把行话翻译成人话

报告是写给人看的。下面这类对照，落笔前自己过一遍：

| 不要这样写 | 改成 |
|---|---|
| path 由 W2 切换至 W1，escalation rung 6.5→6.0 | 直接冲突基本停了，但封锁还在，紧张程度降了一档 |
| chokepoint_status: Hormuz = blockaded | 霍尔木兹海峡仍然堵着 |
| Polymarket 定价 86.5% | 市场押注两周内不会再打，概率接近九成 |
| stale_fields 命中 WTI | 原油的这个报价连续六天没动，数据源卡住了 |
| CHINA_MACRO 滞后至 202606 | 中国的物价数据还停在 6 月 |
| 参见 C-存储芯片-32 | 直接把那条结论讲出来，不要给编号 |
| 该判断由 🟢 高权重来源单独支撑 | 高盛原文口径（🟢） |
| 主线状态机显示 TH-PCB电子链 转入在场候选 | 整段删掉，这份报告不写这个 |

几条通用的：

- **代号一律展开**：路径代号、结论编号、主题 ID、表名、字段名，读者一个都不认识。
- **专业词只在没有等价日常说法时才用**，而且第一次出现要顺手解释一句。像 HBM、长约、扣非这种确实没有替代说法的，保留；像"传导""赋能""闭环"这种可有可无的，删掉重写。
- **不要用结构词充数**。"呈现出……的态势""形成了……的格局"这类话删掉之后句子通常更清楚。
- **判断要说透**。与其写"值得持续关注"，不如写"要看 9 月长约谈判谈成什么价"。

## 五、宏观和产业怎么接上

开头这一段不能和后面的产业段脱节。两条常用接法，各一句话就够：

1. **成本传导**：上游涨价对产业链上游是好事，对下游就是成本上升。同一条价格证据在两章方向相反时，把这件事挪到「跨产业链共同信号」里单独讲。
2. **定价阶段**：产业证据很强但股价没反应，通常是这条线进入了看财报兑现的阶段，属正常，不要写成"证据被推翻"。
