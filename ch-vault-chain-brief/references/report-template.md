## 口径说明放在哪

不设"口径与数据缺口"章，也不设"未决项"清单。**每条口径说明贴着它修饰的那个数走**，读者看到数的同时就知道这个数能不能用。

| 说明的是什么 | 放在哪 |
|---|---|
| 某个指标卡住了、这期换了什么口径 | 核心指标表下面一行 ⚠️ |
| 中国月度数据停在哪个月、哪块是空白 | 同上 |
| 地缘台账在本次会话中被刷新过 | 关键变化那几条里，顺一句"以某日口径为准" |
| 某条证据是 OCR 提取降档、或尚未回源 | 就写在引用它的那句话里，如"（🟡，OCR 提取待复核）" |
| 某个数是公司口径 / 卖方建模 / 预测值 | 紧跟数字，如"公司口径 30-50 美元/瓦，卖方建模 10 美元/瓦" |
| 某份材料还没定去处 | 写进它所属那条产业链的段落末尾一句话，说清为什么没挂上 |
| 高权重机构之间的分歧什么时候有答案 | 「接下来看什么」的日历里 |

一条经验：口径说明写成独立章节时，读者读到数据的当下不知道有坑，读到最后才发现前面白读了。贴着写虽然打断节奏，但省掉一次回翻。

## 日报与周报的差异

| 项 | 周报 | 日报 |
|---|---|---|
| 窗口 | 结束日所在自然周 | 单日 |
| 摘要 | 三句 | 两句 |
| 宏观与地缘 | 关键变化 3-5 条 + 核心指标表 | 关键变化 1-2 条；指标只写当日变动明显的，可以不给表 |
| 产业段分章 | 全部被触碰的产业链 | 只写有 🟢 或 🟡 新证据的链，通常 1-3 章 |
| 五维 | 有证据就写 | 通常只有 1-2 维有料，不要撑满 |
| 假设变化表 | 每章必给 | 全篇合成一张；当日无变化就直说没有 |
| 跨产业链共同信号 | 3-5 条 | 0-2 条，没有就不写这一段 |
| 接下来看什么 | 完整 | 只留未来 5 个交易日内的节点 |
| 篇幅 | 不设上限 | 1500-3000 字 |
