# 财报季研究员

每到业绩预告和季报披露的时候，帮你把全市场扫一遍：拆出每家公司的累计、单季和环比增速，看扣非和现金流有没有给利润撑腰，挑出业绩真正优秀的公司，生成一个可以点开每家公司看详情的 HTML 报告。

## 能做什么

- **业绩预告扫描**：以巨潮资讯官方公告为准，下载并解析每一份预告，提取预告区间、上年同期、扣非净利和公司自己写的变动原因。
- **正式财报扫描**：季报、半年报、年报全市场扫描，看营收、归母、扣非、经营现金流四条线的三口径增速，以及毛利率、费用率、合同负债、应收存货这些利润质量信号，还能对照公司自己之前的预告看兑现得怎么样。
- **单家公司查证**：把一家公司的财报数字、同期公告和互动平台上的问答放在一起讲清楚。
- **增量更新**：同一期过几天再让它"更新一下"，只补新披露的公司，不会从头再来。

## 第一次使用

直接召唤专家说"帮我扫一下最新一期业绩预告"就行。它会先检查你电脑上的环境，缺 Python 包会帮你装，数据库默认用本地 SQLite 文件，不需要装任何服务。

**关于 Tushare token**（可选，但推荐）：

- 没有 token：业绩预告扫描照样能用，你能看到预告区间、上年同期、扣非、变动原因和公告原文；单季拆解、营收、年化 PE、股价断层和行业分类是空的。正式财报扫描需要 token 才能跑。
- 有 token：去 [tushare.pro](https://tushare.pro) 注册，在个人主页找到"接口TOKEN"复制给专家，它会帮你存到本机（`~/.ch-skills/config.env`，只有你自己能读）。不同积分档位能调用的接口不同，专家会逐个接口检查并告诉你哪些功能可用。

## 运行要求

- Python 3.9 及以上
- 能访问巨潮资讯网（cninfo.com.cn）；使用 Tushare 时还需能访问 tushare.pro
- 首次扫描需要几分钟到半小时（要下载公告 PDF 或逐家取报表），之后的更新很快

## 产出在哪里

所有报告都在 `~/earnings-season/reports/` 下：

- `forecast_<报告期>.html`：业绩预告报告
- `qreport_<报告期>.html`：正式财报报告
- 同名的 `.klines/` 文件夹是报告里的 K 线数据，挪动报告时要一起挪

## 说明

本专家只判断"业绩优秀度"和"持续性需要验证什么"，不提供任何买卖建议、目标价或仓位建议，也不预测股价。数据来自巨潮资讯和 Tushare 公开接口，解析结果以公告原文为准。
