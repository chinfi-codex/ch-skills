# 财报季研究员

每到财报季，帮你把一个季度的业绩完整看一遍：业绩预告和正式报告合在一起看，拆出每家公司的累计、单季和环比增速，看扣非和现金流有没有给利润撑腰，挑出业绩真正优秀的公司；再看股价对这份业绩反映了多少、估值和增速配不配，生成可以点开每家公司看详情的 HTML 报告。

## 能做什么

- **预告与正式报告合看**：同一季度的业绩预告和正式报告用一套方法判断。只有预告的公司用推断模式（信息少，结论标"推断"并列出待验证项），正式报告已出的公司用深挖模式（四条线、利润质量、兑现度），先出预告后出报告的公司会对照前后两次判断。
- **业绩预告扫描**：以巨潮资讯官方公告为准，解析每一份预告的区间、上年同期、扣非和变动原因。
- **正式财报扫描**：营收、归母、扣非、经营现金流的三口径增速，毛利率、费用率、合同负债、应收存货等利润质量信号，以及对预告的兑现度。
- **股价反映了多少**：公告前 20/60/120/250 日涨幅和相对沪深300 的超额、公告当天的跳空与回补、公告后是否延续，判断业绩是尚未定价、正在定价，还是已被提前透支。
- **估值配不配**：按公司类型选估值锚（不一律用 PE），看估值在自身近 1/3/5 年的位置、和本季增速是否匹配、近期涨幅里多少来自估值抬升。
- **单家公司查证**：业绩、股价反应、估值、同期公告和互动平台问答放在一起讲。
- **增量更新**：同一期过几天再让它"更新一下"，只补新披露的公司。

## 第一次使用

直接召唤专家说"帮我扫一下最新一期业绩预告"就行。它会先检查你电脑上的环境，缺 Python 包会帮你装，数据库默认用本地 SQLite 文件，不需要装任何服务。

**关于 Tushare token**（可选，但推荐）：

- 没有 token：业绩预告扫描、股价反映和估值分析都能用（K 线与估值来自公开行情接口）；预告的单季拆解和营收是空的，正式财报扫描需要 token 才能跑，所以只能用推断模式。
- 有 token：去 [tushare.pro](https://tushare.pro) 注册，在个人主页找到"接口TOKEN"复制给专家，它会帮你存到本机（`~/.ch-skills/config.env`，只有你自己能读）。不同积分档位能调用的接口不同，专家会逐个接口检查并告诉你哪些功能可用。

## 运行要求

- Python 3.9 及以上
- 能访问巨潮资讯网（cninfo.com.cn）、新浪财经与东方财富的行情接口；使用 Tushare 时还需能访问 tushare.pro
- 首次扫描需要几分钟到半小时（要下载公告 PDF 或逐家取报表），之后的更新很快

## 产出在哪里

所有报告都在 `~/earnings-season/reports/` 下：

- `forecast_<报告期>.html`：业绩预告报告
- `qreport_<报告期>.html`：正式财报报告
- 同名的 `.klines/` 文件夹是报告里的 K 线数据，挪动报告时要一起挪

## 说明

本专家给出的是业绩分档、股价对业绩的反映程度和估值阶段，不提供任何买卖建议、目标价或仓位建议，也不预测股价。数据来自巨潮资讯、新浪财经、东方财富和 Tushare 的公开接口，解析结果以公告原文为准。
