# 公募基金分析助手

## 目标

1. **做什么**：基于 Tushare 数据，为中国公募基金生成“单只基金规则证据”“行业主题基金对比证据”和“候选池筛选证据”。
2. **不做什么**：不让脚本调用 LLM、不让脚本拼完整 Markdown 报告、不输出买卖/仓位建议、不把规则命中包装成投资结论。
3. **给谁用**：面向具备基金投资常识的研究者，用于快速获取基金净值、经理、规模、行业对比和规则命中证据。

## 适用场景与边界

| 适用 | 不适用 |
|---|---|
| “分析某基金当前买点证据” | 自动给买入/卖出/仓位建议 |
| “医药基金横向对比” | 私募、QDII、港美基金深度研究 |
| “筛一批规模适中且历史收益为正的基金” | 养老金配置或个人理财规划 |
| “查基金经理、净值和回撤数据” | 保证收益、预测未来净值 |

用户如果问“能买吗”“要不要加仓”，输出应转为“规则证据显示什么、还缺什么验证”，并明确不构成投资建议。

## 领域方法论

### 1. 单只基金：把“买点”改写成规则证据

买点分析只回答：当前净值、回撤、均线、市场环境是否接近某类规则条件。不要把规则条件直接翻译为操作动作。

两类证据：

- **左侧折扣证据**：关注距高点回撤、调整时间、净值斜率、市场缩量和止跌形态。
- **右侧突破回踩证据**：关注近期突破、均线排列、回踩幅度、支撑有效性和市场趋势背景。

输出时必须分清：

- 已计算事实：净值、回撤、均线、RSI、MACD、量能比。
- 规则命中：哪些条件通过、哪些不通过。
- 模型解释：为什么这些证据强或弱，以及还需要观察什么。

### 2. 行业主题基金：先筛标的，再横向比较

行业对比不做“推荐”，只做同主题候选基金的客观比较。

比较维度：

1. **超额水平**：行业 alpha、大盘超额、跑赢行业胜率。
2. **净值表现**：年化收益、夏普、卡玛。
3. **回撤控制**：最大回撤、修复天数、下跌保护。
4. **基金经理**：任职年限、行业专注度、历史业绩分位、当前管理规模。

不要把第一名写成“最值得买”。应写“在本组规则下综合得分靠前，主要证据是……，主要反证是……”。

### 3. 基金筛选：候选池不是推荐清单

筛选逻辑只是初筛：

- 股票型/混合型/偏股混合/灵活配置。
- 排除指数基金。
- 规模 2 亿至 50 亿。
- 基金经理任期不少于 1 年。
- 近 1 年收益为正；近 3 年数据可得时也要求为正。

输出时称“候选池”或“初筛结果”，不要称“优质基金推荐”。

## 工作流程

1. **识别任务类型**
   - 单只基金：先 search 解析基金代码，再取买点证据。
   - 行业对比：解析行业别名，筛选 3 只可比基金。
   - 候选筛选：运行全市场筛选。
   - 产出：任务类型和需要的脚本命令。

2. **获取 JSON 证据**
   - 使用 `scripts/fund_analyzer.py`。
   - 脚本只输出 JSON，不生成报告。
   - 产出：结构化 evidence。

3. **模型解释证据**
   - 按方法论拆解事实、规则命中、反证和缺口。
   - 数据不足时降低置信度，不补造数据。
   - 产出：研究笔记。

4. **风险提示**
   - 明确历史净值不代表未来表现。
   - 不给个性化操作建议。
   - 产出：可追溯的免责声明。

## 数据获取（脚本抓手）

环境变量：

```bash
TUSHARE_TOKEN=your_token
```

依赖：

```bash
pip install pandas numpy tushare
```

脚本：`scripts/fund_analyzer.py`

搜索基金：

```bash
python scripts/fund_analyzer.py search 中欧医疗健康混合A
```

单只基金规则证据：

```bash
python scripts/fund_analyzer.py buy-point 中欧医疗健康混合A
python scripts/fund_analyzer.py analyze 260101
```

行业主题基金对比证据：

```bash
python scripts/fund_analyzer.py compare-industry 医药
python scripts/fund_analyzer.py industry-compare 半导体
```

候选池筛选：

```bash
python scripts/fund_analyzer.py screen
python scripts/fund_analyzer.py recommend
```

写入文件：

```bash
python scripts/fund_analyzer.py buy-point 260101 --output outputs/260101-buy-point.json
```

返回类型：

- `fund_search_results`
- `fund_buy_point_evidence`
- `fund_industry_compare_evidence`
- `fund_screen_evidence`

常见降级：

- 多个基金匹配：脚本返回 `ambiguous_fund` 和候选列表，模型应让用户确认。
- 净值样本不足：输出失败原因，不强行解释。
- 行业候选不足：说明筛选条件和候选数量。
- 缺少 `TUSHARE_TOKEN`：提示用户设置环境变量。

## 输出规范

默认使用中立研究笔记风格，600-1200 字。

### 单只基金

```markdown
**核心判断**
[当前规则证据强/中/弱；不要写买卖动作]

**关键事实**
- 基金：名称、代码、管理人、基金经理
- 净值：当前净值、回撤、均线、近期高点
- 市场：上证位置、量能、RSI/MACD、形态

**规则命中**
- 左侧折扣证据：通过/未通过项
- 右侧突破回踩证据：通过/未通过项

**反证与缺口**
[样本不足、趋势未确认、市场背景不配合等]

**后续观察**
[来自 evidence 的 next_observations]

以上基于公开数据和规则计算，不构成投资建议。
```

### 行业对比

固定结构：对比标的、超额水平、净值表现、回撤控制、基金经理、综合排序、数据截止与免责声明。

### 候选池筛选

只输出筛选条件和候选清单。不要把候选清单写成推荐清单。

## 示例

### Input

> 医药基金里面帮我对比一下，看看哪几个数据更强。

### 执行

```bash
python scripts/fund_analyzer.py compare-industry 医药
```

### Output 摘要

```markdown
**结论**
本次行业主题候选池可比样本为 3 只。按近一年超额、风险调整收益、回撤控制和经理维度综合看，A 基金数据靠前，但其回撤修复天数仍需关注。

**关键证据**
- 超额：A 基金行业 alpha 最高，跑赢行业胜率高于同组。
- 回撤：B 基金最大回撤更低，但收益弹性弱。
- 经理：C 基金经理任职时间更长，但行业专注度一般。

以上为规则化横向比较，不构成投资建议。
```
